# 算法讲解039【必备】嵌套类问题的递归解题套路
前置知识：讲解017、020、021、023、036、037、038（这些章节都分析过递归，尤其讲解038，不熟悉的同学可以先熟悉一下）
代码位置：src/class039 ｜ 内容：3 道嵌套类问题（表达式求值、字符串解码、分子式求原子数量），时间复杂度均 O(n)
## 零、嵌套类问题的解题套路
适用场景：字符串中存在"括号/定界符嵌套"结构，需要逐层解析，例如 `2*(3+4)`、`3[a2[c]]`、`(H2O)2` 等。
大概过程：
- 定义全局变量 `int where`。
- 递归函数 `f(i)`：从 `s[i..]` 位置出发开始解析，遇到「字符串终止」或「嵌套条件终止符」就返回。
- 返回值就是 `f(i)` 负责的这一段的结果。
- `f(i)` 在返回前更新全局变量 `where`，让上级函数通过 `where` 知道解析到了什么位置，进而继续。
执行细节：
- 如果 `f(i)` 遇到「嵌套条件开始符」（如 `(`、`[`），就调用下级递归去处理嵌套部分，下级负责嵌套部分的计算结果。
- 下级处理完成后，`f(i)` 通过下级更新的全局变量 `where`，知道该从什么位置继续解析（`i = where + 1`）。
套路核心示意（以 `a(bc)` 为例）：
```
外层 f(0):  解析 a → 遇到 '(' → 调用内层 f(2)
内层 f(2):  解析 bc → 遇到 ')' → 更新 where=4 → 返回结果
外层 f(0):  收到结果，i = where+1 = 5，继续解析（已到串尾）
外层 f(0):  更新 where → 返回整个结果
```
为什么每个字符只被处理一次：外层通过 `where` 跳过已解析的嵌套段，嵌套段内部字符只被内层递归访问，所以总时间复杂度 O(n)。
## 一、含有嵌套的表达式求值 ｜ 时间复杂度 O(n)
- 测试链接：https://leetcode.cn/problems/basic-calculator-iii/（LeetCode 772. 基本计算器 III，会员题）
- 牛客网链接：https://www.nowcoder.com/practice/c215ba61c8b1443b996351df929dc4d4（提交时将函数名 calculate 改为 solve）
- 题意：实现一个支持 `+ - * /` 和括号嵌套的非负整数表达式求值，例如 `2*(5+5*2)/3+(6/2+8) = 21`。
- 思路：`f(s, i)` 负责从 i 开始计算到 `)` 或串尾；遇到 `(` 递归处理子表达式；用两个列表 numbers/ops 收集本层数字与运算符，乘除在入栈时立即结算（与栈顶运算），加减留到最后统一求和。
```java
public static int where;
// s[i....]开始计算，遇到字符串终止 或者 遇到)停止
// 返回 : 自己负责的这一段，计算的结果
// 返回之前，更新全局变量where，为了上游函数知道从哪继续！
public static int f(char[] s, int i) {
  int cur = 0;
  ArrayList<Integer> numbers = new ArrayList<>();
  ArrayList<Character> ops = new ArrayList<>();
  while (i < s.length && s[i] != ')') {
    if (s[i] >= '0' && s[i] <= '9') {
      cur = cur * 10 + s[i++] - '0';
    } else if (s[i] != '(') {
      // 遇到了运算符 + - * /
      push(numbers, ops, cur, s[i++]);
      cur = 0;
    } else {
      // 遇到了左括号！
      cur = f(s, i + 1);
      i = where + 1;
    }
  }
  push(numbers, ops, cur, '+');
  where = i;
  return compute(numbers, ops);
}
```
- 乘除优先级的处理：入栈时若栈顶运算符是 `*` 或 `/`，直接与栈顶数字结算，结果写回栈顶；否则（栈顶是 `+`、`-` 或栈空）正常入栈。
```java
public static void push(ArrayList<Integer> numbers, ArrayList<Character> ops, int cur, char op) {
  int n = numbers.size();
  if (n == 0 || ops.get(n - 1) == '+' || ops.get(n - 1) == '-') {
    numbers.add(cur);
    ops.add(op);
  } else {
    int topNumber = numbers.get(n - 1);
    char topOp = ops.get(n - 1);
    if (topOp == '*') {
      numbers.set(n - 1, topNumber * cur);
    } else {
      numbers.set(n - 1, topNumber / cur);
    }
    ops.set(n - 1, op);
  }
}
```
- 最后 `compute` 把剩余数字按 `+`/`-` 累加即得结果。注意循环结束后要补一次 `push(cur, '+')`，把最后一个数字也收进来。
## 二、含有嵌套的字符串解码 ｜ 时间复杂度 O(n)
- 测试链接：https://leetcode.cn/problems/decode-string/（LeetCode 394. 字符串解码）
- 题意：编码规则为 `k[encoded_string]`，表示方括号内的 encoded_string 恰好重复 k 次，例如 `3[a2[c]] → accaccacc`，嵌套深度不限。
- 思路：`f(s, i)` 负责从 i 开始解码到 `]` 或串尾；遇到字母直接拼进结果；遇到数字累积倍数 cnt；遇到 `[` 递归解出内部串，重复 cnt 次后拼接。
```java
public static int where;
// s[i....]开始计算，遇到字符串终止 或者 遇到 ] 停止
// 返回 : 自己负责的这一段字符串的结果
// 返回之前，更新全局变量where，为了上游函数知道从哪继续！
public static String f(char[] s, int i) {
  StringBuilder path = new StringBuilder();
  int cnt = 0;
  while (i < s.length && s[i] != ']') {
    if ((s[i] >= 'a' && s[i] <= 'z') || (s[i] >= 'A' && s[i] <= 'Z')) {
      path.append(s[i++]);
    } else if (s[i] >= '0' && s[i] <= '9') {
      cnt = cnt * 10 + s[i++] - '0';
    } else {
      // 遇到 [
      path.append(get(cnt, f(s, i + 1)));
      i = where + 1;
      cnt = 0;
    }
  }
  where = i;
  return path.toString();
}
public static String get(int cnt, String str) {
  StringBuilder builder = new StringBuilder();
  for (int i = 0; i < cnt; i++) {
    builder.append(str);
  }
  return builder.toString();
}
```
- 关键点：数字只在 `[` 前面出现，遇到 `[` 时 cnt 恰好收集完整；用完 cnt 后必须清零，等待下一个数字。
## 三、含有嵌套的分子式求原子数量 ｜ 时间复杂度 O(n)
- 测试链接：https://leetcode.cn/problems/number-of-atoms/（LeetCode 726. 原子的数量）
- 题意：给定化学式（含元素名、括号、计数），按字典序输出每种原子数量，例如 `K4(ON(SO3)2)2 → K4N2O14S4`；计数为 1 时不输出数字。
- 思路：`f(s, i)` 负责从 i 开始统计到 `)` 或串尾，返回一个 TreeMap（有序表，天然按字典序）；维护三个"历史信息"——当前收集的元素名 name、下级括号返回的有序表 pre、计数 cnt；每当遇到「新的大写字母」或「(」时，说明上一段信息结束，先 `fill` 进总表再清空历史，开始收集新一段。
```java
public static int where;
// s[i....]开始计算，遇到字符串终止 或者 遇到 ) 停止
// 返回 : 自己负责的这一段字符串的结果，有序表！
// 返回之前，更新全局变量where，为了上游函数知道从哪继续！
public static TreeMap<String, Integer> f(char[] s, int i) {
  // ans是总表
  TreeMap<String, Integer> ans = new TreeMap<>();
  // 之前收集到的名字，历史一部分
  StringBuilder name = new StringBuilder();
  // 之前收集到的有序表，历史一部分
  TreeMap<String, Integer> pre = null;
  // 历史翻几倍
  int cnt = 0;
  while (i < s.length && s[i] != ')') {
    if (s[i] >= 'A' && s[i] <= 'Z' || s[i] == '(') {
      fill(ans, name, pre, cnt);
      name.setLength(0);
      pre = null;
      cnt = 0;
      if (s[i] >= 'A' && s[i] <= 'Z') {
        name.append(s[i++]);
      } else {
        // 遇到 (
        pre = f(s, i + 1);
        i = where + 1;
      }
    } else if (s[i] >= 'a' && s[i] <= 'z') {
      name.append(s[i++]);
    } else {
      cnt = cnt * 10 + s[i++] - '0';
    }
  }
  fill(ans, name, pre, cnt);
  where = i;
  return ans;
}
```
- `fill` 把"一段历史"结算进总表：普通元素名直接加 cnt；括号子表则整体翻 cnt 倍再合并；cnt 为 0 视为 1。
```java
public static void fill(TreeMap<String, Integer> ans, StringBuilder name, TreeMap<String, Integer> pre, int cnt) {
  if (name.length() > 0 || pre != null) {
    cnt = cnt == 0 ? 1 : cnt;
    if (name.length() > 0) {
      String key = name.toString();
      ans.put(key, ans.getOrDefault(key, 0) + cnt);
    } else {
      for (String key : pre.keySet()) {
        ans.put(key, ans.getOrDefault(key, 0) + pre.get(key) * cnt);
      }
    }
  }
}
```
- 最外层用 TreeMap 按字典序拼接答案，数量为 1 时不写数字。
## 四、本节小结
- 嵌套类问题统一套路：全局变量 `where` + 递归函数 `f(i)`，返回本段结果、返回前更新 `where`，上级用 `i = where + 1` 继续，每个字符只处理一次，整体 O(n)。
- 三道题只是"本段结果"的类型不同：表达式求值返回 int、字符串解码返回 String、分子式返回 TreeMap，递归骨架完全一致。
- 处理嵌套的关键是信任下级递归：遇到开始符就递归，递归必然正确返回嵌套段结果并更新 where，上级只管拼接本层逻辑。
- 与讲解038的联系：同样不要去"人肉模拟"多层嵌套调用过程，只需定义好 `f(i)` 的含义——"负责从 i 到终止符这一段"。
