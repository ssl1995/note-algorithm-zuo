## 一、堆结构：完全二叉树 + 数组前缀
- 堆结构用完全二叉树和数组的前缀范围来对应：数组 arr 的 [0, size-1] 前缀就是一棵完全二叉树，堆的大小用单独的变量 size 控制（往堆里加数 size++，弹出堆顶 size--）。
- 下标换算（i 位置的节点）：
  - 父亲节点：(i - 1) / 2
  - 左孩子：i * 2 + 1
  - 右孩子：i * 2 + 2
- 堆的定义：每一棵子树的最大值都是这棵子树的头，叫大根堆；每一棵子树的最小值都是这棵子树的头，叫小根堆。本课按大根堆讲解，小根堆同理。
- 完全二叉树的高度是 O(logn)，所以堆的两个基本调整（heapInsert、heapify）单次调用时间复杂度都是 O(logn)，这是完全二叉树的结构决定的。
## 二、heapInsert：i 位置的数向上调整
- 场景：arr[i] = x 是新来的数（或者在 i 位置变大了），往上看，只要比父亲大就和父亲交换，直到不比父亲大，或者来到 0 位置（堆顶）。
```java
// i位置的数，向上调整大根堆
public static void heapInsert(int[] arr, int i) {
    while (arr[i] > arr[(i - 1) / 2]) {
        swap(arr, i, (i - 1) / 2);
        i = (i - 1) / 2;
    }
}
```
- 一路最多交换到根，路径长度就是树高，时间复杂度 O(logn)。
## 三、heapify：i 位置的数向下调整
- 场景：i 位置的数变小了，又想维持大根堆结构，就往下沉：每次在左孩子、右孩子、自己三者中选出最大的（下标 best），如果自己就是最大的就停，否则与最大孩子交换，继续往下。
```java
// i位置的数，向下调整大根堆，当前堆的大小为size
public static void heapify(int[] arr, int i, int size) {
    int l = i * 2 + 1;
    while (l < size) {
        // 先评选左右孩子中最强的孩子，注意右孩子可能不存在(l+1越界)
        int best = l + 1 < size && arr[l + 1] > arr[l] ? l + 1 : l;
        // 再和当前的数比，选出三者中的最强下标
        best = arr[best] > arr[i] ? best : i;
        if (best == i) {
            break;
        }
        swap(arr, best, i);
        i = best;
        l = i * 2 + 1;
    }
}
```
- 细节：右孩子 l+1 可能越界，必须先判断 l + 1 < size；同样最多沉到叶，时间复杂度 O(logn)。
## 四、堆排序：建堆 + 依次弹出最大值
### 1. 建堆的两种方式
- A. 从顶到底建堆：依次让每个位置的数 heapInsert（像一个个新数加入堆），时间复杂度 O(n * logn)，代价是 log1 + log2 + ... + logn。
- B. 从底到顶建堆：从最后一个位置往前，依次让每个位置的数 heapify，时间复杂度 O(n)。
- 为什么会有差异？越靠下的节点越多、但能下沉的高度越小；越靠上的节点越少、下沉高度越大。代价是收敛的等比数列，以 n = 15（4层满树）为例：
```plain
层(自底向上)   节点数      每节点最多下沉次数     该层总代价
第0层(叶)       8            0                   8 * 0 = 0
第1层           4            1                   4 * 1 = 4
第2层           2            2                   2 * 2 = 4
第3层(根)       1            3                   1 * 3 = 3
总代价 = 0+4+4+3 = 11 < n=15
通项：n/2 * 0 + n/4 * 1 + n/8 * 2 + ... <= n，等比数列求和收敛，所以 O(n)
```
- 而从顶到底建堆时，越靠下节点越多、要上浮的高度也越大（大多数节点代价都接近 logn），所以是 O(n * logn)。
### 2. 排序阶段
- 建好堆后：堆顶（0位置）是当前最大值，把它和堆的最后一个位置（size-1）交换，size--（最大值归位、脱离堆），再对堆顶 heapify(0, size) 恢复大根堆；重复直到 size 只剩 1。
- 这样从最大值到最小值依次归位到数组尾部，数组自然升序。共 n 次弹出，每次 heapify 是 O(logn)，时间复杂度 O(n * logn)。
```java
// 从底到顶建立大根堆，O(n)
// 依次弹出堆内最大值并排好序，O(n * logn)
// 整体时间复杂度O(n * logn)
public static void heapSort2(int[] arr) {
    int n = arr.length;
    for (int i = n - 1; i >= 0; i--) {
        heapify(arr, i, n);
    }
    int size = n;
    while (size > 1) {
        swap(arr, 0, --size);
        heapify(arr, 0, size);
    }
}
```
## 五、复杂度与性质总结
- 时间复杂度 O(n * logn)：不管以什么方式建堆，调整阶段的时间复杂度都是 O(n * logn)，所以整体复杂度也是这个。
- 额外空间复杂度 O(1)：堆直接建立在要排序的数组上，没有额外空间。
- 堆排序是不稳定排序：堆顶与堆尾的交换会打乱相等元素的相对顺序。
- 注意：堆结构比堆排序有用得多，尤其是和比较器（自定义比较规则）结合之后（如求中位数、合并K个有序链表、最大线段重合等问题），后面几节课会重点讲述。

## 七、总结
- 堆 = 数组前缀表示的完全二叉树；父亲 (i-1)/2、左孩子 2i+1、右孩子 2i+2；大根堆每棵子树的最大值在子树的头上。
- heapInsert 向上调、heapify 向下调，单次都是 O(logn)。
- 堆排序 = 建堆（从顶到底 O(n*logn)，从底到顶 O(n)）+ 堆顶与堆尾交换并 heapify 的弹出阶段 O(n*logn)，整体 O(n*logn)、额外空间 O(1)、不稳定。
- 堆结构本身（尤其配合比较器）比堆排序更有用，是后续课程的重点。
