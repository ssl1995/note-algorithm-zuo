## 一、辗转相除法求最大公约数（欧几里得算法）
- 核心代码只有一行：不断用 `gcd(b, a % b)` 递归，直到 `b == 0` 时 `a` 就是最大公约数。
```java
public static long gcd(long a, long b) {
    return b == 0 ? a : gcd(b, a % b);
}
```
- 正确性证明：只需证明 `gcd(a, b) = gcd(b, a % b)`。
  - 设 `a % b = r`，则两个等式必然成立：① `a = b * q + r`；② `r = a − b * q`（q 为非负整数）。
  - 若 u 是 a 和 b 的公因子，即 `a = s*u, b = t*u`，代入 ② 得 `r = (s − t*q) * u`，说明 u 也是 r 的因子。
  - 若 v 是 b 和 r 的公因子，即 `b = x*v, r = y*v`，代入 ① 得 `a = (x*q + y) * v`，说明 v 也是 a 的因子。
  - 综上，a 和 b 的全体公因子集合 = b 和 r 的全体公因子集合，所以 `gcd(a, b) = gcd(b, r)`，证明结束。
- 时间复杂度：求 `gcd(a, b)`（a > b）为 O((log a)³)，复杂度证明略，这个效率已经足够好，直接记忆过程即可。
- 过程示意（求 gcd(48, 18)）：
```
gcd(48, 18) → gcd(18, 48%18=12) → gcd(12, 18%12=6) → gcd(6, 12%6=0) → 返回 6
```
- 由最大公约数简单转化即可求最小公倍数（注意先除后乘防止溢出）：
```java
public static long lcm(long a, long b) {
    return (long) a / gcd(a, b) * b;
}
```
- 扩展（比赛同学可继续研究）：更高效的 Stein 算法（用移位和减法代替取模）、由最大公约数扩展出的"裴蜀定理"（`ax + by = gcd(a,b)` 必有整数解）。
## 二、经典题目：第 n 个神奇的数字
- 测试链接：https://leetcode.cn/problems/nth-magical-number/（LeetCode 878. 第 N 个神奇数字）
- 题意：一个正整数如果能被 a 或 b 整除，那么它是神奇的。给定 n、a、b，返回第 n 个神奇的数字，答案对 10⁹+7 取模。
- 思路：二分答案法 + 容斥原理（两个重要算法，本题用得很浅）：
  - 在 `[0, n * min(a, b)]` 范围内二分答案 m，第 n 个神奇数字一定不超过 `n * min(a, b)`。
  - 用容斥原理统计 1..m 中神奇数字的个数：`m/a + m/b − m/lcm`（a 的倍数 + b 的倍数 − 重复的 lcm 的倍数）。
  - 若个数 >= n，说明答案 <= m，收缩右边界并记录 m；否则收缩左边界。
```java
public static int nthMagicalNumber(int n, int a, int b) {
    long lcm = lcm(a, b);
    long ans = 0;
    // l = 0, r = (long) n * Math.min(a, b)，在 l......r 上二分
    for (long l = 0, r = (long) n * Math.min(a, b), m = 0; l <= r;) {
        m = (l + r) / 2;
        // 1....m 中神奇数字的个数 : m / a + m / b - m / lcm
        if (m / a + m / b - m / lcm >= n) {
            ans = m;
            r = m - 1;
        } else {
            l = m + 1;
        }
    }
    return (int) (ans % 1000000007);
}
```
- "二分答案法"非常巧妙，可以解决很多问题，后续【必备】课程会有专题；"容斥原理"可以考得很难，后续【扩展】课程会有专题。
## 三、同余原理
- 背景：笔试中常遇到"答案很大，请对 10⁹+7 取模"的要求。同余原理保证：加法、减法、乘法在任意中间步骤取模，最终结果与算完再取模完全一致。
- 三条规则：
  - 加法：`(a + b) % m`，每一步算完直接取模；
  - 乘法：`(a * b) % m`，每一步算完直接取模，中间变量要用 `long` 防止溢出（两个 int 相乘可能溢出 int）；
  - 减法：`(a − b + m) % m`，加 m 是为了避免出现负数结果；
  - 除法：不能直接取模，需要求逆元，较难题目才会涉及，后续【必备】课程讲述。
- 对数器验证：代码中用 `BigInteger` 实现暴力精确版 f1，用同余原理实现快速版 f2，随机 10 万组数据对比两者结果是否一致。
```java
// 计算 ((a + b) * (c - d) + (a * c - b * d)) % mod 的非负结果
// f1 : BigInteger 暴力版（先算精确值，最后取模，作为对数器的标准答案）
// f2 : 同余原理版（每一步直接取模）
public static int f2(long a, long b, long c, long d, int mod) {
    int o1 = (int) (a % mod); // a
    int o2 = (int) (b % mod); // b
    int o3 = (int) (c % mod); // c
    int o4 = (int) (d % mod); // d
    int o5 = (o1 + o2) % mod; // a + b
    int o6 = (o3 - o4 + mod) % mod; // c - d，+mod 防止负数
    int o7 = (int) (((long) o1 * o3) % mod); // a * c，用long做中间变量
    int o8 = (int) (((long) o2 * o4) % mod); // b * d
    int o9 = (int) (((long) o5 * o6) % mod); // (a + b) * (c - d)
    int o10 = (o7 - o8 + mod) % mod; // (a * c - b * d)
    int ans = (o9 + o10) % mod; // 最终结果
    return ans;
}
```
- 验证结果：10 万组随机数据下 f1 与 f2 结果完全一致，证明同余原理的正确性。自己也可以设计实验用对数器随意验证。
## 四、总结
- `gcd(a, b) = b == 0 ? a : gcd(b, a % b)`，一行代码必须背下来；`lcm(a, b) = a / gcd(a, b) * b`（先除后乘防溢出）。
- 最大公约数的典型应用：结合二分答案法 + 容斥原理解决"第 n 个神奇数字"这类计数问题。
- 同余原理是处理"大数取模"类题目的基本功：加、乘每步取模，减法 `(a − b + m) % m`，乘法中间变量用 `long`，除法留待逆元讲解。
