## 二、题目1：普通二叉树上寻找两个节点的最近公共祖先（LeetCode 236）
- 测试链接：https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/
- 要求：给定普通二叉树和两个节点 p、q（保证都在树中），返回它们的最近公共祖先（LCA，允许一个节点是它自己的祖先）。
- 思路（递归，搜索汇报）：在整棵树上搜索 p 或 q，遇到空、p、q 就直接返回当前节点；一个节点收到左右子树的返回值后：左右都非空 → 说明 p、q 分居两侧，当前节点就是答案；左右都为空 → 返回空；一空一不空 → 把不空的那个继续向上汇报。
```text
        root
       /    \
   搜到p    搜到q   → 左右都非空，root 就是 LCA
       \
      搜到p(q在其子树中) → 一空一不空，返回不空的（p 就是 LCA）
```
```java
public static TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) {
        // 遇到空，或者p，或者q，直接返回
        return root;
    }
    TreeNode l = lowestCommonAncestor(root.left, p, q);
    TreeNode r = lowestCommonAncestor(root.right, p, q);
    if (l != null && r != null) {
        // 左树也搜到，右树也搜到，返回root
        return root;
    }
    if (l == null && r == null) {
        // 都没搜到返回空
        return null;
    }
    // l和r一个为空，一个不为空，返回不空的那个
    return l != null ? l : r;
}
```
- 复杂度：时间 O(n)，空间 O(树高)。
- 关键点：返回值含义是"以当前节点为根的子树里搜到的 p/q 或它们的 LCA"；一旦某侧先搜到 p 或 q 就直接返回，所以被搜到的节点不会继续往下搜——这正是"若 p 是 q 的祖先则返回 p"能被正确处理的原因。
## 三、题目2：搜索二叉树上寻找两个节点的最近公共祖先（LeetCode 235）
- 测试链接：https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/
- 思路：利用 BST 的有序性，从根开始迭代，根本不需要递归整棵树：
  - 1）root 就是 p 或 q → root 就是答案（先遇到谁谁就是答案）；
  - 2）root.val 落在 p、q 值之间（开区间）→ p、q 分居两侧，root 就是答案；
  - 3）root.val 比 p、q 都小 → 答案在右树，往右走；
  - 4）root.val 比 p、q 都大 → 答案在左树，往左走。
```text
        6
       / \
      2   8       p=2, q=8：6 在 (2,8) 之间 → 答案是 6
     / \ / \
    0  4 7  9     p=2, q=4：先遇到 p=2 → 答案是 2
```
```java
public static TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // root从上到下
    // 如果先遇到了p，说明p是答案；先遇到了q，说明q是答案
    // 如果root在p~q的值之间，不用管谁大谁小，root就是答案
    // 如果root在p~q的值左侧，往右移动；在右侧，往左移动
    while (root.val != p.val && root.val != q.val) {
        if (Math.min(p.val, q.val) < root.val && root.val < Math.max(p.val, q.val)) {
            break;
        }
        root = root.val < Math.min(p.val, q.val) ? root.right : root.left;
    }
    return root;
}
```
- 复杂度：时间 O(树高)，空间 O(1)。
- 关键点：BST 的 LCA 就是从上往下走遇到的第一个"值落在 [p,q] 范围内（含端点）"的节点，一次遍历即可，是题目1的特例优化。
## 四、题目3：收集累加和等于aim的所有路径（LeetCode 113）
- 测试链接：https://leetcode.cn/problems/path-sum-ii/
- 要求：返回所有从根到叶子、节点值累加和等于 targetSum 的路径。
- 思路（深度优先遍历 + 恢复现场）：用一个全局 path 列表记录当前路径，向下递归时 add，递归返回时 remove（回溯）；到达叶节点时判断 sum + 当前值是否等于 aim，是则把 path 拷贝一份加入答案。
```text
        5
       / \
      4   8        aim = 22
     /   / \
   11  13  4      答案: [5,4,11,2] 和 [5,8,4,5]
   / \    / \
  7   2  5   1
path 的使用节奏：add(向下走) → 递归 → remove(回退)，现场必须复原
```
```java
public static void f(TreeNode cur, int aim, int sum, List<Integer> path, List<List<Integer>> ans) {
    if (cur.left == null && cur.right == null) {
        // 叶节点
        if (cur.val + sum == aim) {
            path.add(cur.val);
            copy(path, ans); // 拷贝一份进答案，不能把 path 本体加进去
            path.remove(path.size() - 1);
        }
    } else {
        // 不是叶节点
        path.add(cur.val);
        if (cur.left != null) {
            f(cur.left, aim, sum + cur.val, path, ans);
        }
        if (cur.right != null) {
            f(cur.right, aim, sum + cur.val, path, ans);
        }
        path.remove(path.size() - 1); // 恢复现场
    }
}
```
- 复杂度：时间 O(n^2)（最坏情况每条合格路径都要拷贝 O(n)），空间 O(树高)。
- 关键点："递归恢复现场"是路径收集类问题的基本功——所有分支共用一份 path，每次递归返回后必须 remove 撤销修改；答案里要放 path 的拷贝而不是引用，否则会被后续修改污染。
## 五、题目4：验证平衡二叉树（LeetCode 110，树型dp沾边）
- 测试链接：https://leetcode.cn/problems/balanced-binary-tree/
- 要求：判断每个节点的左右子树高度差是否都不超过 1。
- 思路：求高度的同时顺带验证——递归返回每棵子树的高度，返回前检查 |左高-右高| > 1 就把全局标志 balance 置为 false；一旦发现不平衡，提前剪枝，返回什么高度已经不重要了。
```java
public static boolean balance; // 全局变量，所有调用过程共享
public static boolean isBalanced(TreeNode root) {
    balance = true; // 每次判断开始时，设置为true
    height(root);
    return balance;
}
// 一旦发现不平衡，返回什么高度已经不重要了
public static int height(TreeNode cur) {
    if (!balance || cur == null) {
        return 0;
    }
    int lh = height(cur.left);
    int rh = height(cur.right);
    if (Math.abs(lh - rh) > 1) {
        balance = false;
    }
    return Math.max(lh, rh) + 1;
}
```
- 复杂度：时间 O(n)，空间 O(树高)。
- 关键点1：不要写成"对每个节点分别求左右子树高度"——那会产生大量重复计算，复杂度退化为 O(n·h)；一定要在求高度的递归过程中同步检查，一次遍历搞定。
- 关键点2：这就是树型dp的雏形——每个节点依赖左右子树的信息（高度）做出自己的判断，只是本题用全局变量代替了信息封装。
## 六、题目5：验证搜索二叉树（LeetCode 98，树型dp沾边）
- 测试链接：https://leetcode.cn/problems/validate-binary-search-tree/
- 重要结论：BST 的中序遍历结果一定是严格递增序列，验证 BST 的本质就是验证这一点。
- 方法1（推荐）：中序遍历（非递归，数组模拟栈），边遍历边比较"前一个值 pre 是否 >= 当前值"，一旦出现逆序直接返回 false。
```java
public static int MAXN = 10001;
public static TreeNode[] stack = new TreeNode[MAXN];
public static int r;
// 提交时改名为isValidBST
public static boolean isValidBST1(TreeNode head) {
    if (head == null) {
        return true;
    }
    TreeNode pre = null;
    r = 0;
    while (r > 0 || head != null) {
        if (head != null) {
            stack[r++] = head;
            head = head.left;
        } else {
            head = stack[--r];
            if (pre != null && pre.val >= head.val) { // 中序序列必须严格递增
                return false;
            }
            pre = head;
            head = head.right;
        }
    }
    return true;
}
```
- 方法2（递归，树型dp沾边）：每棵子树向父节点汇报自己的最小值 min 和最大值 max；以 head 为根的树是 BST 当且仅当：左树是 BST、右树是 BST、左树max < head.val < 右树min。
```java
public static long min, max; // 全局变量，每棵子树递归返回后更新
// 提交时改名为isValidBST
public static boolean isValidBST2(TreeNode head) {
    if (head == null) {
        min = Long.MAX_VALUE;
        max = Long.MIN_VALUE;
        return true;
    }
    boolean lok = isValidBST2(head.left);
    long lmin = min, lmax = max;
    boolean rok = isValidBST2(head.right);
    long rmin = min, rmax = max;
    min = Math.min(Math.min(lmin, rmin), head.val);
    max = Math.max(Math.max(lmax, rmax), head.val);
    return lok && rok && lmax < head.val && head.val < rmin;
}
```
- 复杂度：两种方法都是时间 O(n)，空间 O(树高)。
- 易错点：只比较"节点和它的直接孩子"是错的——BST 要求左子树的所有节点都小于当前节点，所以要么用中序递增性，要么用子树的 min/max 信息。
- 细节：用 long 类型的 min/max 是为了兼容节点值取到 Integer 边界的测试数据；空树约定 min=+∞、max=-∞，让父节点的比较自然成立。
## 七、题目6：修剪搜索二叉树（LeetCode 669）
- 测试链接：https://leetcode.cn/problems/trim-a-binary-search-tree/
- 要求：删除 BST 中所有值不在 [low, high] 区间内的节点，并保持结果仍是 BST。
- 思路（利用 BST 性质剪枝，递归函数的返回值就是"修剪好的子树"）：
  - 1）cur 为空 → 返回空；
  - 2）cur.val < low → cur 和它的整个左子树都要删，答案只能在右子树里，返回修剪后的右子树；
  - 3）cur.val > high → 对称地，返回修剪后的左子树；
  - 4）cur 在范围内 → cur 保留，左右子树分别接上修剪后的结果，返回 cur。
```text
     3               3
    / \             / \
   0   4    →      1   4       [low, high] = [1, 3]
    \
     2            0和2被删：0 < low 整个去掉；2 > high 被左孩子1替代
    /
   1
```
```java
public static TreeNode trimBST(TreeNode cur, int low, int high) {
    if (cur == null) {
        return null;
    }
    if (cur.val < low) {
        // cur和左子树全部不要，去右子树里找能留的部分
        return trimBST(cur.right, low, high);
    }
    if (cur.val > high) {
        return trimBST(cur.left, low, high);
    }
    // cur在范围中，左右接上修剪后的子树
    cur.left = trimBST(cur.left, low, high);
    cur.right = trimBST(cur.right, low, high);
    return cur;
}
```
- 复杂度：时间 O(n)，空间 O(树高)。
- 关键点：正因为是 BST，"cur.val < low 则左子树全删、cur.val > high 则右子树全删"才成立，普通二叉树没有这种好事；"父节点接住子节点修剪后的返回值"是树结构修改类问题的通用写法。
## 八、题目7：二叉树打家劫舍问题（LeetCode 337，树型dp沾边）
- 测试链接：https://leetcode.cn/problems/house-robber-iii/
- 要求：二叉树节点上放着钱，直接相连的父子节点不能同时偷，求能偷到的最大金额。
- 思路：对每个节点讨论两种状态——偷它（yes）和不偷它（no）：
  - 偷：不能偷左右孩子，收益 = 自己 + 左子树no + 右子树no；
  - 不偷：左右孩子偷不偷都行，取各自最优，收益 = max(左yes, 左no) + max(右yes, 右no)。
  - 最终答案 = max(根的yes, 根的no)。
```text
        3            偷3 → 不能偷2和3，只能偷最右的1：3+1 = 4
       / \           不偷3 → 偷2和右3：2+3 = 5
      2   3          答案 = max(4, 5) = 5
       \   \
        3   1
```
```java
// 全局变量：完成X子树的遍历返回之后
// yes = X子树在偷头节点情况下的最大收益
// no  = X子树在不偷头节点情况下的最大收益
public static int yes, no;
public static void f(TreeNode root) {
    if (root == null) {
        yes = 0;
        no = 0;
    } else {
        int y = root.val;
        int n = 0;
        f(root.left);
        y += no;                    // 偷root，左孩子不能偷
        n += Math.max(yes, no);     // 不偷root，左孩子偷不偷取最优
        f(root.right);
        y += no;                    // 偷root，右孩子不能偷
        n += Math.max(yes, no);     // 不偷root，右孩子偷不偷取最优
        yes = y;
        no = n;
    }
}
public static int rob(TreeNode root) {
    f(root);
    return Math.max(yes, no);
}
```
- 复杂度：时间 O(n)，空间 O(树高)。
- 关键点：这是标准的树型dp——每个节点向父节点返回"偷/不偷"两种状态的信息，父节点据此合并；用全局变量 yes/no 在递归返回后承载信息，是本课程的惯用写法，LeetCode 官方解法等价地用长度为2的数组返回。
- 注意：y 和 n 要先用局部变量累加，最后再赋给全局的 yes/no，否则右子树递归时会覆盖左子树刚算出的信息。
## 九、总结
- LCA 问题：普通二叉树用"搜索汇报"递归（左右都搜到则当前节点是答案），O(n)；BST 利用有序性从上往下一次遍历即可，O(树高)，空间 O(1)。批量查询（Tarjan）和在线查询（树链剖分）属于扩展内容。
- 路径收集类问题：全局 path + "向下add、回退remove"的恢复现场写法，答案记得放拷贝。
- 递归类树题的两大防退化意识：①验证平衡树要在求高度的过程中同步检查，避免 O(n·h)；②验证 BST 要用中序递增性或子树 min/max，不能只比直接孩子。
- 本节课出现的"树型dp沾边"套路：每个节点递归地向父节点返回若干信息（高度、min/max、偷/不偷两种收益），父节点合并信息后向上传递——平衡树、验证BST、打家劫舍III 全是这个框架，为后续动态规划大章节的树型dp打基础。
