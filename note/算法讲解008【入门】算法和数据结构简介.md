## 一、一个有趣、有用的算法分类
- 注意：下面两个名词都不是计算机科学或算法中的标准术语，但很有现实意义。
- 硬计算类算法：精确求解。但某些问题使用硬计算类的算法，可能会让计算的复杂度较高。
- 考察场景：大厂算法和数据结构笔试、面试题、ACM 比赛或和 ACM 形式类似的比赛，考察的都是硬计算类算法。
- 软计算类算法：更注重逼近解决问题，而不是精确求解，计算时间可控。
- 软计算类举例：模糊逻辑、神经网络、进化计算、概率理论、混沌理论、支持向量机、群体智能。
- 岗位关系：硬计算类算法是所有程序员岗位都会考、任何写代码的工作都会用到的——前端、后端、架构、算法所有岗位都要用到；但算法工程师除了掌握硬计算类算法之外，还需要掌握软计算类算法。
## 二、一个宏观的数据结构分类
- 任何数据结构都一定是"连续结构"和"跳转结构"这两种结构拼出来的，没有例外！
- 连续结构：数据在内存中连续存储，通过下标（地址偏移）直接访问。最典型的是数组：
```java
int[] arr = new int[5];
arr[2] = 10; // 下标寻址：起始地址 + 2 * 元素大小，O(1) 直接定位
```
- 跳转结构：数据分散存储，节点之间通过指针（引用）跳转连接。最典型的是链表：
```java
class Node {
    int value;
    Node next; // 通过 next 引用"跳"到下一个节点
}
```
- 组合示例：数组（连续）+ 链表（跳转）可以拼出哈希表；链表节点里再放数组就是"分块链表"；树、图等复杂结构也无非是连续与跳转的不同拼法。
- 数据结构太多了，从链表、队列、栈，到可持久化线段树、树链剖分、后缀数组等等结构，后面的课都会讲到！
