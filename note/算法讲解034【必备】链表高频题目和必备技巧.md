## 一、开场：链表类题目的注意点（PPT 原话）
- 1，如果笔试中空间要求不严格，直接使用容器来解决链表问题。
- 2，如果笔试中空间要求严格、或者在面试中面试官强调空间的优化，需要使用额外空间复杂度 O(1) 的方法。
- 3，最常用的技巧——快慢指针。
- 4，链表类题目往往都是很简单的算法问题，核心考察点并不是算法设计，是 coding 能力。
- 5，这一类问题除了多写多练没有别的应对方法。
- 个人建议：链表类问题既然练的就是 coding，那么不要采取空间上讨巧的方式来练习。
- 注意：这些题目往往难度标为"简单"，是因为用容器解决真的很简单；但是不用容器、实现额外空间复杂度 O(1) 的方法并不轻松，包括很多提交的答案也都没有符合要求。
- 链表相关的比较难的问题是约瑟夫环问题，会在【扩展】阶段单独讲解。
- 本节课 6 道题：①两个无环链表相交的第一个节点；②每 k 个节点一组翻转链表；③复制带随机指针的链表；④判断链表是否是回文结构；⑤返回链表的第一个入环节点；⑥链表排序（O(n*logn) 时间、O(1) 额外空间、有稳定性）。
## 二、题目1：返回两个无环链表相交的第一个节点（LeetCode 160）
- 测试链接：https://leetcode.cn/problems/intersection-of-two-linked-lists/
- 思路（长度差法）：
  - 1）分别遍历两个链表到尾部，用 diff 记录长度差（链表1每走一步 diff++，链表2每走一步 diff--）。
  - 2）如果两个尾节点不是同一个节点，说明不相交，返回 null。
  - 3）让较长的链表头指针先走 |diff| 步，然后两个指针同步走，第一个相遇的节点就是相交的第一个节点。
- 图示：
```text
链表1: a1 -> a2 -> c1 -> c2 -> c3        长度 = 5
链表2:       b1 -> c1 -> c2 -> c3        长度 = 4
diff = 5 - 4 = 1，链表1先走1步到 a2，再同步走：
a2 vs b1 -> c1 vs c1（相遇！返回 c1）
```
```java
public static ListNode getIntersectionNode(ListNode h1, ListNode h2) {
    if (h1 == null || h2 == null) {
        return null;
    }
    ListNode a = h1, b = h2;
    int diff = 0;
    while (a.next != null) { a = a.next; diff++; }
    while (b.next != null) { b = b.next; diff--; }
    if (a != b) {
        return null; // 尾节点不同，不相交
    }
    if (diff >= 0) { a = h1; b = h2; } else { a = h2; b = h1; } // a指向长链表
    diff = Math.abs(diff);
    while (diff-- != 0) { a = a.next; } // 长链表先走差值步
    while (a != b) { a = a.next; b = b.next; } // 同步走，相遇即答案
    return a;
}
```
- 复杂度：时间 O(n)，额外空间 O(1)。
- 扩展（另一种经典写法，双指针浪漫相遇）：指针 a 走完链表1后接着走链表2，指针 b 走完链表2后接着走链表1，两指针走的总路程相等（len1+len2），必在交点相遇（或同时到 null）。代码极短但理解稍绕，笔试用长度差法更稳。
## 三、题目2：每 k 个节点一组翻转链表（LeetCode 25，K 个一组翻转链表）
- 测试链接：https://leetcode.cn/problems/reverse-nodes-in-k-group/
- 思路（分组 + 组内翻转 + 组间串接）：
  - 1）每次从 start 往下数 k 个找到本组结尾 end，不足 k 个直接返回（不翻转）。
  - 2）第一组特殊：翻转后涉及换头，head 要指向第一组的 end。
  - 3）reverse(start, end) 把 start..end 这一段翻转，并且让 start.next 指向下一组的开头（翻转后 start 变成组尾）。
  - 4）用 lastTeamEnd（上一组的结尾）把各组串起来：lastTeamEnd.next = 本组翻转后的头（end），然后 lastTeamEnd 更新为本组翻转后的尾（start）。
- 图示（k=3）：
```text
原链表: 1 -> 2 -> 3 -> 4 -> 5
第一组翻转: 3 -> 2 -> 1 -> 4 -> 5   (lastTeamEnd = 1)
第二组不足k个(只剩4->5)，直接结束
```
```java
public static ListNode reverseKGroup(ListNode head, int k) {
    ListNode start = head;
    ListNode end = teamEnd(start, k);
    if (end == null) {
        return head; // 第一组都不够k个
    }
    head = end; // 第一组很特殊因为牵扯到换头的问题
    reverse(start, end);
    ListNode lastTeamEnd = start; // 翻转之后start变成了上一组的结尾节点
    while (lastTeamEnd.next != null) {
        start = lastTeamEnd.next;
        end = teamEnd(start, k);
        if (end == null) {
            return head; // 剩余不足k个，保持原样
        }
        reverse(start, end);
        lastTeamEnd.next = end; // 上一组结尾接本组新头
        lastTeamEnd = start;    // 本组新尾成为上一组结尾
    }
    return head;
}
// 当前组的开始节点是s，往下数k个找到当前组的结束节点返回（不够返回null）
public static ListNode teamEnd(ListNode s, int k) {
    while (--k != 0 && s != null) { s = s.next; }
    return s;
}
// s -> a -> b -> c -> e -> 下一组开始  调整成  e -> c -> b -> a -> s -> 下一组开始
public static void reverse(ListNode s, ListNode e) {
    e = e.next;
    ListNode pre = null, cur = s, next = null;
    while (cur != e) {
        next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    s.next = e; // 组尾接下一组开头
}
```
- 复杂度：时间 O(n)，额外空间 O(1)（纯迭代，不用递归栈）。
## 四、题目3：复制带随机指针的链表（LeetCode 138）
- 测试链接：https://leetcode.cn/problems/copy-list-with-random-pointer/
- 思路（不用哈希表、O(1) 额外空间的经典三步法）：
  - 1）穿插复制：遍历老链表，把每个节点的拷贝节点插到自己后面：1 -> 2 -> 3 变成 1 -> 1' -> 2 -> 2' -> 3 -> 3'。
  - 2）设置 random：利用"新节点 = 老节点.next"的结构关系，copy.random = cur.random.next（老节点 random 指向谁，新节点的 random 就指向谁的拷贝）。
  - 3）分离：老链表重新连在一起，新链表重新连在一起，返回新链表头。
- 图示：
```text
步骤1后: 1 -> 1' -> 2 -> 2' -> 3 -> 3'
步骤2:   若 1.random = 3，则 1'.random = 1.random.next = 3'
步骤3:   老: 1 -> 2 -> 3   新: 1' -> 2' -> 3' 返回1'
```
```java
public static Node copyRandomList(Node head) {
    if (head == null) {
        return null;
    }
    Node cur = head, next = null;
    // 1 -> 2 -> 3 变成 1 -> 1' -> 2 -> 2' -> 3 -> 3'
    while (cur != null) {
        next = cur.next;
        cur.next = new Node(cur.val);
        cur.next.next = next;
        cur = next;
    }
    // 利用新老节点的结构关系，设置每一个新节点的random指针
    cur = head;
    Node copy = null;
    while (cur != null) {
        next = cur.next.next;
        copy = cur.next;
        copy.random = cur.random != null ? cur.random.next : null;
        cur = next;
    }
    // 新老链表分离
    Node ans = head.next;
    cur = head;
    while (cur != null) {
        next = cur.next.next;
        copy = cur.next;
        cur.next = next;
        copy.next = next != null ? next.next : null;
        cur = next;
    }
    return ans;
}
```
- 复杂度：时间 O(n)，额外空间 O(1)（不计返回值占用的空间）。如果用哈希表建立 老节点->新节点 的映射也能做，但要 O(n) 额外空间，面试优先写这个三步法。
## 五、题目4：判断链表是否是回文结构（LeetCode 234）
- 测试链接：https://leetcode.cn/problems/palindrome-linked-list/
- 备注：这个题的流程设计甚至是考研常用。快慢指针找中点。
- 思路（快慢指针找中点 + 右半逆序 + 双头比对 + 恢复现场）：
  - 1）快慢指针找中点：fast 每次走 2 步、slow 每次走 1 步，fast 走不动时 slow 就是中点。
  - 2）从中点往后的节点逆序，链表变成从左右两侧往中间指：head -> ... -> slow <- ... <- pre。
  - 3）left 从 head 往右、right 从 pre 往左，每一步比对值，不一样就是 false。
  - 4）本着不坑的原则，把右半部分再逆序回去，恢复链表原样后返回答案。
- 图示：
```text
1 -> 2 -> 3 -> 2 -> 1
找中点slow=3，右半逆序: 1 -> 2 -> 3 <- 2 <- 1(pre)
left=1(左头) right=1(右头) 逐位比对: 1=1, 2=2, 然后left/right到null结束 -> true
```
```java
public static boolean isPalindrome(ListNode head) {
    if (head == null || head.next == null) {
        return true;
    }
    ListNode slow = head, fast = head;
    // 找中点
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // 从中点开始往后的节点逆序
    ListNode pre = slow;
    ListNode cur = pre.next;
    ListNode next = null;
    pre.next = null;
    while (cur != null) {
        next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    // head -> ... -> slow <- ... <- pre，左右往中间比对
    boolean ans = true;
    ListNode left = head, right = pre;
    while (left != null && right != null) {
        if (left.val != right.val) {
            ans = false;
            break;
        }
        left = left.next;
        right = right.next;
    }
    // 恢复现场：把右半部分逆序回去
    cur = pre.next;
    pre.next = null;
    next = null;
    while (cur != null) {
        next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    return ans;
}
```
- 复杂度：时间 O(n)，额外空间 O(1)。用栈的容器做法要 O(n) 空间，面试必须会这个 O(1) 版本。
## 六、题目5：返回链表的第一个入环节点（LeetCode 142，环形链表 II）
- 测试链接：https://leetcode.cn/problems/linked-list-cycle-ii/
- 思路（快慢指针，Floyd 判圈）：
  - 1）slow 每次走 1 步、fast 每次走 2 步。fast 走到 null 说明无环，返回 null。
  - 2）如果 slow == fast 相遇，说明有环。此时把 fast 放回 head，接下来 slow 和 fast 都每次只走 1 步，再次相遇的节点就是第一个入环节点。
- 为什么第二段相遇点一定是入环口（记住结论即可，证明很简单）：
```text
设 head 到入环口距离 = a，入环口到相遇点距离 = b，相遇点绕回入环口距离 = c（环长 = b+c）
相遇时: slow走了 a+b，fast走了 a+b + k*(b+c)，且 fast 路程 = 2 * slow 路程
=> a+b = k*(b+c) => a = (k-1)*(b+c) + c
即：从 head 走 a 步 = 从相遇点绕 k-1 圈再走 c 步，都到入环口
所以一个指针从 head、一个从相遇点，同速走必在入环口相遇
```
```java
public static ListNode detectCycle(ListNode head) {
    if (head == null || head.next == null || head.next.next == null) {
        return null;
    }
    ListNode slow = head.next;
    ListNode fast = head.next.next;
    while (slow != fast) {
        if (fast.next == null || fast.next.next == null) {
            return null; // 无环
        }
        slow = slow.next;
        fast = fast.next.next;
    }
    fast = head; // 有环：fast回头，双速变同速
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow; // 第一个入环节点
}
```
- 复杂度：时间 O(n)，额外空间 O(1)。
## 七、题目6：排序链表（LeetCode 148）—— O(n*logn) 时间 + O(1) 额外空间 + 稳定性
- 测试链接：https://leetcode.cn/problems/sort-list/
- 要求：时间复杂度 O(n*logn)，额外空间复杂度 O(1)，还要求稳定性。数组排序做不到（快排不稳定、堆排不稳定、归并要 O(n) 空间），链表排序可以做到！
- 思路（自底向上的非递归归并排序）：
  - 1）先数出链表长度 n。
  - 2）step 从 1 开始每次乘 2：把链表按 step 长度切成 左段[l1..r1] 和 右段[l2..r2]，两段各自已有序（上一轮保证），merge 成一组有序段，再把各组串起来。
  - 3）为了额外空间 O(1) 不能使用递归（mergeSort 递归需要 O(log n) 的栈空间），所以用步长倍增的迭代写法。
  - 4）稳定性来自 merge 时相等元素先取左段（l1.val <= l2.val 取左）。
  - 5）细节：merge 前要把 r1.next 和 r2.next 断成 null；用全局变量 start/end 记录 merge 后的头尾，方便上一组的尾巴 lastTeamEnd 接上来。
- 图示（step 倍增过程，以 4->3->1->2 为例）：
```text
step=1: [4][3][1][2] -> merge(4,3)->3->4, merge(1,2)->1->2  得 3->4->1->2
step=2: [3->4][1->2] -> merge -> 1->2->3->4
step=4 >= n，结束
```
```java
public static ListNode sortList(ListNode head) {
    int n = 0;
    ListNode cur = head;
    while (cur != null) { n++; cur = cur.next; }
    // l1...r1 每组左部分；l2...r2 每组右部分；next 下一组开头；lastTeamEnd 上一组结尾
    ListNode l1, r1, l2, r2, next, lastTeamEnd;
    for (int step = 1; step < n; step <<= 1) {
        // 第一组很特殊，因为要决定整个链表的头，所以单独处理
        l1 = head;
        r1 = findEnd(l1, step);
        l2 = r1.next;
        r2 = findEnd(l2, step);
        next = r2.next;
        r1.next = null;
        r2.next = null;
        merge(l1, r1, l2, r2);
        head = start;
        lastTeamEnd = end;
        while (next != null) {
            l1 = next;
            r1 = findEnd(l1, step);
            l2 = r1.next;
            if (l2 == null) { // 只剩一段，直接接上
                lastTeamEnd.next = l1;
                break;
            }
            r2 = findEnd(l2, step);
            next = r2.next;
            r1.next = null;
            r2.next = null;
            merge(l1, r1, l2, r2);
            lastTeamEnd.next = start;
            lastTeamEnd = end;
        }
    }
    return head;
}
// 包括s在内往下数k个节点返回；如果不够，返回最后一个数到的非空节点
public static ListNode findEnd(ListNode s, int k) {
    while (s.next != null && --k != 0) { s = s.next; }
    return s;
}
public static ListNode start;
public static ListNode end;
// l1...r1 -> null 有序左部分，l2...r2 -> null 有序右部分
// merge在一起保证有序，并把全局变量start设置为整体的头、end设置为整体的尾
public static void merge(ListNode l1, ListNode r1, ListNode l2, ListNode r2) {
    ListNode pre;
    if (l1.val <= l2.val) { start = l1; pre = l1; l1 = l1.next; }
    else { start = l2; pre = l2; l2 = l2.next; }
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { pre.next = l1; pre = l1; l1 = l1.next; } // <=取左边，保证稳定性
        else { pre.next = l2; pre = l2; l2 = l2.next; }
    }
    if (l1 != null) { pre.next = l1; end = r1; }
    else { pre.next = l2; end = r2; }
}
```
- 复杂度：时间 O(n*logn)，额外空间 O(1)，有稳定性。
## 八、本节课一句话总结
- 链表题核心考 coding 而不是算法设计，空间要求严格时必须会 O(1) 额外空间的做法，最常用技巧是快慢指针。
- 相交链表：算长度差，长链表先走差值再同步走；回文链表：快慢指针找中点 + 右半逆序 + 比对 + 恢复现场。
- 入环节点：快慢指针相遇后，一个回 head、同速再相遇即入环口（Floyd 判圈）。
- 复制随机指针链表：老新节点穿插 -> 用 next 关系设 random -> 分离，三步 O(1) 空间代替哈希表。
- K 个一组翻转与链表归并排序：都是"分组处理 + 上一组尾巴串下一组"的套路，链表归并排序是 O(n*logn) + O(1) 空间 + 稳定排序的唯一经典解。
