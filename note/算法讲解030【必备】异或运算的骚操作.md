## 一、开场陷阱题：黑白球问题
- 题目：袋子里一共 a 个白球、b 个黑球，每次从袋子里拿 2 个球（机会均等）。
  - 如果拿出 2 白或 2 黑，放回 1 个白球；
  - 如果拿出 1 白 1 黑，放回 1 个黑球。
  - 最终袋子里一定只剩 1 个球，问最终是黑球的概率（用 a、b 表达）。
- 答案：黑球数量是偶数 -> 黑球概率 0%；黑球数量是奇数 -> 黑球概率 100%。和白球数量完全无关！
- 为什么？用异或理解：白球记 0、黑球记 1，考察袋中所有球的异或和。
  - 拿出 2 白放回 1 白：0^0 -> 0，异或和不变；
  - 拿出 2 黑放回 1 白：1^1 -> 0，异或和不变；
  - 拿出 1 白 1 黑放回 1 黑：0^1 -> 1，异或和不变。
  - 即每次操作都不改变整体异或和（异或和是本过程的"不变量"）。
- 最后只剩 1 个球时，异或和就等于这个球的颜色：黑球个数为偶数则异或和为 0（白球），为奇数则异或和为 1（黑球）。所以概率只会是 0% 或 100%。
## 二、异或运算的 4 条性质
- 性质1：异或运算就是无进位相加（二进制每一位独立相加，不进位）。
- 性质2：满足交换律、结合律。同一批数字不管异或顺序是什么，最终结果都一样（可以由性质1推出：每个二进制位上 1 的个数是奇数则该位为 1）。
- 性质3：0 ^ n = n；n ^ n = 0。出现偶数次的数异或后全部抵消。
- 性质4：整体异或和是 x，其中某部分的异或和是 y，那么剩下部分的异或和是 x ^ y。利用"区间异或和"的题目最多，前缀异或和就是它的典型应用。
- 最重要的结论就是性质1，其他结论都能由它推出。
- 预告：Nim 博弈也是和异或运算相关的算法，将在后续【必备】课程里讲到。
## 三、Brian Kernighan 算法：提取最右侧的 1
- 公式：rightOne = n & (-n) 或 n & (~n + 1)。
- 原理：-n 等于 ~n + 1（补码定义），取反加一之后，n 最右侧的 1 及其右边的 0 不变，左边全部变反，相与之后只剩最右侧的 1。
- 示例：n = 0b0101100，则 rightOne = 0b0000100。
```java
int rightOne = eor & (-eor);
```
## 四、题目1：用异或交换两个数（Code01）
- 三连异或即可交换，不用临时变量。本质是：a^b 相当于"差异记录"，再异或一次就还原出对方。
- 坑：当 i == j（同一块内存）时会出错，自己把自己抹成 0。所以知道这种写法即可，并不推荐，面试聊起来能讲清楚即可。
```java
// 当i!=j，没问题，会完成交换功能
// 当i==j，会出错（同一块内存被异或成0）
// 所以知道这种写法即可，并不推荐
public static void swap(int[] arr, int i, int j) {
    arr[i] = arr[i] ^ arr[j];
    arr[j] = arr[i] ^ arr[j];
    arr[i] = arr[i] ^ arr[j];
}
```
## 五、题目2：不用判断和比较，返回两数最大值（Code02）
- 测试链接：https://www.nowcoder.com/practice/d2707eaf98124f1e8f1d9c18ad487f76
- 基础件：flip(n) 把 0 变 1、1 变 0；sign(n) 非负返回 1、负数返回 0（取符号位再 flip）。
- 思路一（有溢出风险）：c = a - b，c 非负就返回 a，否则返回 b。用 returnA/returnB 两个系数 0/1 来"选择"返回值，全程无 if。
- 思路二（正确版）：c = a - b 可能溢出（如 a 是 Integer.MIN_VALUE，b 是 Integer.MAX_VALUE），导致 c 的符号不可信。补救：a、b 符号不同（diffAB=1）时直接信 a 的符号（a 非负则 a 大）；符号相同（sameAB=1）时不会溢出，信 c 的符号。
```java
public static int flip(int n) { return n ^ 1; }        // 0变1，1变0
public static int sign(int n) { return flip(n >>> 31); } // 非负返回1，负数返回0
// 没有任何问题的实现
public static int getMax2(int a, int b) {
    int c = a - b;          // c可能是溢出的
    int sa = sign(a);       // a的符号
    int sb = sign(b);       // b的符号
    int sc = sign(c);       // c的符号
    int diffAB = sa ^ sb;   // 符号不一样diffAB=1，一样diffAB=0
    int sameAB = flip(diffAB);
    int returnA = diffAB * sa + sameAB * sc;
    int returnB = flip(returnA);
    return a * returnA + b * returnB;
}
```
## 六、题目3：找到缺失的数字（Code03）
- 测试链接：https://leetcode.cn/problems/missing-number/（0~n 中缺一个数）
- 思路（性质4的应用）：eorAll 异或 0~n 所有数，eorHas 异或数组中实际存在的数，两者再异或，成对抵消后剩下的就是缺失的数。时间 O(N)，空间 O(1)。
```java
public static int missingNumber(int[] nums) {
    int eorAll = 0, eorHas = 0;
    for (int i = 0; i < nums.length; i++) {
        eorAll ^= i;
        eorHas ^= nums[i];
    }
    eorAll ^= nums.length;
    return eorAll ^ eorHas;
}
```
## 七、题目4：1 种数出现奇数次，其余出现偶数次（Code04）
- 测试链接：https://leetcode.cn/problems/single-number/
- 思路：全部异或，偶数次的数全部 n^n=0 抵消，剩下的就是答案。异或题型的"入门母题"。
```java
public static int singleNumber(int[] nums) {
    int eor = 0;
    for (int num : nums) {
        eor ^= num;
    }
    return eor;
}
```
## 八、题目5：2 种数出现奇数次，其余出现偶数次（Code05）
- 测试链接：https://leetcode.cn/problems/single-number-iii/
- 思路（本题是异或骚操作的经典）：
  - 1）全部异或得 eor1 = a ^ b（a、b 是那两种出现奇数次的数）。因为 a != b，所以 eor1 != 0，即 eor1 至少有一位是 1。
  - 2）用 Brian Kernighan 算法提取 eor1 最右侧的 1：rightOne = eor1 & (-eor1)。这一位为 1 说明 a、b 在这一位上不同。
  - 3）按"这一位是否为 1"把数组分成两组再异或：a、b 必被分到不同组，偶数次的数无论如何分组都会在自己组内抵消，于是其中一组异或出 a（或 b）。
  - 4）另一个数 = eor1 ^ eor2（性质4）。
```java
public static int[] singleNumber(int[] nums) {
    int eor1 = 0;
    for (int num : nums) {
        eor1 ^= num; // eor1 = a ^ b
    }
    // Brian Kernighan算法，提取出二进制里最右侧的1
    int rightOne = eor1 & (-eor1);
    int eor2 = 0;
    for (int num : nums) {
        if ((num & rightOne) == 0) {
            eor2 ^= num; // 这一位是0的数全异或，得到a或b
        }
    }
    return new int[] { eor2, eor1 ^ eor2 };
}
```
- 提醒：C++ 版要写成 unsigned int rightOne = (unsigned int)eor1 & (-(unsigned int)eor1); 避免有符号整数的坑（Code05_DoubleNumber2）。
## 九、题目6：只有 1 种数出现次数少于 m 次，其余都出现 m 次（Code06）
- 测试链接：https://leetcode.cn/problems/single-number-ii/（LeetCode 上只是 m=3 的特例，课上讲的是通用方法）
- 思路：出现次数不是 2 次/偶数次，异或抵消不了，改用"按位计数"。
  - 1）准备 cnts[32]，统计所有数字在每一位上 1 的个数。
  - 2）出现 m 次的数，对每一位的贡献一定是 m 的倍数；所以 cnts[i] % m != 0 的位，一定是由那个"出现次数少于 m 次"的数贡献的，该位就是 1。
  - 3）把这些位拼起来就是答案。时间 O(32*N) 即 O(N)，空间 O(1)（固定 32 长度）。
```java
public static int find(int[] arr, int m) {
    // cnts[i] : i位上有多少个1
    int[] cnts = new int[32];
    for (int num : arr) {
        for (int i = 0; i < 32; i++) {
            cnts[i] += (num >> i) & 1;
        }
    }
    int ans = 0;
    for (int i = 0; i < 32; i++) {
        if (cnts[i] % m != 0) {
            ans |= 1 << i;
        }
    }
    return ans;
}
```
## 十、本节课一句话总结
- 异或 = 无进位相加 -> 交换律结合律 -> 偶数次抵消（n^n=0）、整体减部分（x^y）-> 一套"消消乐"打法解决一切出现次数类问题。
- 三件武器：全员异或（消偶留奇）、n & (-n)（提取最右侧 1 用于分组）、按位计数模 m（处理出现 m 次的泛化情况）。
