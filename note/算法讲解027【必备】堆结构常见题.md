## 题目1：合并K个有序链表
- 测试链接：牛客（https://www.nowcoder.com/practice/65cfde9e5b9b4cf2b6bafa5f3ef33fa6）、LeetCode 23（https://leetcode.cn/problems/merge-k-sorted-lists/）
- 题意：给出 K 个已经排好序（升序）的链表，把它们合并成一个升序链表。
- 思路（小根堆 + 比较器）：
  - 建一个小根堆，堆中放链表节点，按节点值 val 比较（比较器定制优先级）。
  - 把 K 个链表的头节点都放进堆里。堆顶就是所有链表当前剩余节点中的最小值。
  - 每次弹出堆顶节点，接到答案链表尾部；如果该节点还有 next，就把 next 放进堆（相当于这条链表的"新头"参与竞争）。
  - 堆空时合并结束。
- 复杂度：堆中最多 K 个节点，每次弹出/加入 O(log K)；总共 N 个节点，时间复杂度 O(N * log K)，优于两两合并的朴素写法。
```java
public static ListNode mergeKLists(ArrayList<ListNode> arr) {
    // 小根堆，比较器：节点值小的优先级高
    PriorityQueue<ListNode> heap = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode h : arr) {
        // 遍历所有的头！注意空链表不进堆
        if (h != null) {
            heap.add(h);
        }
    }
    if (heap.isEmpty()) {
        return null;
    }
    // 先弹出一个节点，做总头部
    ListNode h = heap.poll();
    ListNode pre = h;
    if (pre.next != null) {
        heap.add(pre.next);
    }
    while (!heap.isEmpty()) {
        ListNode cur = heap.poll();
        pre.next = cur;
        pre = cur;
        if (cur.next != null) {
            heap.add(cur.next);
        }
    }
    return h;
}
```
- 本质：每条链表内部已经有序，所以每条链表只需要让"当前最小节点"进堆竞争即可；弹出一个就补进它的后继，堆里始终只有 K 个候选人。
## 题目2：最多线段重合问题（会议室 II）
- 测试链接：牛客（https://www.nowcoder.com/practice/1ae8d0b6bb4e4bcdbf64ec491f63fc37）、LeetCode 253 会议室 II（https://leetcode.cn/problems/meeting-rooms-ii/）
- 题意：给定 n 条线段 [start, end]（左闭右闭），求最多有多少条线段重合（同一个位置被多少条线段覆盖）。等价于：安排这些会议最少需要几间会议室。
- 思路（排序 + 小根堆）：
  - 把所有线段按开始位置从小到大排序（结束位置无所谓，用比较器排序）。
  - 依次遍历每条线段 line[i]，堆里存放"之前所有还没结束的线段的结束位置"（小根堆，堆顶是最早结束时间）。
  - 堆顶 <= line[i][0]，说明这条线段开始时，之前有线段已经结束了（[1,4]和[4,5]首尾相接不算重合），把堆里所有已结束的线段弹掉。
  - 把当前线段的结束位置加入堆，此时堆的大小就是"当前同时进行的线段数"，全程取最大值即为答案。
- 复杂度：排序 O(n * log n)，每条线段进堆、出堆各一次 O(log n)，总时间 O(n * log n)。
```java
public static int minMeetingRooms(int[][] meeting) {
    int n = meeting.length;
    // 所有线段按开始位置排序
    Arrays.sort(meeting, (a, b) -> a[0] - b[0]);
    // 小根堆，存还没结束的线段的结束位置
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    int ans = 0;
    for (int i = 0; i < n; i++) {
        // 结束时间 <= 当前线段开始时间的，都已经结束，弹出
        while (!heap.isEmpty() && heap.peek() <= meeting[i][0]) {
            heap.poll();
        }
        heap.add(meeting[i][1]);
        ans = Math.max(ans, heap.size());
    }
    return ans;
}
```
- 笔试提效：牛客提交版用手写小根堆（数组 + add/pop/heapify）替代 PriorityQueue，常数更小，并配合 StreamTokenizer + PrintWriter 的高效输入输出（参考 Code02_MaxCover.java）。
- 细节辨析：LeetCode 2406 将区间分组的最少组数（https://leetcode.cn/problems/divide-intervals-into-minimum-number-of-groups/）几乎一样，但它认为 [1,4]、[4,5] 在 4 处有重合，所以弹堆条件要改成严格小于：
```java
// 注意这里的判断：heap.peek() < meeting[i][0] 才弹出
// 即结束位置 == 开始位置也算重合，不能复用
while (!heap.isEmpty() && heap.peek() < meeting[i][0]) {
    heap.poll();
}
```
## 题目3：将数组和减半的最少操作次数
- 测试链接：LeetCode 2208（https://leetcode.cn/problems/minimum-operations-to-halve-array-sum/）
- 题意：每次操作可以把数组中任意一个数变成它的一半，求使数组整体累加和减少至少一半的最少操作次数。
- 思路（贪心 + 大根堆）：
  - 贪心结论：每次都减半当前数组中最大的数，一定最优。因为操作次数固定时，每次砍最大的数才能让累加和下降得最快，任何其他选择都可以交换成砍最大数而不更差。
  - 实现：所有数进大根堆，算出目标 sum/2；反复弹出堆顶最大值，减半后放回堆，累计减少量 minus，直到 minus >= sum/2，返回操作次数。
### 写法一：PriorityQueue + Double（直观版）
```java
public static int halveArray1(int[] nums) {
    // 大根堆，比较器定制：b.compareTo(a)
    PriorityQueue<Double> heap = new PriorityQueue<>((a, b) -> b.compareTo(a));
    double sum = 0;
    for (int num : nums) {
        heap.add((double) num);
        sum += num;
    }
    // sum，整体累加和，-> 要减少的目标！
    sum /= 2;
    int ans = 0;
    for (double minus = 0, cur; minus < sum; ans++, minus += cur) {
        cur = heap.poll() / 2;
        heap.add(cur);
    }
    return ans;
}
```
### 写法二：手写大根堆 + 整数缩放（避免浮点误差，性能更好）
- 浮点数反复除以 2 可能有精度问题，可以把每个数左移 20 位（乘以 2^20）变成整数再操作。因为每次减半相当于右移一位，整数右移的截断误差在放大 2^20 倍后不会影响最终结果，从而把 double 运算变成精确的 long 运算。
- 另一个技巧：不需要"弹出堆顶再加回"，直接把堆顶 heap[0] 减半后 heapify(0) 向下调整即可，省一次操作。
```java
public static int halveArray2(int[] nums) {
    size = nums.length;
    long sum = 0;
    // 从底到顶建大根堆 O(n)，每个数放大2^20倍变整数
    for (int i = size - 1; i >= 0; i--) {
        heap[i] = (long) nums[i] << 20;
        sum += heap[i];
        heapify(i);
    }
    sum /= 2;
    int ans = 0;
    for (long minus = 0; minus < sum; ans++) {
        heap[0] /= 2;      // 堆顶最大值直接减半
        minus += heap[0];  // 减少的量就是减半后丢掉的那一半
        heapify(0);        // 向下调整，维持大根堆
    }
    return ans;
}
```
- 复杂度：建堆 O(n)，每次操作 O(log n)，最多操作次数远小于 n 级别，整体非常快。
## 总结：什么时候想到用堆
- 需要动态维护"当前最值"（最大/最小），并且数据不断进出：合并K个有序链表（当前各链表的最小头节点）、线段重合（当前最早结束时间）、减半累加和（当前最大数）。
- 配合比较器可以任意定制优先级；笔试场景中手写数组堆（heapInsert/heapify）替代 PriorityQueue 可以压常数；涉及浮点反复减半时可用整数缩放技巧规避精度问题。
