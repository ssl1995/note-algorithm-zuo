## 一、题目1：接头密匙（Code01_CountConsistentKeys）
- 题意：密匙是一组数字序列，密匙 b 与密匙 a "一致"的条件：b 的长度不超过 a 的长度，且对任意 0 <= i < length(b)，有 `b[i+1] - b[i] == a[i+1] - a[i]`。给定 m 个密匙 b 和 n 个密匙 a，返回长度为 m 的数组 ans，ans[i] 表示 b[i] 与多少个 a 一致。
- 数据量：数组 a、b 的元素个数均不超过 10^5（代码注释），1 <= m, n（单个密匙长度 <= 1000 级别）。测试链接：https://www.nowcoder.com/practice/c552d3b4dfda49ccb883a6371d9a6932
- **关键观察**：一致的条件只和"相邻差值序列"有关，且 b 的差值序列只要是 a 的差值序列的**前缀**即可 → 天然的"前缀查询"场景，上前缀树！
- **转化技巧**：把每个密匙转成"差值字符串"。例如 `[3, 6, 50, 10]` → 差值为 3、44、-40 → 拼成 `"3#44#-40#"`。注意必须加分隔符 `#`，否则 "1#11#" 和 "11#1#" 会混淆（不加分隔符都会拼成 "111"）；差值可能为负，所以字符集里还要有 `-`。
- 建树细节：这棵树只有 `pass` 没有 `end`——插入 a 的差值串时沿途 pass++；查询 b 的差值串能走到哪个节点，该节点的 pass 就是"有多少个 a 以它为前缀"，即答案。
- 路的可能性有 12 种：'0'~'9' 映射到 0~9，'#' 映射到 10，'-' 映射到 11，所以 `tree[MAXN][12]`：
```java
// '0' ~ '9' -> 0~9 ; '#' -> 10 ; '-' -> 11
public static int path(char cha) {
    if (cha == '#') {
        return 10;
    } else if (cha == '-') {
        return 11;
    } else {
        return cha - '0';
    }
}
```
- 主流程：先 `build()`，把所有 a 的差值串 insert 进树；再逐个查询 b 的差值串，用 `count`（沿 pre 走到底返回 pass）收集答案；最后 `clear()`：
```java
public static int[] countConsistentKeys(int[][] b, int[][] a) {
    build();
    StringBuilder builder = new StringBuilder();
    // [3,6,50,10] -> "3#44#-40#"
    for (int[] nums : a) {
        builder.setLength(0);
        for (int i = 1; i < nums.length; i++) {
            builder.append(nums[i] - nums[i - 1]).append("#");
        }
        insert(builder.toString());
    }
    int[] ans = new int[b.length];
    for (int i = 0; i < b.length; i++) {
        builder.setLength(0);
        int[] nums = b[i];
        for (int j = 1; j < nums.length; j++) {
            builder.append(String.valueOf(nums[j] - nums[j - 1])).append("#");
        }
        ans[i] = count(builder.toString());
    }
    clear();
    return ans;
}
```
- 插入和查询就是标准静态数组前缀树，区别只是路用 `path()` 函数映射：
```java
public static void insert(String word) {
    int cur = 1;
    pass[cur]++;
    for (int i = 0, path; i < word.length(); i++) {
        path = path(word.charAt(i));
        if (tree[cur][path] == 0) {
            tree[cur][path] = ++cnt;
        }
        cur = tree[cur][path];
        pass[cur]++;
    }
}
public static int count(String pre) {
    int cur = 1;
    for (int i = 0, path; i < pre.length(); i++) {
        path = path(pre.charAt(i));
        if (tree[cur][path] == 0) {
            return 0;
        }
        cur = tree[cur][path];
    }
    return pass[cur];
}
```
- 复杂度（PPT 给出）：时间 O(a数组的数字个数 * 10) + O(b数组的数字个数 * 10)，空间 O(a数组的数字个数 * 10)（即树上节点数量）。每个密匙长度有限，差值串长度约为密匙长度的常数倍，所以总体是线性级别。
- 本题启示：① 题目条件可以**转化**（原序列 → 差值序列）后再匹配前缀树模型；② 拼接字符串时**分隔符必不可少**；③ 前缀树的"字符集"可以是任意有限集合，自定义映射函数即可。
## 二、题目2：数组中两个数的最大异或值（Code02_TwoNumbersMaximumXor）
- 题意：整数数组 nums，返回 `nums[i] XOR nums[j]` 的最大值（0 <= i <= j <= n，可以选同一个数）。LeetCode 421，测试链接：https://leetcode.cn/problems/maximum-xor-of-two-numbers-in-an-array/
- 数据量：1 <= nums.length <= 2 * 10^5，0 <= nums[i] <= 2^31 - 1。O(n^2) 暴力 4*10^10 必然超时。
- 时间/空间复杂度：O(n * logV)，V 是数值范围（logV ≈ 31）。
### 方法1：01 字典树（好想，推荐）
- 核心思想（上节课预告的"按位建树"）：把每个整数的二进制位**从高位到低位**看成 01 字符串，建一棵每个节点只有 0、1 两条路的前缀树（`tree[MAXN][2]`）。这棵树不需要 pass/end，只用来判断"某条位路径是否存在"。
- 查询 num 的最大异或值时，从最高位开始**贪心**：当前位是 `status`，最希望走相反的路 `want = status ^ 1`（异或出 1）；如果树里没有这条路，才退而求其次走相同的路（异或出 0）。**高位异或出 1 的收益大于所有低位全为 1**，所以贪心正确。
- 一个实用优化：先找数组最大值，用 `Integer.numberOfLeadingZeros` 算出它的最高有效位 `high`，忽略所有数共同的前导 0，只从 `high` 位开始建树和查询，省常数时间：
```java
public static void build(int[] nums) {
    cnt = 1;
    int max = Integer.MIN_VALUE;
    for (int num : nums) {
        max = Math.max(num, max);
    }
    // 数组最大值的二进制有多少个前导0，可以忽略，从high位开始考虑
    high = 31 - Integer.numberOfLeadingZeros(max);
    for (int num : nums) {
        insert(num);
    }
}
public static void insert(int num) {
    int cur = 1;
    for (int i = high, path; i >= 0; i--) {
        path = (num >> i) & 1;
        if (tree[cur][path] == 0) {
            tree[cur][path] = ++cnt;
        }
        cur = tree[cur][path];
    }
}
```
- 贪心查询（本题最核心的代码）：
```java
public static int maxXor(int num) {
    int ans = 0;   // 最终异或的结果(尽量大)
    int cur = 1;   // 前缀树目前来到的节点编号
    for (int i = high, status, want; i >= 0; i--) {
        status = (num >> i) & 1; // num第i位的状态
        want = status ^ 1;       // num第i位希望遇到的状态(相反位)
        if (tree[cur][want] == 0) { // 前缀树里没有相反的路
            want ^= 1;              // 只能走相同的路
        }
        ans |= (status ^ want) << i; // 这一位实际能异或出的值
        cur = tree[cur][want];
    }
    return ans;
}
```
- 主流程：`build(nums)` 后，对每个 num 调 `maxXor(num)` 取最大（i = j 合法，所以不用先把 num 从树里删掉，直接全部建好再查即可）；最后 `clear()`。静态空间 MAXN = 3000001 是"实验出来的"，数据规模升级就改大。
### 方法2：哈希表（难想，了解）
- 逐位确定答案：从高位到低位，假设 `ans` 已确定 i+1 以上的位，尝试让第 i 位也为 1（目标 `better = ans | (1 << i)`）。把所有数"只保留 i 及以上位"的前缀放进 HashSet；若存在两个前缀 a、b 使 `a ^ b = better`，则第 i 位可以达成。利用异或性质 `a ^ b = better <=> b = better ^ a`，边放边查 `set.contains(better ^ num)` 即可：
```java
public int findMaximumXOR2(int[] nums) {
    int max = Integer.MIN_VALUE;
    for (int num : nums) {
        max = Math.max(num, max);
    }
    int ans = 0;
    HashSet<Integer> set = new HashSet<>();
    for (int i = 31 - Integer.numberOfLeadingZeros(max); i >= 0; i--) {
        int better = ans | (1 << i);       // 尝试让第i位变成1
        set.clear();
        for (int num : nums) {
            num = (num >> i) << i;         // 只保留 i 及以上位（前缀）
            set.add(num);
            // num ^ 某状态 = better  <=>  某状态 = better ^ num
            if (set.contains(better ^ num)) {
                ans = better;
                break;
            }
        }
    }
    return ans;
}
```
- 两种方法对比：复杂度同为 O(n * logV)；01 字典树**好想好写**、是通用套路（还能扩展成"与 x 异或最大的数""第 k 大异或值"等问题）；哈希表法省空间但思维难度高，了解即可。
## 三、题目3：单词搜索 II（Code03_WordSearchII）
- 题意：m x n 二维字符网格 board 和一个单词列表 words，返回所有能在网格中拼出的单词。单词由**水平或垂直相邻**的单元格按顺序构成，同一单元格在一个单词中不能重复使用。LeetCode 212，测试链接：https://leetcode.cn/problems/word-search-ii/
- 数据量：1 <= m, n <= 12；1 <= words.length <= 3 * 10^4；1 <= words[i].length <= 10。
- 朴素思路：以每个格子为起点做 DFS 回溯（4 个方向、最深 10 层、走过置标记防回头），每拼出一个串就查它在不在 words 里。时间复杂度 O(m * n * 4^10)。
- **前缀树的作用**：PPT 强调——**不管用不用前缀树，复杂度都是 O(m * n * 4^10)，前缀树只是大量剪枝、优化常数时间**。具体剪枝点：DFS 每走到一个格子，就同步在前缀树上走一步（`t = tree[t][road]`），如果对应节点的 `pass == 0`，说明**没有任何 words 中的单词以当前路径为前缀**，整条分支直接砍掉（`return 0`），不用白走。
- 建树定制：`end[i]` 不再是计数，而是直接存**字符串本身**（`end[cur] = word`），这样 DFS 走到结尾节点时能立刻拿到单词加入答案，且置 null 后不会重复收集：
```java
public static void build(String[] words) {
    cnt = 1;
    for (String word : words) {
        int cur = 1;
        pass[cur]++;
        for (int i = 0, path; i < word.length(); i++) {
            path = word.charAt(i) - 'a';
            if (tree[cur][path] == 0) {
                tree[cur][path] = ++cnt;
            }
            cur = tree[cur][path];
            pass[cur]++;
        }
        end[cur] = word; // 结尾节点直接挂单词
    }
}
```
- DFS 全流程（递归 + 回溯 + 前缀树剪枝）：
```java
// i,j : 此时来到的格子位置；t : 前缀树的节点编号
// 返回值 : 从当前位置出发，一共收集到了几个字符串
public static int dfs(char[][] board, int i, int j, int t, List<String> ans) {
    // 越界 或者 走了回头路，直接返回0
    if (i < 0 || i == board.length || j < 0 || j == board[0].length || board[i][j] == 0) {
        return 0;
    }
    char tmp = board[i][j];   // 用tmp记录当前字符
    int road = tmp - 'a';     // 路的编号: a->0, b->1, ..., z->25
    t = tree[t][road];
    if (pass[t] == 0) {       // 没有任何单词以当前路径为前缀，剪枝！
        return 0;
    }
    int fix = 0;              // 从当前i,j位置出发，收集到了几个字符串
    if (end[t] != null) {     // 当前节点是某个单词的结尾
        fix++;
        ans.add(end[t]);
        end[t] = null;        // 置空，同一个单词不重复收集
    }
    board[i][j] = 0;          // 改成0，后续过程不可以再来到i,j位置（防回头）
    fix += dfs(board, i - 1, j, t, ans);
    fix += dfs(board, i + 1, j, t, ans);
    fix += dfs(board, i, j - 1, t, ans);
    fix += dfs(board, i, j + 1, t, ans);
    pass[t] -= fix;           // 已收集fix个，沿途pass减掉（后续起点不再走无效分支）
    board[i][j] = tmp;        // 恢复现场
    return fix;
}
```
- 三个精妙细节：
  1. **走格子和走树同步**：DFS 参数带上前缀树节点编号 t，每走一步格子就在树上走一步，剪枝条件是 O(1) 的；
  2. **`end[t]` 置 null 去重**：同一单词可能被多条路径拼出，收集一次后删掉标记；
  3. **回溯时 `pass[t] -= fix`**：把"已经收集掉的单词"从树的 pass 计数里减掉，让后续其他起点的 DFS 剪枝越来越狠——越搜越快。
- 主流程：`build(words)` 建树后，从每个格子 `(i, j)` 出发调 `dfs(board, i, j, 1, ans)`（1 是 root 编号），最后 `clear()`。
- 复杂度：时间 O(m * n * 4^10)（前缀树只优化常数），空间 O(words 中所有字符串的全部字符数量)（即树上的节点数）。
## 四、扩充：前缀树解题的通用套路总结
- **什么时候想到前缀树**：题目出现"前缀"二字（前缀匹配、前缀统计、公共前缀），或者需要反复判断"当前串是不是某个集合里某串的前缀/开头"，或者涉及**逐位贪心**（如异或最大/最小、字典序最大）时，优先考虑。
- **建模三部曲**：
  1. **定字符集和路的映射**：小写字母 26 路、数字 10 路、本题"差值串"12 路（含 '#'、'-'）、二进制位 2 路（01 字典树）。字符集大时用哈希表存路，或像 01 字典树一样**按位拆**把路压到 2 条；
  2. **定节点信息**：pass（前缀计数）、end（单词计数或直接挂单词）、甚至不存任何信息只判断存在性（题目2）；
  3. **定查询方式**：走到底看 end（精确匹配）、走到底看 pass（前缀统计）、逐位贪心选路（异或最值）、DFS 同步走树（网格剪枝）。
- **相关经典题**（可用于练习）：LeetCode 208 实现 Trie、LeetCode 1804 实现 Trie II、LeetCode 648 单词替换（前缀匹配）、LeetCode 421/1707 最大异或（01 字典树）、LeetCode 212 单词搜索 II、洛谷 P4551 最长异或路径。
- **与哈希表/排序的分工**：只查"整个串在不在"用哈希表即可；涉及**前缀信息**的查询，哈希表无能为力，前缀树不可替代。
## 五、总结
- 题目1（接头密匙）：把数字序列转成带分隔符的**差值字符串**，前缀树做前缀计数；自定义 12 种路的映射；分隔符防止拼接歧义。
- 题目2（最大异或值）：整数按二进制**从高位到低位**建 01 字典树，贪心走相反位得最大异或；用最高有效位 `high` 砍掉前导 0 优化常数；哈希表逐位确定法作为拓展了解。
- 题目3（单词搜索 II）：DFS 与前缀树**同步行走**，`pass == 0` 剪枝；`end` 直接挂单词并置 null 去重；回溯时 `pass -= fix` 让剪枝越来越有效。记住前缀树在这里**不改变复杂度，只优化常数**。
- 三题统一套路：静态数组实现 + 自定义路映射 + 定制节点信息（pass/end），前缀树是"前缀信息查询"和"逐位贪心"场景的利器。

## 六、附录：题目2 中 tree 二维数组的含义详解（以 nums = {12, 2} 为例）
### 6.1 数组的两个维度分别是什么
`Code02_TwoNumbersMaximumXor` 用**静态二维数组**实现 01 字典树（只存 0/1 两种路的前缀树）：

```java
public static int MAXN = 12;
public static int[][] tree = new int[MAXN][2];
```

- **第一维（行下标 i）：节点编号**。`tree[i]` 就是编号为 `i` 的节点。节点编号由全局计数器 `cnt` 分配：根节点固定是 **1 号**，之后每新建一个节点 `++cnt`。
- **第二维（列下标 0 / 1）：两条"路"，分别对应二进制位 0 和位 1**。
  - `tree[i][0]`：从节点 `i` 沿 **bit = 0** 的路走，到达的子节点编号；
  - `tree[i][1]`：从节点 `i` 沿 **bit = 1** 的路走，到达的子节点编号；
  - 存的是**子节点编号**，值 `0` 表示"这条路不存在"（空路）。
- 正因为用 `0` 表示空路，**0 号节点被永久闲置**（`tree[0]` 恒为 `[0, 0]`），真实节点从 1 号开始用。`insert` 和 `maxXor` 里 `cur = 1` 起步就是这个原因。

一句话记忆：**行 = 节点，列 = 二进制位，值 = 孩子节点编号，0 = 没路**。

### 6.2 建树过程推演（nums = {12, 2}）
准备阶段：`max = 12`（二进制 `1100`），`high = 31 - Integer.numberOfLeadingZeros(12) = 3`，即只关心第 3 ~ 0 位，共 4 层；`cnt = 1`（根已占 1 号）。

**插入 12（二进制 1100，从高位到低位逐位走）**，`cur` 从根节点 1 出发：

| 位 i | bit | tree[cur][bit] 为空？ | 操作 | 结果 |
|---|---|---|---|---|
| 3 | 1 | 是 | 分配节点 2 | `tree[1][1] = 2` |
| 2 | 1 | 是 | 分配节点 3 | `tree[2][1] = 3` |
| 1 | 0 | 是 | 分配节点 4 | `tree[3][0] = 4` |
| 0 | 0 | 是 | 分配节点 5 | `tree[4][0] = 5` |

**插入 2（二进制 0010）**，再次从根节点 1 出发：

| 位 i | bit | tree[cur][bit] 为空？ | 操作 | 结果 |
|---|---|---|---|---|
| 3 | 0 | 是 | 分配节点 6 | `tree[1][0] = 6` |
| 2 | 0 | 是 | 分配节点 7 | `tree[6][0] = 7` |
| 1 | 1 | 是 | 分配节点 8 | `tree[7][1] = 8` |
| 0 | 0 | 是 | 分配节点 9 | `tree[8][0] = 9` |

> 注意：如果某个 bit 对应的路**已存在**（`tree[cur][bit] != 0`），就不再新建节点，直接复用走下去——这就是前缀树"共享前缀"的核心。

### 6.3 最终数组逐行对照
`Arrays.deepToString(tree)` 输出：


### 6.4 查询时如何用这个结构（maxXor）
对每个 `num`，从根节点 1 出发逐位贪心：

- `status = (num >> i) & 1`：num 第 i 位的实际值；
- `want = status ^ 1`：**希望**走相反的路（异或出 1，结果更大）；
- 看 `tree[cur][want]`：
  - **不为 0**：理想路存在，走它，该位异或得 1；
  - **为 0**：理想路不存在，退而求其次走 `status` 那条路（`tree[cur][status]` 必然非 0，因为 num 自己就在树里），该位异或得 0。

例如查 12：第 3 位是 1，希望走 0，`tree[1][0] = 6` 存在 → 走节点 6，该位异或出 1；一路走下去最终得到 `1110 = 14`（即 12 ^ 2），就是最大异或值。

### 6.5 要点回顾
1. `tree[i][0]` / `tree[i][1]` 分别是节点 `i` 沿二进制位 0 / 位 1 的子节点编号，**0 表示空路**；
2. 因为 0 当"空"用，**0 号节点闲置，根是 1 号**；
3. 插入时"有路就复用，没路才 `++cnt` 新建"，这是前缀共享的体现；
4. `MAXN` 只需开到"所有数字的有效二进制位总数 + 2"级别即可，课堂 demo 开 12 纯属演示，提交时用 3000001。
