## 一、双端队列的介绍
- 双端队列（Deque，Double Ended Queue）：头部、尾部都可以加入元素、弹出元素的数据结构。
- 常用操作：insertFront / insertLast（头/尾加入）、deleteFront / deleteLast（头/尾弹出）、getFront / getRear（看头/尾）、isEmpty / isFull。
- 队列只能从尾进、从头出，栈只能从顶进出，双端队列是两者的泛化——只从一头进出一头弹就是队列，只在一头进出就是栈。
- 队列、栈、双端队列可以组成非常多重要的数据结构（单调队列、滑动窗口等），将在【必备】课程里继续。
## 二、双端队列用双链表实现
- 双链表天然支持头尾 O(1) 的增删，Java 中 LinkedList 就是双链表，直接实现 Deque 接口。
- 缺点：常数操作慢（每个节点都是对象，有额外的引用开销），但 leetcode 数据量小，看不出劣势。
- 以 LeetCode 641（设计循环双端队列）为例，在双链表基础上加 size/limit 控制容量即可：
```java
class MyCircularDeque1 {
    public Deque<Integer> deque = new LinkedList<>();
    public int size;
    public int limit;
    public MyCircularDeque1(int k) {
        size = 0;
        limit = k;
    }
    public boolean insertFront(int value) {
        if (isFull()) {
            return false;
        }
        deque.offerFirst(value);
        size++;
        return true;
    }
    public boolean insertLast(int value) {
        if (isFull()) {
            return false;
        }
        deque.offerLast(value);
        size++;
        return true;
    }
    public boolean deleteFront() {
        if (isEmpty()) {
            return false;
        }
        size--;
        deque.pollFirst();
        return true;
    }
    public boolean deleteLast() {
        if (isEmpty()) {
            return false;
        }
        size--;
        deque.pollLast();
        return true;
    }
    public int getFront() { return isEmpty() ? -1 : deque.peekFirst(); }
    public int getRear() { return isEmpty() ? -1 : deque.peekLast(); }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == limit; }
}
```
## 三、双端队列用固定数组实现（重点）
- 思路：固定数组 + l、r 两个下标 + size 计数 + limit 容量，下标走到边界就环绕（同讲解013 环形队列）。
- 与环形队列的关键区别：这里 l 指向队头元素、r 指向队尾元素（都指向真实数据，而不是下一个写入位置），因为两头都要读写。
- 核心细节1：为空时插入第一个元素要特判，直接 l = r = 0，deque[0] = value。
- 核心细节2：头插时 l 往前走（l == 0 绕到 limit - 1），尾插时 r 往后走（r == limit - 1 绕到 0）；删除反之。
- 核心细节3：用 size 区分空和满（size == 0 空、size == limit 满），否则 l、r 相邻关系无法判断状态。
```plain
固定数组双端队列（limit = 5，l指向队头，r指向队尾）:
下标:    0    1    2    3    4
       [ 9 | 7 | 5 | 3 | _ ]
                   r    l
头插 insertFront(1): l 往前走一格(环绕到3)，deque[3]=1
尾插 insertLast(x):  r 往后走一格，deque[r]=x
头删 deleteFront():  l 往后走一格，size--
尾删 deleteLast():   r 往前走一格，size--
```
## 四、代码实现（固定数组版，LeetCode 641）
```java
class MyCircularDeque2 {
    public int[] deque;
    public int l, r, size, limit;
    public MyCircularDeque2(int k) {
        deque = new int[k];
        l = r = size = 0;
        limit = k;
    }
    public boolean insertFront(int value) {
        if (isFull()) {
            return false;
        }
        if (isEmpty()) { // 空队列插入第一个数，特判
            l = r = 0;
            deque[0] = value;
        } else {
            l = l == 0 ? (limit - 1) : (l - 1); // l往前走，到头绕回
            deque[l] = value;
        }
        size++;
        return true;
    }
    public boolean insertLast(int value) {
        if (isFull()) {
            return false;
        }
        if (isEmpty()) {
            l = r = 0;
            deque[0] = value;
        } else {
            r = r == limit - 1 ? 0 : (r + 1); // r往后走，到尾绕回
            deque[r] = value;
        }
        size++;
        return true;
    }
    public boolean deleteFront() {
        if (isEmpty()) {
            return false;
        }
        l = (l == limit - 1) ? 0 : (l + 1); // l往后走
        size--;
        return true;
    }
    public boolean deleteLast() {
        if (isEmpty()) {
            return false;
        }
        r = r == 0 ? (limit - 1) : (r - 1); // r往前走
        size--;
        return true;
    }
    public int getFront() { return isEmpty() ? -1 : deque[l]; }
    public int getRear() { return isEmpty() ? -1 : deque[r]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == limit; }
}
```
## 五、总结与易错点
- 双端队列 = 头尾都能增删的队列，是队列和栈的泛化；双链表实现简单，固定数组实现常数时间更优。
- 所有操作都是 O(1)；数组版空间就是固定大小的数组，删除只需移动下标，空间自动复用。
- 易错点1：空队列插入第一个元素必须特判 l = r = 0，否则下标移动方向不对。
- 易错点2：l、r 四个方向的环绕别写反——头插 l 前走、尾插 r 后走、头删 l 后走、尾删 r 前走。
- 易错点3：必须用 size 区分空和满，不能只靠 l、r 的位置关系。
- 对比讲解013 的环形队列：那里 r 指向下一个写入位置；本题 r 指向队尾元素本身，读写逻辑不同，不要混淆。
