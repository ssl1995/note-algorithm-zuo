# 算法讲解015【入门】栈的入门题目-最小栈
前置知识：栈的概念及实现（讲解013）｜ 建议：经典题目，掌握"同步栈"的技巧
代码位置：src/class015/GetMinStack.java ｜ 测试链接：https://leetcode.cn/problems/min-stack/
## 一、题目描述
- 设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。
- 实现 MinStack 类：MinStack() 初始化；push(int val) 压栈；pop() 删除栈顶；top() 获取栈顶；getMin() 获取栈中最小元素。
- 难点：getMin 要求 O(1)，不能每次去遍历栈。
## 二、解题思路：数据栈 + 最小栈（同步栈）
- 准备两个栈：data 栈正常存数据，min 栈与 data 栈同步操作，min 栈顶始终是当前 data 栈中的最小值。
- push(val) 时：data 正常压入；min 栈压入 val 和 min 栈顶两者中的较小值（min 为空时直接压 val）。
- 这样 min 栈顶就记录了"从栈底到当前位置的最小值"，pop 时两栈同步弹出即可，getMin 直接返回 min 栈顶。
- 代码中的写法：若 val <= min 栈顶就压 val，否则把 min 栈顶再压一遍（重复压旧最小值），保证两个栈始终等长。
```plain
依次 push 5, 3, 7, 2 的过程（栈底在左，栈顶在右）:
push 5:  data[5]        min[5]        getMin=5
push 3:  data[5,3]      min[5,3]      getMin=3   (3<5, 压入3)
push 7:  data[5,3,7]    min[5,3,3]    getMin=3   (7>3, 重复压旧最小值3)
push 2:  data[5,3,7,2]  min[5,3,3,2]  getMin=2   (2<3, 压入2)
pop 2:   data[5,3,7]    min[5,3,3]    getMin=3   (两栈同步弹出, 最小值恢复)
```
## 三、代码实现一：用 Java 自带的 Stack
```java
class MinStack1 {
    public Stack<Integer> data;
    public Stack<Integer> min;
    public MinStack1() {
        data = new Stack<Integer>();
        min = new Stack<Integer>();
    }
    public void push(int val) {
        data.push(val);
        if (min.isEmpty() || val <= min.peek()) {
            min.push(val);
        } else { // val > min.peek()
            min.push(min.peek()); // 重复压旧最小值，保持两栈等长
        }
    }
    public void pop() {
        data.pop();
        min.pop(); // 同步弹出
    }
    public int top() {
        return data.peek();
    }
    public int getMin() {
        return min.peek();
    }
}
```
## 四、代码实现二：用数组实现（常数时间更优）
- 刷题时更推荐数组实现：提前开好固定大小的数组，用 size 当栈顶指针，常数时间好于 Stack 类。
- 数组版本的 min[i] 直接记录"data[0..i] 中的最小值"：min[i] = Math.min(data[i], min[i-1])。
```java
class MinStack2 {
    // leetcode的数据在测试时，同时在栈里的数据不超过这个值
    // 这是几次提交实验出来的；如果补测试数据超过了，就调大
    public final int MAXN = 8001;
    public int[] data;
    public int[] min;
    int size;
    public MinStack2() {
        data = new int[MAXN];
        min = new int[MAXN];
        size = 0;
    }
    public void push(int val) {
        data[size] = val;
        if (size == 0 || val <= min[size - 1]) {
            min[size] = val;
        } else {
            min[size] = min[size - 1]; // 沿用之前的最小值
        }
        size++;
    }
    public void pop() {
        size--; // 数组实现只需移动指针，空间自动复用
    }
    public int top() {
        return data[size - 1];
    }
    public int getMin() {
        return min[size - 1];
    }
}
```
## 五、复杂度与易错点
- 所有操作（push、pop、top、getMin）都是 O(1)；空间复杂度 O(n)，多开了一个同步的最小栈。
- 易错点1：push 时的比较条件要用 val <= min 栈顶（带等号），保证相等的最小值也压入，pop 时两栈才能同步、不会弹错。
- 易错点2：pop 时两栈必须同步弹出，只弹 data 栈会导致 min 栈顶与真实最小值错位。
- 易错点3：取栈顶前默认题目保证栈非空；自己写判空逻辑时两个栈要一起考虑。
- 延伸：同样的"同步栈"思想还能做"最大栈"、O(1) 获取中位数等变形题，单调栈在【必备】课程继续。
