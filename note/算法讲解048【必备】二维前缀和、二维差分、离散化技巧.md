## 零、本节课内容概览
- **二维前缀和**：预处理出一个结构后，每次查询二维数组任意矩形范围的累加和都是 O(1) 操作。
- **二维差分**：解决"二维数组上批量做**矩形区域加一个数**，所有操作做完后统一查询最终每个位置的值"的问题。add 时 O(1) 快速处理，最后 build 一次得到每个位置的值。**修改操作必须集中在一起，不能边修改边查询**。
- **离散化技巧**：坐标值域巨大但实际用到的坐标很少时，把坐标映射成紧凑的小编号，让二维差分可以用在小数组上，用题目5（最强祝福力场）说明。
- 注意：支持**实时单点修改 + 实时范围查询**的结构是**二维树状数组**，会在【扩展】课程里讲述，本课不覆盖。
## 一、二维前缀和原理
- 目标：预处理出一个结构，以后每次查询二维数组任何范围上的累加和都是 O(1)。
- **构建**：生成二维前缀和数组 sum，`sum[i][j]` 代表左上角 (0,0) 到右下角 (i,j) 范围的累加和：
  `sum[i][j] += sum[i][j-1] + sum[i-1][j] - sum[i-1][j-1]`（左 + 上 - 左上，去重补全）。
- **查询**：左上角 (a,b) 到右下角 (c,d) 范围的累加和：
  `sum[c][d] - sum[c][b-1] - sum[a-1][d] + sum[a-1][b-1]`（大矩形 - 左条 - 上条 + 重叠角）。
- 实际工程中往往**补第 0 行、第 0 列**（下标从 1 开始）来消除大量边界判断；也可以不补，用 get 函数把越界访问返回 0，根据个人习惯决定。
- 图示理解（查询 (a,b)~(c,d) 区域和）：
  - `sum[c][d]` 是整个大矩形；减去 `sum[c][b-1]`（左侧条）和 `sum[a-1][d]`（上侧条）；左上角 `sum[a-1][b-1]` 被减了两次，加回来一次。
- 复杂度：构建 O(n·m)，每次查询 O(1)，空间 O(n·m)。
## 二、题目1：二维前缀和模板（Code01_PrefixSumMatrix）
- 题意：Range Sum Query 2D - Immutable，设计一个结构，初始化时给定矩阵，之后多次查询任意子矩阵的元素和。测试链接：https://leetcode.cn/problems/range-sum-query-2d-immutable/
- 思路：补 0 行 0 列的标准二维前缀和模板。先把原矩阵拷贝到 sum 的 (1,1) 起始位置，再统一加工前缀和；查询时右下角 (c,d) 下标 +1 对齐。
```java
public NumMatrix(int[][] matrix) {
    int n = matrix.length;
    int m = matrix[0].length;
    sum = new int[n + 1][m + 1];
    for (int a = 1, c = 0; c < n; a++, c++) {
        for (int b = 1, d = 0; d < m; b++, d++) {
            sum[a][b] = matrix[c][d];
        }
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            sum[i][j] += sum[i][j - 1] + sum[i - 1][j] - sum[i - 1][j - 1];
        }
    }
}
public int sumRegion(int a, int b, int c, int d) {
    c++;
    d++;
    return sum[c][d] - sum[c][b] - sum[a][d] + sum[a][b];
}
```
## 三、题目2：边框为1的最大正方形（Code02_LargestOneBorderedSquare）
- 题意：01 二维网格 grid，找出**边界全部由 1 组成**的最大正方形子网格，返回其元素数量，不存在返回 0。测试链接：https://leetcode.cn/problems/largest-1-bordered-square/
- 思路：二维前缀和的应用题。边框上 1 的个数 = 外矩形累加和 - 内矩形累加和，若等于边框格子总数 `4×(k-1)`（k 为边长），则该正方形合法。枚举左上角 (a,b) 和更大的右下角 (c,d)，用前缀和 O(1) 验证。
- 代码技巧：**不补 0 行 0 列的版本**，把原数组原地加工成前缀和数组，用 `get` 函数把越界下标返回 0，省空间且免去下标平移：
```java
// 把g原地变成前缀和数组，不补0行0列
public static void build(int n, int m, int[][] g) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            g[i][j] += get(g, i, j - 1) + get(g, i - 1, j) - get(g, i - 1, j - 1);
        }
    }
}
public static int sum(int[][] g, int a, int b, int c, int d) {
    return a > c ? 0 : (g[c][d] - get(g, c, b - 1) - get(g, a - 1, d) + get(g, a - 1, b - 1));
}
public static int get(int[][] g, int i, int j) {
    return (i < 0 || j < 0) ? 0 : g[i][j];
}
```
- 主逻辑：先判断全图 1 的个数为 0 直接返回 0；否则从 ans=1 开始，枚举每个左上角点 (a,b)，再尝试更大的边长 k（右下角 c=a+ans, d=b+ans 起步），验证边框：
```java
for (int c = a + ans, d = b + ans, k = ans + 1; c < n && d < m; c++, d++, k++) {
    if (sum(g, a, b, c, d) - sum(g, a + 1, b + 1, c - 1, d - 1) == (k - 1) << 2) {
        ans = k;
    }
}
```
- 复杂度：时间 O(n·m·min(n,m))，额外空间 O(1)（复用原数组）。打败比例不高纯属常数时间问题，复杂度指标上是最优解。
## 四、二维差分原理
- 问题：二维数组上批量做 `add(a, b, c, d, v)`——左上角 (a,b) 到右下角 (c,d) 范围每个数字 +v，怎么快速处理？操作做完后如何正确得到每个位置的值？
- 核心思想：一维差分的二维推广。一次矩形加只改 4 个角点，最后对差分矩阵求**二维前缀和**还原出每个位置的值：
```java
void add(int a, int b, int c, int d, int v) {
    diff[a][b] += v;
    diff[c + 1][b] -= v;
    diff[a][d + 1] -= v;
    diff[c + 1][d + 1] += v;
}
void build() {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            diff[i][j] += diff[i - 1][j] + diff[i][j - 1] - diff[i - 1][j - 1];
        }
    }
}
```
- 直观理解：`diff[a][b] += v` 会让前缀和还原后 (a,b) 右下角的所有位置都 +v；`diff[c+1][b] -= v` 和 `diff[a][d+1] -= v` 把超出矩形的下侧、右侧部分减掉；`diff[c+1][d+1] += v` 把被减了两次的右下角区域补回来。与二维前缀和的容斥结构完全对应。
- 实战要点：**真实数据用一圈 0 包裹起来**（下标从 1 开始，数组多开 1~2 格），这样 c+1、d+1 不会越界，可以减少很多边界讨论。
- 复杂度：q 次操作 + n·m 数组，总代价 O(q + n·m)。对比暴力每次操作 O(n·m)，优势巨大。
- 局限：所有修改必须先做完，再 build 一次统一查询；不支持边修改边查询（要在线请用二维树状数组，【扩展】课程讲述）。
## 五、题目3：二维差分模板（Code03_DiffMatrixLuogu / Code03_DiffMatrixNowcoder）
- 题意（洛谷 P3397 地毯）：n×n 的白毯子上铺 q 块地毯，每块地毯覆盖 (a,b)~(c,d) 范围，问每个格子被多少块地毯覆盖。测试链接：https://www.luogu.com.cn/problem/P3397
- 题意（牛客模板题）：n×m 矩阵有初始值，q 次矩形区域加 k，输出最终矩阵。测试链接：https://www.nowcoder.com/practice/50e1a93989df42efb0b1dec386fb4ccc
- 思路：纯二维差分模板。每块地毯就是一次 `add(a, b, c, d, 1)`；全部操作后 `build()` 还原，diff[i][j] 就是该格子的覆盖次数。
```java
public static void add(int a, int b, int c, int d, int k) {
    diff[a][b] += k;
    diff[c + 1][b] -= k;
    diff[a][d + 1] -= k;
    diff[c + 1][d + 1] += k;
}
public static void build() {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            diff[i][j] += diff[i - 1][j] + diff[i][j - 1] - diff[i - 1][j - 1];
        }
    }
}
```
- 初始值不为 0 的处理（牛客版）：把每个初始值当作一次单点修改 `add(i, j, i, j, 初始值)`，初始值与后续操作走同一入口，代码统一不易错（与 047 课一维差分的结论一致）。
- **多组数据注意 clear**：牛客版是多组输入，每组数据结束后要把 diff 数组清零（清到 n+1、m+1 范围），否则上一组的残留会污染下一组。
- **笔试必备输入输出模板**：`BufferedReader + StreamTokenizer` 读入、`PrintWriter` 输出，以 `in.nextToken() != StreamTokenizer.TT_EOF` 判断结束。提交时类名改成 `Main`。
- 数据量大时（牛客版 k 可能很大）diff 数组用 **long** 防溢出。
## 六、题目4：用邮票贴满网格图（Code04_StampingTheGrid）
- 题意：m×n 二进制矩阵 grid（0 空 / 1 被占据），邮票尺寸 stampHeight×stampWidth。要求覆盖所有空格、不覆盖任何被占据的格子，邮票可任意多张、可重叠、不可旋转、必须完全在矩阵内。问能否满足。测试链接：https://leetcode.cn/problems/stamping-the-grid/
- 思路：**二维前缀和 + 二维差分联用**，是本课最经典的双技巧组合题：
  1. 前缀和数组 sum：O(1) 查询任意 h×w 区域是否全 0（`sumRegion == 0`），即判断某个位置能不能贴邮票；
  2. 差分矩阵 diff：能贴的位置，不在原始矩阵里贴，而是在差分矩阵里 `add(a, b, c, d)` 打一次矩形 +1 标记；
  3. 全部贴完后 build(diff) 还原，逐格检查：`grid[i][j] == 0`（是个洞）且 `diff[i+1][j+1] == 0`（洞上没有邮票）则返回 false。
- 贪心正确性：邮票可以重叠，所以只要某区域全 0 就贴，绝不会让答案变得更糟——贴得越多，空格被覆盖的可能性越大。
```java
for (int a = 1, c = a + h - 1; c <= n; a++, c++) {
    for (int b = 1, d = b + w - 1; d <= m; b++, d++) {
        // (a,b)左上角点，按邮票规格算出右下角(c,d)
        // 区域全0则可以贴邮票，在差分矩阵里打标记
        if (sumRegion(sum, a, b, c, d) == 0) {
            add(diff, a, b, c, d);
        }
    }
}
build(diff);
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        if (grid[i][j] == 0 && diff[i + 1][j + 1] == 0) {
            return false;
        }
    }
}
return true;
```
- 复杂度：时间 O(n·m)，空间 O(n·m)。原始矩阵只用来判断、不修改，这是设计上的关键分工。
## 七、离散化技巧 + 题目5：最强祝福力场（Code05_StrongestForceField）
- 题意（LCP 74）：n 片力场，`forceField[i] = [x, y, side]` 表示以 (x,y) 为中心、边长 side 的正方形区域（边缘同样被覆盖）。任意点的力场强度 = 覆盖该点的力场数量，求最强处的力场强度。测试链接：https://leetcode.cn/problems/xepqZ5/
- 难点：坐标值域高达 ±10^9，不可能开 10^9×10^9 的数组做二维差分。但力场只有 n 个，**实际有意义的坐标只有 2n 个 x 边界和 2n 个 y 边界**——这正是离散化的用武之地。
- **离散化三步**：
  1. 收集所有出现过的坐标（每个力场贡献左右/上下两个边界）；
  2. 排序 + 去重，得到紧凑的有效长度 sizex、sizey；
  3. 用二分查找把原始坐标映射成 1~size 的小编号（rank），差分数组只需开 `(sizex+2)×(sizey+2)`。
- **本题精髓：坐标 ×2 避开小数**。边长 side 可能为奇数，力场边界是 `x - side/2.0`、`x + side/2.0`，会出现 .5 的小数。把所有坐标左移一位（`x << 1`）后，边界变成 `2x - side`、`2x + side`，全是整数，且不影响力场之间的覆盖关系：
```java
for (int i = 0, k = 0, p = 0; i < n; i++) {
    long x = fields[i][0];
    long y = fields[i][1];
    long r = fields[i][2];
    xs[k++] = (x << 1) - r;
    xs[k++] = (x << 1) + r;
    ys[p++] = (y << 1) - r;
    ys[p++] = (y << 1) + r;
}
```
- 排序去重（sort）与二分定位（rank）：
```java
// 排序且相同值只留一份，返回有效长度
// [50,70,30,70,30,60] -> [30,50,60,70] 有效长度4，编号1~4
public static int sort(long[] nums) {
    Arrays.sort(nums);
    int size = 1;
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] != nums[size - 1]) {
            nums[size++] = nums[i];
        }
    }
    return size;
}
// v 一定在 nums[0~size-1] 中，返回 v 对应的编号（从1开始）
public static int rank(long[] nums, long v, int size) {
    int l = 0, r = size - 1, m, ans = 0;
    while (l <= r) {
        m = (l + r) / 2;
        if (nums[m] >= v) {
            ans = m;
            r = m - 1;
        } else {
            l = m + 1;
        }
    }
    return ans + 1;
}
```
- 主流程：每个力场映射成离散坐标后做一次二维差分 add；最后 build 的同时取最大值：
```java
int[][] diff = new int[sizex + 2][sizey + 2];
for (int i = 0, a, b, c, d; i < n; i++) {
    long x = fields[i][0], y = fields[i][1], r = fields[i][2];
    a = rank(xs, (x << 1) - r, sizex);
    b = rank(ys, (y << 1) - r, sizey);
    c = rank(xs, (x << 1) + r, sizex);
    d = rank(ys, (y << 1) + r, sizey);
    add(diff, a, b, c, d);
}
int ans = 0;
for (int i = 1; i < diff.length; i++) {
    for (int j = 1; j < diff[0].length; j++) {
        diff[i][j] += diff[i - 1][j] + diff[i][j - 1] - diff[i - 1][j - 1];
        ans = Math.max(ans, diff[i][j]);
    }
}
return ans;
```
- 正确性要点：力场覆盖是闭区间，而离散化保留了所有边界的相对顺序，两个力场在原坐标系中相交 ⟺ 它们离散后的矩形相交，所以离散化不影响"某个区域被几片力场覆盖"的统计结果。
- 复杂度：时间 O(n²)，空间 O(n²)（n 是力场个数）。把 10^9 的值域压缩到 2n 的网格，是离散化的典型威力。
## 八、总结
- 二维前缀和：`sum[i][j] += sum[i][j-1] + sum[i-1][j] - sum[i-1][j-1]` 构建；`sum[c][d] - sum[c][b-1] - sum[a-1][d] + sum[a-1][b-1]` 查询，容斥结构左右对称。查询 O(1)，适合"矩阵静态、多次范围求和"。
- 二维差分：矩形区域 +v 只改 4 个角点 `diff[a][b]+=v; diff[c+1][b]-=v; diff[a][d+1]-=v; diff[c+1][d+1]+=v`，最后一遍二维前缀和还原，O(q + n·m)。适合"批量矩形修改、最后统一查询"。
- 实战细节：① 数据用一圈 0 包裹（下标从 1 开始、数组多开 1~2 格）防越界；② 初始值不为 0 时当作单点 add 打到差分数组上；③ 多组数据记得 clear；④ 大数据用 long；⑤ 笔试用 `StreamTokenizer + PrintWriter` 高效 IO。
- 前缀和与差分联用（邮票题）：前缀和负责"查询哪里能操作"，差分负责"批量记录操作"，原始矩阵只读不改——职责分离是常见设计模式。
- 离散化：值域巨大但数据量小时，"收集坐标 → 排序去重 → 二分映射编号"，把大坐标系压成小网格再跑差分；坐标可能出现小数时**整体 ×2 转整数**是常用技巧。
- 边界提醒：需要边修改边查询（在线操作）的场景请用二维树状数组/线段树，【扩展】课程讲述。
