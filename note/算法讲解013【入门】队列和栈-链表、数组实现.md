## 一、队列的介绍
- 队列（Queue）：先进先出（FIFO，First In First Out）的数据结构，像排队一样，从尾部加入（offer），从头部取出（poll）。
- 常用操作：offer（加数到尾巴）、poll（从头弹出）、peek（看头不弹出）、size、isEmpty。
- 调用任何取数方法之前，必须先调用 isEmpty 判断队列里是否有东西。
- 底层可以用链表实现（天然支持头尾操作），也可以用数组实现（常数时间更好）。
## 二、栈的介绍
- 栈（Stack）：先进后出（FILO，First In Last Out）的数据结构，像一摞盘子，只在顶部操作。
- 常用操作：push（压入栈顶）、pop（弹出栈顶）、peek（看栈顶不弹出）、size、isEmpty。
- 同样，调用取数方法前必须先判空。
- 队列、栈、双端队列可以组成非常多重要的数据结构（如单调栈、单调队列），将在【必备】课程里继续。
## 三、队列的实现
### 1. 链表实现（直接用 Java 内部的 LinkedList）
- Java 中的 LinkedList 是双向链表，其实单向链表就足够了；缺点是常数操作慢。
```java
public static class Queue1 {
    public Queue<Integer> queue = new LinkedList<>();
    public boolean isEmpty() { return queue.isEmpty(); }
    public void offer(int num) { queue.offer(num); } // 加到尾巴
    public int poll() { return queue.poll(); }       // 从头拿
    public int peek() { return queue.peek(); }       // 看头不弹出
    public int size() { return queue.size(); }
}
```
### 2. 数组实现（实际刷题更常见，常数时间好）
- 前提：可以确定加入操作的总次数不超过 n（笔试、面试一般都有明确数据量，所以这是最常用的方式）。
- 用 l、r 两个指针标记区间 [l, r)：offer 时 queue[r++] = num，poll 时 queue[l++]。
```java
public static class Queue2 {
    public int[] queue;
    public int l, r;
    public Queue2(int n) { // 加入操作的总次数上限，一定要明确
        queue = new int[n];
        l = 0;
        r = 0;
    }
    public boolean isEmpty() { return l == r; }
    public void offer(int num) { queue[r++] = num; }
    public int poll() { return queue[l++]; }
    public int head() { return queue[l]; }
    public int tail() { return queue[r - 1]; }
    public int size() { return r - l; }
}
```
```plain
数组: [ _ | 4 | 5 | 6 | _ ]
         l         r
有效区间是 [l, r)，即 l...r-1
offer(x): queue[r++]=x   poll(): return queue[l++]
size = r - l，空队列 l == r
```
## 四、栈的实现
### 1. 直接用 Java 内部的 Stack
- 底层其实是动态数组，常数时间并不好。
```java
public static class Stack1 {
    public Stack<Integer> stack = new Stack<>();
    public boolean isEmpty() { return stack.isEmpty(); }
    public void push(int num) { stack.push(num); }
    public int pop() { return stack.pop(); }
    public int peek() { return stack.peek(); }
    public int size() { return stack.size(); }
}
```
### 2. 数组实现（实际刷题更常见，常数时间好）
- 前提：同时在栈里的元素个数不会超过 n（弹出之后空间可以复用）。
- 用一个 size 变量当栈顶指针即可：push 时 stack[size++] = num，pop 时 stack[--size]。
```java
public static class Stack2 {
    public int[] stack;
    public int size;
    public Stack2(int n) { // 同时在栈里的元素个数不会超过n
        stack = new int[n];
        size = 0;
    }
    public boolean isEmpty() { return size == 0; }
    public void push(int num) { stack[size++] = num; }
    public int pop() { return stack[--size]; }
    public int peek() { return stack[size - 1]; }
    public int size() { return size; }
}
```
## 五、高频考点：环形队列用数组实现（LeetCode 622）
- 题目要求：设计循环队列，支持 enQueue（入队）、deQueue（出队）、Front（看队头）、Rear（看队尾）、isEmpty、isFull。
- 核心思路：数组 + l、r 两个下标 + size 计数 + limit 容量。l、r 走到数组末尾就跳回 0，形成环。
- 关键细节：用 size 区分空和满（size == 0 为空，size == limit 为满），这样 l 和 r 追上彼此时不会混淆。
```java
class MyCircularQueue {
    public int[] queue;
    public int l, r, size, limit;
    public MyCircularQueue(int k) { // 同时在队列里的数字个数不超过k
        queue = new int[k];
        l = r = size = 0;
        limit = k;
    }
    public boolean enQueue(int value) { // 满了返回false，否则加入返回true
        if (isFull()) {
            return false;
        }
        queue[r] = value;
        r = r == limit - 1 ? 0 : (r + 1); // r++，到头跳回0
        size++;
        return true;
    }
    public boolean deQueue() { // 空了返回false，否则弹出头部返回true
        if (isEmpty()) {
            return false;
        }
        l = l == limit - 1 ? 0 : (l + 1); // l++，到头跳回0
        size--;
        return true;
    }
    public int Front() {
        return isEmpty() ? -1 : queue[l];
    }
    public int Rear() {
        if (isEmpty()) {
            return -1;
        }
        int last = r == 0 ? (limit - 1) : (r - 1); // r的前一个位置才是队尾
        return queue[last];
    }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == limit; }
}
```
```plain
环形队列图示（limit = 5，当前 size = 3）:
下标:   0    1    2    3    4
      [ 7 | 8 | 9 | _ | _ ]
        l         r
入队: queue[r]=x, r=(r+1)%limit, size++
出队: l=(l+1)%limit, size--
r 指向的是下一个写入位置，所以队尾元素在 r-1（r==0 时在 limit-1）
```
## 六、总结与易错点
- 队列 FIFO、栈 FILO，任何取数操作前必须先判空。
- 刷题时优先用数组实现：提前开好固定大小的数组，用下标当指针，常数时间远好于 LinkedList/Stack。
- 队列数组实现的区间语义是 [l, r)，size = r - l；栈只需要一个 size 指针。
- 环形队列易错点1：l、r 到达 limit - 1 后要跳回 0（取模思想的展开写法）。
- 环形队列易错点2：必须额外维护 size 来区分空与满，否则 l == r 时无法判断是空还是满。
- 环形队列易错点3：Rear() 要找 r 的前一个位置，注意 r == 0 时前一个位置是 limit - 1。
