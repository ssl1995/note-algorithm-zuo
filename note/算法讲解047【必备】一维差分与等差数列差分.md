# 算法讲解047【必备】一维差分与等差数列差分
前置知识：无，知道什么是数组就行
代码位置：src/class047 ｜ 内容：一维差分原理（航班预订统计）、等差数列差分模板（洛谷P4231）、等差数列差分经典题（落水水位，洛谷P5026）
## 零、本节课内容概览
- **一维差分**：解决"数组上多次**区间加一个数**，所有操作做完后统一查询最终数组"的问题。理解难度极低，但不支持**边操作、边查询**（要边操作边查询请用线段树等结构，【扩展】课程讲述）。
- **等差数列差分**：一维差分的升级版——每次操作是在 l~r 范围上依次加上**首项 s、末项 e、公差 d 的等差数列**，用**两遍前缀和**还原出最终数组。大厂笔试面试中还不常见，是比赛必备技巧，但预计会流行。
- 二维差分会在后续【必备】课程讲述。
- 复杂度：m 次操作 + n 长度数组，一维差分总代价 O(m + n)；等差数列差分同样是 O(m + n)，只是把"一遍前缀和"换成"两遍前缀和"。
## 一、一维差分原理
- 核心思想：与其每次操作都把 l~r 上每个数 +v（O(n) 一次），不如只记"变化的边界"：
  - `diff[l] += v`：从 l 开始，整体抬高 v；
  - `diff[r + 1] -= v`：从 r+1 开始，把抬高取消。
- 所有操作打完后，对 diff 求**一遍前缀和**，`diff[i]` 的前缀和就是原数组每个位置的最终值。
- 图示（原数组全 0，操作 [2,4] +3）：
  - diff 设置后：`[0, 0, +3, 0, 0, -3]`
  - 前缀和还原：`[0, 0, 3, 3, 3, 0]` —— 正是 2~4 位置各 +3。
- 记忆口诀：**左边加、右边减，一遍前缀和还原**。
## 二、初始值不为0时，如何使用差分数组
- 课程代码中初始数组全 0，差分数组天然全 0，所以直接 `new int[n+2]` 即可。若初始值不为 0，差分操作（`diff[l]+=v; diff[r+1]-=v`）**完全不用改**，因为它只关心"增量"，与初始值无关——只需先构建出带初始值的差分数组。有两种等价方法：
- **方法一：相邻相减直接构建**。按定义 `diff[i] = arr[i] - arr[i-1]`：
```java
// init 下标0~n-1 对应位置1~n
cnt[1] = init[0];
for (int i = 2; i <= n; i++) {
    cnt[i] = init[i - 1] - init[i - 2];
}
```
- **方法二（更推荐）：把每个初始值当作一次区间修改**。全 0 基础上的初始数组 = n 次"区间长度为1"的修改 `[i, i, +init[i]]`，直接复用现成的修改函数，不用写新的初始化逻辑：
```java
for (int i = 1; i <= n; i++) {
    cnt[i] += init[i - 1];     // add(l) 部分
    cnt[i + 1] -= init[i - 1]; // add(r+1) 部分
}
```
- 举例验证（初始 `[10, 20, 30, 40, 50]`）：方法一得 `diff = [0, 10, 10, 10, 10, 10, 0]`；方法二中 `cnt[2]` 累计 `-10 + 20 = 10`，恰好就是相邻相减的结果——**方法二每个位置的累计效果天然等于方法一**，两种方法得到的差分数组一模一样，时间复杂度都是 O(n)。
- **为什么方法二更合理**：① 代码统一，初始值和后续操作走同一个修改入口，不易写错；② 推广到等差数列差分时优势更明显——如果初始值本身是等差数列等规律数据，直接调 `set(l, r, s, e, d)` 即可，不用手动推相邻相减（二阶差分）的公式。
- 后续流程两种方法完全一致：正常做所有修改操作，最后一遍（或两遍）前缀和还原，初始值会自动保留在结果中。
## 三、题目1：航班预订统计（Code01_CorporateFlightBookings）
- 题意：n 个航班（编号 1~n），bookings[i] = [first, last, seats] 表示 first~last 每个航班预订 seats 个座位，返回每个航班的预订总数。测试链接：https://leetcode.cn/problems/corporate-flight-bookings/
- 思路：一维差分模板题。数组开 n+2 大小防止 r+1 越界；每条记录只做两次设置，最后前缀和还原。
```java
public static int[] corpFlightBookings(int[][] bookings, int n) {
    int[] cnt = new int[n + 2];
    // 设置差分数组，每一个操作对应两个设置
    for (int[] book : bookings) {
        cnt[book[0]] += book[2];
        cnt[book[1] + 1] -= book[2];
    }
    // 加工前缀和
    for (int i = 1; i < cnt.length; i++) {
        cnt[i] += cnt[i - 1];
    }
    int[] ans = new int[n];
    for (int i = 0; i < n; i++) {
        ans[i] = cnt[i + 1]; // 航班从1号开始，下标平移1格
    }
    return ans;
}
```
- 复杂度：时间 O(m + n)，空间 O(n)。对比暴力 O(m·n)，数据量大时优势巨大。
## 四、等差数列差分原理（本课核心模板）
- 问题描述：一开始 1~n 范围上的数字都是 0，共 m 个操作，每次操作 (l, r, s, e, d) 表示在 l~r 范围上依次加上首项为 s、末项为 e、公差为 d 的等差数列（e = s + (r-l)·d），求最终每个位置的值。
- 推导：等差数列 = "相邻位置的增量恒为 d"。对 arr 做一阶差分后，操作等价于：位置 l 处是 s，l+1~r 上每个位置是常数 d，r+1 处要"还债"。而"区间加常数"本身又可以用一维差分解决——所以对 arr 维护**二阶差分**数组 arr（即对差分再差分），每次操作只改 4 个点：
```java
// 等差数列差分的set方法：l~r范围加首项s、末项e、公差d的等差数列
public static void set(int l, int r, int s, int e, int d) {
    arr[l] += s;
    arr[l + 1] += d - s;
    arr[r + 1] -= d + e;
    arr[r + 2] += e;
}
// build方法：生成两遍前缀和，arr[i]就是最终i位置的值
public static void build() {
    for (int i = 1; i <= n; i++) {
        arr[i] += arr[i - 1];
    }
    for (int i = 1; i <= n; i++) {
        arr[i] += arr[i - 1];
    }
}
```
- 正确性验证（单步追踪）：设二阶差分数组为 f，第一遍前缀和得到一阶差分 g，第二遍前缀和得到最终值 h：
  - g[l] = s；g[l+1..r] = d（常数）；g[r+1] = -e；之后归 0；
  - h[l] = s；h[l+1] = s+d；…；h[r] = s+(r-l)·d = e；h[r+1] = e+(-e) = 0，完美收尾。
- 使用流程：每个操作调用一次 `set`（O(1)），全部操作结束后调用一次 `build`（O(n)），总复杂度 O(m + n)。
- **注意**：操作范围可能触及 r+2，数组要多开 2 个格子防越界；数据量大时 arr 用 long 防止溢出。
## 五、题目2：等差数列差分模板题（Code02_ArithmeticSequenceDifference）
- 题意（洛谷 P4231）：1~n 初始全 0，m 个操作 (l,r,s,e,d)，所有操作做完后统计 1~n 上所有数字的**最大值和异或和**。数据量：n ≤ 10^7，m ≤ 3×10^5。测试链接：https://www.luogu.com.cn/problem/P4231
- 思路：纯模板套用。`d = (e - s) / (r - l)` 由首末项反算公差；n 到 10^7，数组必须开静态全局（`new long[10000005]`），且必须使用高效输入输出。
```java
public static int MAXN = 10000005;
public static long[] arr = new long[MAXN];
// 每个操作：set(l, r, s, e, (e - s) / (r - l));
// 全部操作后：build(); 然后扫一遍统计
long max = 0, xor = 0;
for (int i = 1; i <= n; i++) {
    max = Math.max(max, arr[i]);
    xor ^= arr[i];
}
out.println(xor + " " + max);
```
- **笔试必备输入输出模板**（务必参考）：`BufferedReader + StreamTokenizer` 读入、`PrintWriter` 输出，以 `in.nextToken() != StreamTokenizer.TT_EOF` 判断是否还有数据。提交时类名改成 `Main`。
- 复杂度：时间 O(m + n)，空间 O(n)。10^7 规模下这是唯一可行的做法量级。
## 六、题目3：落水水位——等差数列差分经典题（Code03_WaterHeight）
- 题意（洛谷 P5026 Lycanthropy）：湖泊是长度为 m 的直线，初始水位全 0。体积 v 的人在位置 x 落水，水位变化呈"波形"：入水点附近下降、远处升高，具体为 4 段等差变化（x-3v+1~x-2v 加 1..v；x-2v+1~x 从 v-1 递减到 -v；x+1~x+2v 从 -v+1 递增到 v；x+2v+1~x+3v-1 从 v-1 递减到 1）。n 个人落水后打印每个位置水位。n,m ≤ 10^6，v ≤ 10000。测试链接：https://www.luogu.com.cn/problem/P5026
- 思路：**一个人落水 = 4 次等差数列操作**，直接调 4 次模板里的 `set`：
```java
public static void fall(int v, int x) {
    set(x - 3 * v + 1, x - 2 * v, 1, v, 1);
    set(x - 2 * v + 1, x, v - 1, -v, -1);
    set(x + 1, x + 2 * v, -v + 1, v, 1);
    set(x + 2 * v + 1, x + 3 * v - 1, v - 1, 1, -1);
}
```
- **OFFSET 设计（本题精髓）**：v 最大 10000，影响最远到 x±3v，即可能超出正式位置 1~m 约 30000 的规模。与其做大量边界讨论，不如把所有下标统一 `+OFFSET`（30001），数组开 `OFFSET + MAXN + OFFSET` 大小，**任何下标都不会越界**，最后只打印 OFFSET+1 开始的 m 个位置：
```java
public static int OFFSET = 30001;
public static int[] arr = new int[OFFSET + MAXN + OFFSET];
public static void set(int l, int r, int s, int e, int d) {
    arr[l + OFFSET] += s;
    arr[l + 1 + OFFSET] += d - s;
    arr[r + 1 + OFFSET] -= d + e;
    arr[r + 2 + OFFSET] += e;
}
public static void build() {
    for (int i = 1; i <= m + OFFSET; i++) {
        arr[i] += arr[i - 1];
    }
    for (int i = 1; i <= m + OFFSET; i++) {
        arr[i] += arr[i - 1];
    }
}
```
- 启示：当操作范围可能越出正式区间时，"**整体平移 + 开大数组**"是省去边界讨论的通用技巧，比赛和笔试中非常实用。
## 七、总结
- 一维差分：区间加常数 → `diff[l]+=v, diff[r+1]-=v`，一遍前缀和还原，O(m+n)。口诀：**左加右减，一遍还原**。
- 初始值不为 0 时：推荐把初始值当作一批区间修改操作打到全 0 差分数组上（等价于相邻相减构建），初始值与后续操作走同一入口，代码统一不易错。
- 等差数列差分：区间加等差数列 → 二阶差分，`set` 改 4 个点，`build` 跑**两遍前缀和**还原，O(m+n)。
- 等差数列差分局限：只支持"全部操作做完后统一查询"，不支持边操作边查询；需要在线查询请上线段树/树状数组（【扩展】课程内容）。
- 实战细节：① 数组多开 2 格防 r+2 越界；② 大数据用 long + 静态全局数组；③ 下标可能为负时用 OFFSET 整体平移；④ 笔试输入输出用 `StreamTokenizer + PrintWriter` 模板。
