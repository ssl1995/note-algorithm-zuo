## 三、题目1：判断一个整数是不是 2 的幂（Code01）
- 测试链接：https://leetcode.cn/problems/power-of-two/
- 核心工具：Brian Kernighan 算法提取最右侧的 1，即 n & (-n)（讲解030 已详细介绍）。
- 原理：2 的幂的二进制只有 1 个 1（如 0b0001000），它本身就是自己"最右侧的 1"；其他正整数至少还有别的 1，n & (-n) 只是其中一部分。
- 注意必须加 n > 0：0 和负数都不是 2 的幂，而 0 & (-0) == 0 会被误判。
```java
public static boolean isPowerOfTwo(int n) {
    return n > 0 && n == (n & -n);
}
```
- 等价写法：n > 0 && (n & (n - 1)) == 0。n & (n-1) 能抹掉最右侧的 1，2 的幂只有一个 1，抹掉就变 0。这也是 Brian Kernighan 算法的另一个经典用途。
## 四、题目2：判断一个整数是不是 3 的幂（Code02）
- 测试链接：https://leetcode.cn/problems/power-of-three/
- 原理（非常巧妙，利用 int 范围有限的特性）：
  - 如果一个数是 3 的某次幂，那么这个数一定只含有 3 这个质数因子。
  - 1162261467 是 int 范围内最大的 3 的幂（3 的 19 次方），它只含有 3 这个质数因子。
  - 如果 n 也只含 3 这个质数因子，那么 1162261467 % n == 0；反之如果 1162261467 % n != 0，说明 n 一定含有其他质数因子。
  - 一句话：int 范围内最大的 3 的幂 = 所有 3 的幂的公倍数。
```java
public static boolean isPowerOfThree(int n) {
    return n > 0 && 1162261467 % n == 0;
}
```
- 同类套路可以推广：判断 2 的幂可以用 1 << 30 % n == 0；判断 5 的幂可以用 int 范围内最大的 5 的幂取模。本质都是"最大幂只含单一质因子"。
- 如果不用这个技巧，常规写法是循环除 3：while (n % 3 == 0) n /= 3; 最后看 n == 1，时间复杂度 O(logn)。
## 五、题目3：返回大于等于 n 的最小的 2 的幂（Code03）
- 已知 n 是非负数，返回大于等于 n 的最小的 2 的某次方；如果 int 范围内不存在这样的数，返回整数最小值（溢出自然回到 Integer.MIN_VALUE）。
- 原理（二分扩散，把最高位的 1 向右"铺满"）：
  - 1）先 n--：把"大于等于 n"转化为"严格大于 n-1"，这样 n 本身恰好是 2 的幂时不会多翻一倍（例如 n=8，答案是 8 而不是 16）。
  - 2）依次 n |= n >>> 1、>>> 2、>>> 4、>>> 8、>>> 16：最高位的 1 经过无符号右移再或回来，1 位变 2 位、2 位变 4 位、4 位变 8 位……5 步之后，最高位 1 右边的所有位全被铺成 1。
  - 3）最后 n + 1：全 1 加 1 进位，得到的就是那个 2 的幂。
- 图示（以 n=100 为例，n-- 后 n=99 = 0b01100011）：
```text
n      = 01100011
n>>>1  = 00110001  或回来 -> 01110011   （最高1位扩散成2位）
n>>>2  = 00011100  或回来 -> 01111111   （2位扩散成4位）
n>>>4  = 00000111  或回来 -> 01111111   （4位扩散成8位，已铺满）
n + 1  = 10000000  = 128，即大于等于100的最小2的幂
```
```java
public static final int near2power(int n) {
    if (n <= 0) {
        return 1;
    }
    n--;
    n |= n >>> 1;
    n |= n >>> 2;
    n |= n >>> 4;
    n |= n >>> 8;
    n |= n >>> 16;
    return n + 1;
}
```
- 工程应用：java.util.HashMap 的 tableSizeFor 方法用的就是这个技巧，把传入容量修正为 2 的幂，当模版记住即可。
## 六、题目4：区间 [left, right] 内所有数字 & 的结果（Code04）
- 测试链接：https://leetcode.cn/problems/bitwise-and-of-numbers-range/（包含 left、right 端点）
- 原理：
  - 区间内所有数字做 &，某一位要想最后保留为 1，必须所有数该位都是 1。
  - 从 left 增长到 right 的过程中，低位一定会经历 0/1 翻转，只有 left 和 right 公共前缀部分的位才能幸存。
  - 所以答案 = left 和 right 二进制的最长公共前缀，后面补 0。
- 实现：不断用 Brian Kernighan 算法抹掉 right 最右侧的 1（right -= right & -right），直到 left >= right。每抹一次相当于把 right 的低位"清零对齐"，结束时 right 就是公共前缀。
```java
public static int rangeBitwiseAnd(int left, int right) {
    while (left < right) {
        right -= right & -right; // 抹掉right最右侧的1
    }
    return right;
}
```
- 示例：[5, 7] -> 5=101、6=110、7=111。right=111 抹最右 1 得 110（6），仍大于 left；再抹最右 1 得 100（4），left=5 >= 4 停止，返回 4（100），即公共前缀 "1" 后面补 0。
- 等价写法：while (left < right) right &= right - 1; 或者统计 right-left 需要右移多少位求公共前缀，复杂度都是 O(32) 级别。
## 七、题目5：逆序二进制的状态（Code05）—— 超自然版
- 测试链接：https://leetcode.cn/problems/reverse-bits/
- 注意：是把 32 位二进制整体逆序（第 0 位和第 31 位交换、第 1 位和第 30 位交换……），不是 0 变 1、1 变 0。
- 原理（分治交换，5 步搞定）：
  - 1）相邻的 1 位两两交换（奇偶位互换）；
  - 2）相邻的 2 位块两两交换；
  - 3）相邻的 4 位块两两交换；
  - 4）相邻的 8 位块（字节）两两交换；
  - 5）高 16 位和低 16 位整体交换。
  - 每一层都在更大的粒度上做"逆序"，5 层之后 32 位全部逆序。这和归并/分治的思想一致，但全程没有一句条件判断。
- 掩码记忆法：0xaaaaaaaa = 1010...（偶数位）、0x55555555 = 0101...（奇数位）；0xcccccccc = 1100...、0x33333333 = 0011...；0xf0f0f0f0、0x0f0f0f0f 按 4 位分块；0xff00ff00、0x00ff00ff 按 8 位分块。
```java
// 逆序二进制的状态
// 是不是看着头皮发麻啊？代码看着很魔幻吧？别慌
public static int reverseBits(int n) {
    n = ((n & 0xaaaaaaaa) >>> 1) | ((n & 0x55555555) << 1);  // 1位块互换
    n = ((n & 0xcccccccc) >>> 2) | ((n & 0x33333333) << 2);  // 2位块互换
    n = ((n & 0xf0f0f0f0) >>> 4) | ((n & 0x0f0f0f0f) << 4);  // 4位块互换
    n = ((n & 0xff00ff00) >>> 8) | ((n & 0x00ff00ff) << 8);  // 8位块互换
    n = (n >>> 16) | (n << 16);                              // 16位块互换
    return n;
}
```
- 注意用 >>>（无符号右移），避免符号位捣乱；欣赏完当模版直接用即可。
## 八、题目6：返回一个数二进制中有几个 1（Code06）—— 超自然版
- 题目包装：两个整数之间的汉明距离 = 对应二进制位不同的位置数目，先 x ^ y 再统计 1 的个数。
- 测试链接：https://leetcode.cn/problems/hamming-distance/
- 原理（分治累加，SWAR 技巧，SIMD Within A Register）：
  - 1）每 2 位一组：用 0x55555555（0101...）把偶数位的 1 和低位的 1 相加，每个 2 位块里存的就是这 2 位中 1 的个数；
  - 2）每 4 位一组：用 0x33333333 把相邻两个 2 位块的计数相加，每个 4 位块存的是这 4 位中 1 的个数；
  - 3）依次扩展到 8 位、16 位、32 位，最后 n 本身就是 1 的总数。
  - 全程无循环、无分支，5 行代码完成 32 位计数，这就是"看完能爽一整天"的脑洞。
```java
public static int hammingDistance(int x, int y) {
    return cntOnes(x ^ y);
}
// 返回n的二进制中有几个1，这个实现脑洞太大了
public static int cntOnes(int n) {
    n = (n & 0x55555555) + ((n >>> 1) & 0x55555555); // 每2位存这2位的1的个数
    n = (n & 0x33333333) + ((n >>> 2) & 0x33333333); // 每4位存这4位的1的个数
    n = (n & 0x0f0f0f0f) + ((n >>> 4) & 0x0f0f0f0f); // 每8位
    n = (n & 0x00ff00ff) + ((n >>> 8) & 0x00ff00ff); // 每16位
    n = (n & 0x0000ffff) + ((n >>> 16) & 0x0000ffff);// 32位总和
    return n;
}
```
- 日常替代方案（同样推荐掌握）：
  - Brian Kernighan 消 1 法：int cnt = 0; while (n != 0) { n &= n - 1; cnt++; }，循环次数 = 1 的个数，1 很少时极快。
  - Java 内置：Integer.bitCount(n)，底层就是类似的分治实现。
## 九、本节课一句话总结
- 两件基础武器贯穿全课：n & (-n) 提取最右侧的 1（判 2 的幂、区间 &）；n & (n - 1) 抹掉最右侧的 1。
- 两类"超自然"分治模版：无符号右移 + 或（扩散铺满低位，求 >= n 的最小 2 的幂）；掩码 + 移位 + 或/加（位块两两交换逆序、位块逐级计数），全程无分支，常数时间极好。
- 核心态度：自己写代码以直白可理解为先，大牛的实现理解原理后当模版直接调用。
