## 一、本节内容总览（三种排序一句话）
- 选择排序一句话：i~n-1 范围上，找到最小值并放在 i 位置，然后 i+1~n-1 范围上继续。
- 冒泡排序一句话：0~i 范围上，相邻位置较大的数滚下去，最大值最终来到 i 位置，然后 0~i-1 范围上继续。
- 插入排序一句话：0~i 范围上已经有序，新来的数从右到左滑到不再小的位置插入，然后继续。
## 二、交换函数 swap
- 三种排序都依赖数组中两个位置的交换，先封装一个 swap 方法。
```java
// 数组中交换i和j位置的数
public static void swap(int[] arr, int i, int j) {
    int tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
}
```
## 三、选择排序（Selection Sort）
- 思路：[0,i] 已经有序，[j,n-1] 是未排序区；每轮在未排序区中找到最小值的下标 minIndex，与 i 位置交换。
- 过程示意（数组 [5, 2, 4, 1]）：
  - i=0：在 0~3 范围找最小值 1，交换 -> [1, 2, 4, 5]
  - i=1：在 1~3 范围找最小值 2，不动 -> [1, 2, 4, 5]
  - i=2：在 2~3 范围找最小值 4，不动 -> [1, 2, 4, 5]，排序完成
```java
// 选择排序
public static void selectionSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }
    // [0,i][j,n-1],后面找minIndex与i交换
    for (int minIndex, i = 0; i < arr.length - 1; i++) {
        minIndex = i;
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        swap(arr, i, minIndex);
    }
}
```
## 四、冒泡排序（Bubble Sort）
- 思路：[0,j] 是未排序区，[i,n-1] 已经有序；每轮从左到右比较相邻两个数，较大的往后滚，一轮结束后最大值被推到 i 位置。
- 过程示意（数组 [5, 2, 4, 1]，第一轮 i=3）：
  - 5 和 2 比，交换 -> [2, 5, 4, 1]
  - 5 和 4 比，交换 -> [2, 4, 5, 1]
  - 5 和 1 比，交换 -> [2, 4, 1, 5]，最大值 5 到达最终位置
  - 之后 i=2、i=1 继续同样的过程
```java
// 冒泡排序
public static void bubbleSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }
    // [0,j][i,n-1],每次都将[0,i]中的最大值放到最终位置
    for (int i = arr.length - 1; i > 0; i--) {
        for (int j = 0; j < i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr, j, j + 1);
            }
        }
    }
}
```
## 五、插入排序（Insertion Sort）
- 思路：[0,j] 已经有序，新来的 i 位置的数从右往左依次与左边的数比较，只要比左边小就交换，滑到合适的位置停下来。
- 停止条件有两个：1）j 已经滑到最左端（j>=0 不成立）；2）不再比左边的数小。
- 过程示意（数组 [2, 4, 5, 1]，i=3 处理新来的 1）：
  - 1 和 5 比，交换 -> [2, 4, 1, 5]
  - 1 和 4 比，交换 -> [2, 1, 4, 5]
  - 1 和 2 比，交换 -> [1, 2, 4, 5]，1 到达正确位置
```java
// 插入排序
public static void insertionSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }
    // [0,j][i,n-1],新来的i插入到[0,j]合适的位置：1、j>=0；2、比左边的数小就停止
    for (int i = 1; i < arr.length; i++) {
        for (int j = i - 1; j >= 0 && arr[j] > arr[j + 1]; j--) {
            swap(arr, j, j + 1);
        }
    }
}
```
## 六、三种排序的共同点
- 写法上都是先把数组分成"已排序区"和"未排序区"，每轮把未排序区中的一个数放到正确位置。
- 三种排序的时间复杂度都是 O(n^2)，额外空间复杂度都是 O(1)。
- 数组长度小于 2 时直接返回，不需要排序。
