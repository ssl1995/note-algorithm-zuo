## 一、按值传递、按引用传递
- 很多同学犯错完全是语言问题，务必先搞清楚。
- 按值传递：int、long、byte、short、char、float、double、boolean，还有 String。方法里改参数，外面不受影响。
```java
public static void f(int a) {
    a = 0; // 只改了栈上的副本
}
int a = 10;
f(a);
System.out.println(a); // 输出 10，不变
```
- 按引用传递：其他类型（自定义类、数组等）。传的是"引用的副本"，副本和原引用指向堆上同一个对象：
- 1、方法里把参数指向 null / 新对象，只改了副本的指向，外面的引用不受影响；
- 2、方法里通过参数修改对象内部字段，外面的引用看到的是同一个对象，所以变了。
```java
public static class Number { public int val; public Number(int v) { val = v; } }
public static void g1(Number b) { b = null; }      // 改副本指向，无影响
public static void g2(Number b) { b.val = 6; }       // 改堆上对象，有影响
public static void g3(int[] c) { c = null; }         // 数组同理，无影响
public static void g4(int[] c) { c[0] = 100; }       // 数组同理，有影响
Number b = new Number(5);
g1(b); System.out.println(b.val); // 5
g2(b); System.out.println(b.val); // 6
int[] c = { 1, 2, 3, 4 };
g3(c); System.out.println(c[0]); // 1
g4(c); System.out.println(c[0]); // 100
```
- 堆栈视角：基本类型的值直接放在栈帧里；对象本体在堆上，栈上只存引用。方法调用时压入新栈帧，参数是值的拷贝或引用的拷贝，方法结束栈帧弹出，副本随之消失。
## 二、单链表、双链表的定义
```java
// 单链表节点
public static class ListNode {
    public int val;
    public ListNode next;
    public ListNode(int val) { this.val = val; }
    public ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
// 双链表节点
public static class DoubleListNode {
    public int value;
    public DoubleListNode last;
    public DoubleListNode next;
    public DoubleListNode(int v) { value = v; }
}
```
- 单链表：每个节点只有 next 指向下一个节点；双链表：每个节点同时有 last（前一个）和 next（后一个）。
## 三、反转单链表
- 测试链接：https://leetcode.cn/problems/reverse-linked-list/
- 思路：用 pre 和 next 两个引用辅助，边遍历边把每个节点的 next 指向前一个节点：
- 1、next = head.next：先记住后继，防止断链丢节点；
- 2、head.next = pre：反转指向；
- 3、pre = head：pre 前进；
- 4、head = next：head 前进。
```java
public static ListNode reverseList(ListNode head) {
    ListNode pre = null;
    ListNode next = null;
    while (head != null) {
        next = head.next;
        head.next = pre;
        pre = head;
        head = next;
    }
    return pre; // 循环结束时pre停在原尾节点，即新头节点
}
```
- 图解（以 1 -> 2 -> 3 为例，每轮循环的状态）：
```plain
初始: pre=null  head=1 -> 2 -> 3 -> null
第1轮: 1 -> null   pre=1  head=2 -> 3
第2轮: 2 -> 1 -> null   pre=2  head=3
第3轮: 3 -> 2 -> 1 -> null   pre=3  head=null，返回pre=3
```
## 四、反转双链表
- 与单链表几乎一样，只是反转指向时 next 和 last 要同时交换方向。
```java
public static DoubleListNode reverseDoubleList(DoubleListNode head) {
    DoubleListNode pre = null;
    DoubleListNode next = null;
    while (head != null) {
        next = head.next;
        head.next = pre;   // next指向前一个
        head.last = next;  // last指向后一个
        pre = head;
        head = next;
    }
    return pre;
}
```
