# 算法讲解011【入门】链表入门题目-两个链表相加
前置知识：理解链表及其基本调整 ｜ 建议：做过这个题的同学跳过
代码位置：src/class011/AddTwoNumbers.java ｜ 测试链接：https://leetcode.cn/problems/add-two-numbers/
## 一、题目描述
- 给你两个非空的链表，表示两个非负的整数。
- 它们每位数字都是按照逆序的方式存储的（个位在链表头），并且每个节点只能存储一位数字。
- 请你将两个数相加，并以相同形式返回一个表示和的链表。
- 你可以假设除了数字 0 之外，这两个数都不会以 0 开头。
- 示例：2 -> 4 -> 3（即 342）+ 5 -> 6 -> 4（即 465）= 7 -> 0 -> 8（即 807）。
## 二、解题思路
- 逆序存储正好符合"竖式加法从个位开始"的顺序，从头到尾遍历两个链表即可，无需反转。
- 每一轮做三件事：取两个链表当前位的值（链表走完就当 0）加上进位 carry 得到 sum；本位结果 val = sum % 10；新进位 carry = sum / 10。
- 用 ans 记录结果链表头（第一次创建节点时赋值），cur 始终指向结果链表的尾巴，不断往后挂新节点。
- 循环结束条件：h1 和 h2 都走完才停；但如果最后 carry 还是 1，要额外补一个节点（例如 5 + 5 = 10，需要多出一位）。
- 本实现都是生成新节点（为了教学好懂），实际也可以复用老链表的节点。
## 三、代码实现
```java
 public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
  ListNode dummy = new ListNode(-1);
  ListNode cur = dummy;

  int carry = 0;

  while (l1 != null || l2 != null) {
    // 每次sum都要重置=0
    int sum = 0;
    if (l1 != null) {
      sum += l1.val;
    }
    if (l2 != null) {
      sum += l2.val;
    }
    if (carry == 1) {
      sum += 1;
    }
    carry = sum / 10;
    int value = sum % 10;

    // l1和l2是同时遍历（已经null不移动），而不是只移动一个
    l1 = l1 == null ? null : l1.next;
    l2 = l2 == null ? null : l2.next;

    cur.next = new ListNode(value);
    cur = cur.next;
  }
  if (carry == 1) {
    cur.next = new ListNode(1);
  }

  return dummy.next;
}
```
## 四、过程图解（以 342 + 465 为例）
```plain
h1: 2 -> 4 -> 3      h2: 5 -> 6 -> 4
第1轮: sum=2+5+0=7   val=7 carry=0   结果: 7
第2轮: sum=4+6+0=10  val=0 carry=1   结果: 7 -> 0
第3轮: sum=3+4+1=8   val=8 carry=0   结果: 7 -> 0 -> 8
两链表均走完且carry=0，返回 7 -> 0 -> 8（即807）
```
## 五、复杂度与易错点
- 时间复杂度 O(max(M, N))，M、N 为两链表长度；空间复杂度 O(max(M, N))（生成新链表）。
- 易错点1：两链表不等长，走完的链表要当 0 处理，不能提前停。
- 易错点2：循环结束后忘记处理最后的进位 carry。
