## 一、为什么要学非递归遍历
- 递归遍历的本质是编译器/JVM 用系统栈帮我们保存了每一层的信息，非递归遍历就是自己开一个栈，把这套过程手动实现。
- 任何递归函数都可以改成非递归（自己压栈），二叉树遍历是最经典的练手场景，面试常考。
- 三种遍历的非递归实现难度递增：先序最简单，中序次之，后序最难。
- 示例树（代码中 main 方法建的树，与讲解017相同）：
```plain
        1
       / \
      2   3
     / \ / \
    4  5 6  7
先序: 1 2 4 5 3 6 7
中序: 4 2 5 1 6 3 7
后序: 4 5 2 6 7 3 1
```
## 二、用栈实现先序遍历
- 核心规则：栈中弹出一个节点就打印；先压右孩子，再压左孩子（栈后进先出，这样弹出时先处理左）。
- 流程：头节点入栈 -> 循环：弹栈打印 -> 右孩子非空压栈 -> 左孩子非空压栈。
```java
// 先序打印所有节点，非递归版
public static void preOrder(TreeNode head) {
    if (head != null) {
        Stack<TreeNode> stack = new Stack<>();
        stack.push(head);
        while (!stack.isEmpty()) {
            head = stack.pop();
            System.out.print(head.val + " ");
            if (head.right != null) {
                stack.push(head.right);
            }
            if (head.left != null) {
                stack.push(head.left);
            }
        }
    }
}
```
- 弹出顺序即打印顺序：1 -> 2 -> 4 -> 5 -> 3 -> 6 -> 7，正是先序。
## 三、用栈实现中序遍历
- 核心规则：每棵子树，先整条左边界依次入栈；左边界压完后，弹出节点打印，然后对弹出节点的右子树重复同样过程。
- 流程：cur 非空就压栈并走向左孩子；cur 为空就弹栈打印、走向右孩子。
```java
// 中序打印所有节点，非递归版
public static void inOrder(TreeNode head) {
    if (head != null) {
        Stack<TreeNode> stack = new Stack<>();
        while (!stack.isEmpty() || head != null) {
            if (head != null) {
                stack.push(head);
                head = head.left;
            } else {
                head = stack.pop();
                System.out.print(head.val + " ");
                head = head.right;
            }
        }
    }
}
```
- 以示例树走一遍：1、2、4 依次入栈（整条左边界）-> 弹 4 打印，4 无右树 -> 弹 2 打印，进入右子树 5 -> 5 入栈即弹出打印 -> 弹 1 打印，进入右子树 -> 3、6 入栈……最终得到 4 2 5 1 6 3 7。
## 四、用两个栈实现后序遍历（好写但不推荐）
- 核心规则：利用"先序是 头->左->右"，改成"头->右->左"（弹栈后先压左再压右），得到的序列逆过来就是"左->右->头"的后序。
- 流程：一个栈做"头右左"遍历，弹出节点不打印而是压入收集栈 collect；最后 collect 逆序弹出即后序。
- 缺点：需要收集所有节点再逆序弹出，额外空间复杂度为 O(n)，面试中不推荐。
```java
// 后序打印所有节点，非递归版，用两个栈的方法
public static void posOrderTwoStacks(TreeNode head) {
    if (head != null) {
        Stack<TreeNode> stack = new Stack<>();
        Stack<TreeNode> collect = new Stack<>();
        stack.push(head);
        while (!stack.isEmpty()) {
            head = stack.pop();
            collect.push(head);
            if (head.left != null) {
                stack.push(head.left);
            }
            if (head.right != null) {
                stack.push(head.right);
            }
        }
        while (!collect.isEmpty()) {
            System.out.print(collect.pop().val + " ");
        }
    }
}
```
- 对照理解：stack 弹出顺序（头右左）：1 3 7 6 2 5 4 -> collect 逆序弹出：4 5 2 6 7 3 1，即后序。
## 五、用一个栈实现后序遍历（重点）
- 核心规则：只用一个栈，借助变量 h 记录"上一次打印的节点"，据此判断当前节点的左右子树是否处理过：
  - 有左子树且左、右子树都没处理过（h 不是左右孩子）-> 压入左孩子
  - 否则有右子树且右子树没处理过（h 不是右孩子）-> 压入右孩子
  - 否则左右子树没有或都处理过了 -> 弹出打印，h 更新为该节点
- h 的初始值是头节点（此时还没打印过任何节点）；一旦打印过节点，h 就变成上一次打印的节点。
```java
// 后序打印所有节点，非递归版，用一个栈的方法
public static void posOrderOneStack(TreeNode h) {
    if (h != null) {
        Stack<TreeNode> stack = new Stack<>();
        stack.push(h);
        // 如果始终没有打印过节点，h就一直是头节点
        // 一旦打印过节点，h就变成打印节点
        // 之后h的含义 : 上一次打印的节点
        while (!stack.isEmpty()) {
            TreeNode cur = stack.peek();
            if (cur.left != null && h != cur.left && h != cur.right) {
                // 有左树且左树没处理过
                stack.push(cur.left);
            } else if (cur.right != null && h != cur.right) {
                // 有右树且右树没处理过
                stack.push(cur.right);
            } else {
                // 左树、右树 没有 或者 都处理过了
                System.out.print(cur.val + " ");
                h = stack.pop();
            }
        }
    }
}
```
- 关键细节：循环里用 stack.peek() 只看栈顶不弹出，只有左右子树都处理完才 pop 打印，保证节点第三次被看到时才输出。
## 六、复杂度分析（递归与非递归通用）
- 时间复杂度 O(n)：递归和非递归都是每个节点遇到有限几次（常数次），当然是 O(n)。
- 额外空间复杂度 O(h)：递归（系统栈）和非递归（自己的栈）都需要二叉树高度 h 的空间来保存路径，方便回到上级去。
- 存在时间复杂度 O(n)、额外空间复杂度 O(1) 的遍历方式：Morris 遍历（利用树中大量空闲的 null 指针记录回到上级的路径）。
- Morris 遍历比较难，也比较冷门，会在【扩展】课程里讲述。
## 七、总结与后续
- 非递归遍历 = 自己开栈模拟递归过程：先序"弹就打印、先压右再压左"；中序"左边界全入栈、弹出打印走右边"；后序一个栈 + h 标记上次打印节点。
- 后序双栈法好写但额外空间 O(n)，一个栈的方法才是标准答案。
- 代码中还给出了 LeetCode 144 / 94 / 145 的提交版实现（preorderTraversal / inorderTraversal / postorderTraversal），逻辑与打印版完全一致，只是把打印换成收集到 List。
