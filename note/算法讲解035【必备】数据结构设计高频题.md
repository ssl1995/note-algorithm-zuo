## 二、题目1：setAll 功能的哈希表（牛客）
- 测试链接：https://www.nowcoder.com/practice/7c4559f138e74ceb9ba57d76fd169967
- 要求：哈希表支持 put(k,v)、get(k)，额外支持 setAll(v) 把所有键的值一次性设为 v，全部操作 O(1)。
- 思路（时间戳法）：
  - 1）map 中每个键存的不是裸值，而是 int[]{值, 写入时间戳}；全局维护一个自增计数器 cnt。
  - 2）setAll(v) 不遍历 map，只记录全局的 setAllValue 和 setAllTime = cnt++。
  - 3）get(k) 时比较该键的写入时间戳和 setAllTime：写入时间晚于 setAll → 返回自己的值；早于或等于 setAll → 说明已被 setAll 覆盖，返回 setAllValue。
- 图示：
```text
put(1, 5)@t0  put(2, 7)@t1  setAll(9)@t2  put(1, 3)@t3
get(1): t3 > t2 → 返回 3（setAll 之后又写过）
get(2): t1 < t2 → 返回 setAllValue = 9（被 setAll 覆盖）
```
```java
public static HashMap<Integer, int[]> map = new HashMap<>();
public static int setAllValue;
public static int setAllTime;
public static int cnt;
public static void put(int k, int v) {
    if (map.containsKey(k)) {
        int[] value = map.get(k);
        value[0] = v;
        value[1] = cnt++;
    } else {
        map.put(k, new int[] { v, cnt++ });
    }
}
public static void setAll(int v) {
    setAllValue = v;
    setAllTime = cnt++;
}
public static int get(int k) {
    if (!map.containsKey(k)) {
        return -1;
    }
    int[] value = map.get(k);
    if (value[1] > setAllTime) {
        return value[0]; // put 发生在最近一次 setAll 之后
    } else {
        return setAllValue; // 已被 setAll 覆盖
    }
}
```
- 复杂度：put / get / setAll 均 O(1)。
- 关键点：setAll 绝不遍历，用"时间戳比较"把批量操作 lazy 化，这是设计类题目的经典思想。
## 三、题目2：实现 LRU 结构（LeetCode 146，LRU 缓存）
- 测试链接：https://leetcode.cn/problems/lru-cache/
- 要求：get / put 均 O(1)，容量满时淘汰最久未使用的键。
- 思路（哈希表 + 双向链表）：
  - 1）双向链表按"新旧程度"排序：头 = 最久未使用，尾 = 最近使用。
  - 2）哈希表 keyNodeMap 记录 key → 节点，实现 O(1) 定位。
  - 3）get：查到节点后 moveNodeToTail（变成最近使用），返回 val。
  - 4）put：已存在则改值并移到尾部；不存在则先判断容量，满了就 removeHead（淘汰最久未使用）并同步从 map 删除，再把新节点加到尾部。
- 图示：
```text
容量=3，依次 put(1)(2)(3):  头[1, 2, 3]尾
get(1) 后:                  头[2, 3, 1]尾  (1被移到尾部)
put(4) 超容量: 淘汰头节点2 → 头[3, 1, 4]尾
```
```java
class LRUCache {
    class DoubleNode {
        public int key, val;
        public DoubleNode last, next;
        public DoubleNode(int k, int v) { key = k; val = v; }
    }
    class DoubleList {
        private DoubleNode head, tail;
        public void addNode(DoubleNode newNode) { // 加到尾部（最新）
            if (newNode == null) return;
            if (head == null) {
                head = newNode; tail = newNode;
            } else {
                tail.next = newNode;
                newNode.last = tail;
                tail = newNode;
            }
        }
        public void moveNodeToTail(DoubleNode node) { // 访问后变为最新
            if (tail == node) return;
            if (head == node) {
                head = node.next;
                head.last = null;
            } else {
                node.last.next = node.next;
                node.next.last = node.last;
            }
            node.last = tail;
            node.next = null;
            tail.next = node;
            tail = node;
        }
        public DoubleNode removeHead() { // 淘汰最久未使用
            if (head == null) return null;
            DoubleNode ans = head;
            if (head == tail) {
                head = null; tail = null;
            } else {
                head = ans.next;
                ans.next = null;
                head.last = null;
            }
            return ans;
        }
    }
    private HashMap<Integer, DoubleNode> keyNodeMap;
    private DoubleList nodeList;
    private final int capacity;
    public int get(int key) {
        if (keyNodeMap.containsKey(key)) {
            DoubleNode ans = keyNodeMap.get(key);
            nodeList.moveNodeToTail(ans);
            return ans.val;
        }
        return -1;
    }
    public void put(int key, int value) {
        if (keyNodeMap.containsKey(key)) {
            DoubleNode node = keyNodeMap.get(key);
            node.val = value;
            nodeList.moveNodeToTail(node);
        } else {
            if (keyNodeMap.size() == capacity) {
                keyNodeMap.remove(nodeList.removeHead().key); // 链表和map同步删
            }
            DoubleNode newNode = new DoubleNode(key, value);
            keyNodeMap.put(key, newNode);
            nodeList.addNode(newNode);
        }
    }
}
```
- 复杂度：get / put 均 O(1)。
- 易错点：链表删除和 map 删除必须同步（removeHead 后立刻 keyNodeMap.remove）；moveNodeToTail 要正确处理"节点是头/是尾/在中间"三种情况。
- 扩展：Java 的 LinkedHashMap 本身就是哈希表+双向链表，设置 accessOrder=true 可直接当 LRU 用，面试能手写就别偷懒。
## 四、题目3：插入、删除和获取随机元素 O(1) 时间的结构（LeetCode 380）
- 测试链接：https://leetcode.cn/problems/insert-delete-getrandom-o1/
- 思路（哈希表 + 动态数组）：
  - 1）getRandom 要 O(1) 等概率，必须用数组按下标随机：arr.get(random * size)。
  - 2）map 记录 值 → 在数组中的下标，insert 时追加到数组尾部。
  - 3）remove 核心技巧——"填坑法"：要删 val，先取出数组末尾元素 endValue，把 endValue 填到 val 的位置（同时更新 map 中 endValue 的下标），然后删除数组末尾。数组中间删除由此变成 O(1)。
- 图示（删除 20）：
```text
arr = [10, 20, 30, 40]   map: 10→0, 20→1, 30→2, 40→3
删除20: 用末尾40填下标1 → arr = [10, 40, 30]
        map: 40→1, 删掉20
```
```java
class RandomizedSet {
    public HashMap<Integer, Integer> map; // 值 -> 下标
    public ArrayList<Integer> arr;
    public boolean insert(int val) {
        if (map.containsKey(val)) {
            return false;
        }
        map.put(val, arr.size());
        arr.add(val);
        return true;
    }
    public boolean remove(int val) {
        if (!map.containsKey(val)) {
            return false;
        }
        int valIndex = map.get(val);
        int endValue = arr.get(arr.size() - 1);
        map.put(endValue, valIndex);       // 末尾元素换到被删位置
        arr.set(valIndex, endValue);
        map.remove(val);
        arr.remove(arr.size() - 1);        // 删末尾 O(1)
        return true;
    }
    public int getRandom() {
        return arr.get((int) (Math.random() * arr.size()));
    }
}
```
- 复杂度：insert / remove / getRandom 均 O(1)。
- 注意：remove 中更新 map 和 arr 的顺序无所谓，但"先填坑、后删末尾"的逻辑不能乱；val 恰好是末尾元素时填坑等于自己覆盖自己，不影响正确性。
## 五、题目4：允许重复数字的随机结构（LeetCode 381）
- 测试链接：https://leetcode.cn/problems/insert-delete-getrandom-o1-duplicates-allowed/
- 与题目3的区别：同一值可出现多次。map 的值从"单个下标"升级为"下标集合 HashSet"。
- 思路：
  - 1）insert：直接追加到 arr 尾部，把新下标加入该值的 set，返回 set.size()==1（首次出现返回 true）。
  - 2）remove：从 val 的 set 中任取一个下标 valAnyIndex，用末尾元素填坑——注意要先更新末尾元素的 set（加新下标、删旧下标），再删 val 的下标；val 的 set 空了就从 map 移除该键。
  - 3）特判：若 val 本身就是末尾元素，直接删自己那个下标即可，避免先加后删把自己冲掉。
- 图示（删除一个 20，末尾恰好也是 20 的另一种情况需特判）：
```text
arr = [10, 20, 30, 20]   map: 10→{0}, 20→{1,3}, 30→{2}
删除20: 取valAnyIndex=1, 末尾endValue=20 == val → 直接 valSet.remove(3)
        arr = [10, 20, 30]  map: 20→{1}
若末尾是30: 30的set {2}→{1}, arr[1]=30, 再 valSet.remove(1)
```
```java
class RandomizedCollection {
    public HashMap<Integer, HashSet<Integer>> map; // 值 -> 所有下标
    public ArrayList<Integer> arr;
    public boolean insert(int val) {
        arr.add(val);
        HashSet<Integer> set = map.getOrDefault(val, new HashSet<Integer>());
        set.add(arr.size() - 1);
        map.put(val, set);
        return set.size() == 1;
    }
    public boolean remove(int val) {
        if (!map.containsKey(val)) {
            return false;
        }
        HashSet<Integer> valSet = map.get(val);
        int valAnyIndex = valSet.iterator().next();
        int endValue = arr.get(arr.size() - 1);
        if (val == endValue) {
            valSet.remove(arr.size() - 1); // 删除的就在末尾，直接删下标
        } else {
            HashSet<Integer> endValueSet = map.get(endValue);
            endValueSet.add(valAnyIndex);       // 末尾元素搬新位置
            arr.set(valAnyIndex, endValue);
            endValueSet.remove(arr.size() - 1); // 末尾元素旧下标作废
            valSet.remove(valAnyIndex);
        }
        arr.remove(arr.size() - 1);
        if (valSet.isEmpty()) {
            map.remove(val);
        }
        return true;
    }
    public int getRandom() {
        return arr.get((int) (Math.random() * arr.size()));
    }
}
```
- 复杂度：insert / remove / getRandom 均 O(1)（HashSet 增删查均摊 O(1)）。
- 等概率正确性：重复元素在 arr 中占多个位置，随机下标天然按出现次数加权，满足"等概率返回元素"的要求。
## 六、题目5：快速获得数据流的中位数的结构（LeetCode 295）
- 测试链接：https://leetcode.cn/problems/find-median-from-data-stream/
- 思路（大根堆 + 小根堆，对顶堆）：
  - 1）大根堆 maxHeap 存较小的一半，小根堆 minHeap 存较大的一半；中位数就在两个堆顶。
  - 2）addNum：num ≤ 大根堆堆顶（或大根堆空）进大根堆，否则进小根堆。
  - 3）balance：两边 size 差达到 2 时，把多的一边堆顶弹给少的一边，保证 |size差| ≤ 1。
  - 4）findMedian：size 相等 → 两堆顶平均；不等 → 多的那边堆顶即中位数。
- 图示：
```text
加入 [5, 2, 8, 1] 后:
maxHeap(小的一半): [2, 1]   堆顶2
minHeap(大的一半): [5, 8]   堆顶5
中位数 = (2 + 5) / 2 = 3.5
再加入3: 3<=2?否→进minHeap, size差=2 → minHeap堆顶3弹给maxHeap
maxHeap堆顶=3 → 中位数 = 3
```
```java
class MedianFinder {
    private PriorityQueue<Integer> maxHeap; // 较小的一半，大根堆
    private PriorityQueue<Integer> minHeap; // 较大的一半，小根堆
    public MedianFinder() {
        maxHeap = new PriorityQueue<>((a, b) -> b - a);
        minHeap = new PriorityQueue<>((a, b) -> a - b);
    }
    public void addNum(int num) {
        if (maxHeap.isEmpty() || maxHeap.peek() >= num) {
            maxHeap.add(num);
        } else {
            minHeap.add(num);
        }
        balance();
    }
    public double findMedian() {
        if (maxHeap.size() == minHeap.size()) {
            return (double) (maxHeap.peek() + minHeap.peek()) / 2;
        } else {
            return maxHeap.size() > minHeap.size() ? maxHeap.peek() : minHeap.peek();
        }
    }
    private void balance() {
        if (Math.abs(maxHeap.size() - minHeap.size()) == 2) {
            if (maxHeap.size() > minHeap.size()) {
                minHeap.add(maxHeap.poll());
            } else {
                maxHeap.add(minHeap.poll());
            }
        }
    }
}
```
- 复杂度：addNum O(log n)，findMedian O(1)。
- 关键点："大根堆放小数、小根堆放大数"容易记反——记住两个堆顶夹着中位数；平衡条件用"差值为2再调整"而不是每次强行相等，可少一次堆操作。
## 七、题目6：最大频率栈（LeetCode 895）
- 测试链接：https://leetcode.cn/problems/maximum-frequency-stack/
- 要求：push 入栈；pop 弹出"出现频率最高"的元素，频率并列时弹出最接近栈顶的。
- 思路（分层栈）：
  - 1）valueTimes 记录每个值当前出现次数。
  - 2）cntValues：频率 → 该频率层上的值列表（按入栈先后排列，相当于每层一个栈）。一个值出现第 k 次时，把它压进第 k 层。
  - 3）topTimes 记录当前最大频率。
  - 4）push：次数 +1，压入对应层，更新 topTimes。
  - 5）pop：从 topTimes 层弹出末尾元素（同频率下最后压入 = 最接近栈顶）；该层空了删层并 topTimes--；同步维护 valueTimes。
- 图示：
```text
push序列: 5, 7, 5, 7, 4, 5
第1层: [5, 7, 4]     (各值第1次出现)
第2层: [5, 7]        (各值第2次出现)
第3层: [5]           topTimes=3
pop → 第3层弹5；再pop → 第2层弹7（同层后进的先出）
```
```java
class FreqStack {
    private int topTimes; // 出现的最大次数
    private HashMap<Integer, ArrayList<Integer>> cntValues = new HashMap<>(); // 每层节点
    private HashMap<Integer, Integer> valueTimes = new HashMap<>(); // 每个数出现几次
    public void push(int val) {
        valueTimes.put(val, valueTimes.getOrDefault(val, 0) + 1);
        int curTopTimes = valueTimes.get(val);
        if (!cntValues.containsKey(curTopTimes)) {
            cntValues.put(curTopTimes, new ArrayList<>());
        }
        ArrayList<Integer> curTimeValues = cntValues.get(curTopTimes);
        curTimeValues.add(val);
        topTimes = Math.max(topTimes, curTopTimes);
    }
    public int pop() {
        ArrayList<Integer> topTimeValues = cntValues.get(topTimes);
        int ans = topTimeValues.remove(topTimeValues.size() - 1);
        if (topTimeValues.size() == 0) {
            cntValues.remove(topTimes--); // 当前最高层空了，最大频率-1
        }
        int times = valueTimes.get(ans);
        if (times == 1) {
            valueTimes.remove(ans);
        } else {
            valueTimes.put(ans, times - 1);
        }
        return ans;
    }
}
```
- 复杂度：push / pop 均 O(1)（ArrayList 尾部增删）。
- 精妙之处：一个值每多出现一次就往"更高一层"压一份，pop 高层的值自然满足频率优先；同一层内后进先出自然满足"接近栈顶优先"，不需要任何排序。
## 八、题目7：全 O(1) 的数据结构（LeetCode 432）
- 测试链接：https://leetcode.cn/problems/all-oone-data-structure/
- 要求：inc(key)、dec(key)、getMaxKey()、getMinKey() 全部 O(1)。
- 思路（桶 + 双向链表 + 哈希表，本题最难）：
  - 1）桶 Bucket：计数 cnt + 该计数的所有 key 的 HashSet。所有桶按 cnt 从小到大串成双向链表。
  - 2）哨兵设计：head（cnt=0）、tail（cnt=MAX_VALUE）两个虚拟桶，消除边界判断；getMinKey 取 head.next，getMaxKey 取 tail.last。
  - 3）map：key → 所在桶，O(1) 定位。
  - 4）inc：key 不存在 → 看 head.next 是不是 cnt=1 的桶，是则加入，否则在 head 后新建 cnt=1 桶；key 存在 → 从当前桶移到 cnt+1 的桶（下一个桶恰好是 cnt+1 就直接进，否则在当前桶后新建），原桶空了则删除。
  - 5）dec：对称操作；cnt=1 的 key 直接 dec 成 0，从 map 删除。
- 图示（inc("a") 两次、inc("b") 一次后）：
```text
head(0) <-> [cnt1: {b}] <-> [cnt2: {a}] <-> tail(MAX)
getMinKey → b    getMaxKey → a
再 inc("b"): b 从cnt1桶移到cnt2桶 → [cnt2: {a,b}]，cnt1桶空了被删除
```
```java
class AllOne {
    class Bucket {
        public HashSet<String> set;
        public int cnt;
        public Bucket last, next;
        public Bucket(String s, int c) {
            set = new HashSet<>();
            set.add(s);
            cnt = c;
        }
    }
    private void insert(Bucket cur, Bucket pos) { // 在cur后面插入pos
        cur.next.last = pos;
        pos.next = cur.next;
        cur.next = pos;
        pos.last = cur;
    }
    private void remove(Bucket cur) {
        cur.last.next = cur.next;
        cur.next.last = cur.last;
    }
    Bucket head, tail;
    HashMap<String, Bucket> map;
    public AllOne() {
        head = new Bucket("", 0);
        tail = new Bucket("", Integer.MAX_VALUE);
        head.next = tail;
        tail.last = head;
        map = new HashMap<>();
    }
    public void inc(String key) {
        if (!map.containsKey(key)) {
            if (head.next.cnt == 1) {
                map.put(key, head.next);
                head.next.set.add(key);
            } else {
                Bucket newBucket = new Bucket(key, 1);
                map.put(key, newBucket);
                insert(head, newBucket);
            }
        } else {
            Bucket bucket = map.get(key);
            if (bucket.next.cnt == bucket.cnt + 1) {
                map.put(key, bucket.next);
                bucket.next.set.add(key);
            } else {
                Bucket newBucket = new Bucket(key, bucket.cnt + 1);
                map.put(key, newBucket);
                insert(bucket, newBucket);
            }
            bucket.set.remove(key);
            if (bucket.set.isEmpty()) {
                remove(bucket);
            }
        }
    }
    public void dec(String key) {
        Bucket bucket = map.get(key);
        if (bucket.cnt == 1) {
            map.remove(key);
        } else {
            if (bucket.last.cnt == bucket.cnt - 1) {
                map.put(key, bucket.last);
                bucket.last.set.add(key);
            } else {
                Bucket newBucket = new Bucket(key, bucket.cnt - 1);
                map.put(key, newBucket);
                insert(bucket.last, newBucket);
            }
        }
        bucket.set.remove(key);
        if (bucket.set.isEmpty()) {
            remove(bucket);
        }
    }
    public String getMaxKey() {
        return tail.last.set.iterator().next();
    }
    public String getMinKey() {
        return head.next.set.iterator().next();
    }
}
```
- 复杂度：inc / dec / getMaxKey / getMinKey 均 O(1)。
- 核心不变式：链表上的桶 cnt 严格递增且不留空桶，所以"相邻桶 cnt 一定差 1（否则要新建桶）"是移动逻辑的依据；哨兵桶保证 head.next / tail.last 永远存在。
## 九、本节课总结
- 数据结构设计的万能公式：哈希表（O(1) 定位）+ 一种维持顺序/结构关系的载体（双向链表 / 动态数组 / 堆 / 桶链表）。
- 经典搭配回顾：
  - 哈希表 + 时间戳 → setAll 哈希表（懒标记思想）。
  - 哈希表 + 双向链表 → LRU、全 O(1) 结构（顺序关系用链表维护）。
  - 哈希表 + 动态数组 + 末尾填坑 → O(1) 随机集合（删除变 O(1) 的关键）。
  - 大根堆 + 小根堆 → 数据流中位数（对顶堆夹中值）。
  - 哈希表 + 分层栈 → 最大频率栈（一层一频率，天然有序）。
- 写这类题的重点不是算法设计而是 coding 细节：链表增删的边界、map 与结构的同步、空结构的特判，务必多写多练。
