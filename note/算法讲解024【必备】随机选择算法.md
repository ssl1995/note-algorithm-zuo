# 算法讲解024【必备】随机选择算法
前置知识：讲解023-随机快速排序（荷兰国旗问题划分、随机选值的复杂度收敛）
代码位置：src/class024/RandomizedSelect.java
测试链接：LeetCode 215 数组中的第K个最大元素（https://leetcode.cn/problems/kth-largest-element-in-an-array/）
## 一、问题：无序数组中寻找第K大的数
- 题目：给定整数数组 nums 和整数 k，返回数组中第 k 个最大的元素。注意是排序后的第 k 个最大元素，而不是第 k 个不同的元素（数组中可能有重复值）。
- 要求：必须设计并实现时间复杂度为 O(n) 的算法解决此问题。
- 如果先排序再找，时间复杂度是 O(n * logn)，不达标；利用改写快排的方法可以做到时间复杂度 O(n)，额外空间复杂度 O(1)，这就是随机选择算法（Randomized Select），是常考内容！
## 二、整体思路：改写快速排序，只走一侧
- 第 k 大的数，等价于"如果数组升序排序，下标为 n - k 位置的数字"，所以问题转化为：找排序后下标 i 位置上的数。
- 借用随机快速排序的荷兰国旗划分：每次在 arr[l...r] 上随机选一个值 x，partition 后数组分成 <x | ==x | >x 三段，==x 区域是 [first, last]。
- 关键区别：快排划分后左右两侧都要递归，而随机选择划分后只需要走一侧：
  - i < first：目标在 <x 区域，收缩右边界 r = first - 1。
  - i > last：目标在 >x 区域，收缩左边界 l = last + 1。
  - first <= i <= last：i 位置就是 x，直接返回 arr[i]。
- 因为只走一侧，可以用循环代替递归，所以额外空间复杂度 O(1)；也正因为只走一侧，不需要临时变量记录全局的 first、last，直接用即可。
- 以 arr = {3, 2, 1, 5, 6, 4}、k = 2 为例（找第2大，即排序后下标 i = 6-2 = 4 的数）：
```plain
目标下标 i = 4，范围 [0, 5]: [3, 2, 1, 5, 6, 4]
第1轮: 随机选到 x=3，划分后 [<3: 2,1 | ==3 | >3: 5,6,4]
       first=2, last=2，i=4 > last -> 只走右侧，l = 3，范围 [3, 5]
第2轮: 随机选到 x=6，划分后 [<6: 5,4 | ==6]
       first=5, last=5，i=4 < first -> 只走左侧，r = 4，范围 [3, 4]
第3轮: 随机选到 x=4，划分后 [==4 | >4: 5]
       first=3, last=3，i=4 > last -> l = 4，范围 [4, 4]
第4轮: 只剩一个数5，first=last=4，命中 i，返回 5（第2大的数，正确）
```
- 对比快排：快排每层两个子问题都要处理，每层总代价 O(n)、共 O(logn) 层，得 O(n * logn)；随机选择每层只处理一个子问题，代价按 n + n/2 + n/4 + ... 收敛，期望 O(n)。
## 三、代码实现
```java
// 随机选择算法，时间复杂度O(n)
public static int findKthLargest(int[] nums, int k) {
    return randomizedSelect(nums, nums.length - k);
}
// 如果arr排序的话，在i位置的数字是什么
public static int randomizedSelect(int[] arr, int i) {
    int ans = 0;
    for (int l = 0, r = arr.length - 1; l <= r;) {
        // 随机这一下，常数时间比较大
        // 但只有这一下随机，才能在概率上把时间复杂度收敛到O(n)
        partition(arr, l, r, arr[l + (int) (Math.random() * (r - l + 1))]);
        // 因为左右两侧只需要走一侧
        // 所以不需要临时变量记录全局的first、last，直接用即可
        if (i < first) {
            r = first - 1;
        } else if (i > last) {
            l = last + 1;
        } else {
            ans = arr[i];
            break;
        }
    }
    return ans;
}
// 荷兰国旗问题（与随机快排的partition2完全一致）
public static int first, last;
public static void partition(int[] arr, int l, int r, int x) {
    first = l;
    last = r;
    int i = l;
    while (i <= last) {
        if (arr[i] == x) {
            i++;
        } else if (arr[i] < x) {
            swap(arr, first++, i++);
        } else {
            swap(arr, i, last--);
        }
    }
}
```
- 入口细节：findKthLargest 传入 nums.length - k，把"第 k 大"翻译成"升序排序后的下标"。
## 四、复杂度分析与说明
- 随机选择算法：时间复杂度 O(n)（期望），额外空间复杂度 O(1)（迭代写法，partition 都是原地的）。
- 与随机快排同理：随机选值让任何人构造的数据都无法针对划分结果，时间复杂度按概率期望收敛到 O(n)。
- 复杂度证明理解起来很困难，只需记住结论，不会对后续的算法学习造成影响；因为数学很好才能理解的算法其实比较少，绝大部分内容高中数学基础就能理解。本课定性讲述，定量证明见《算法导论》9.2 节。
- 扩展：《算法导论》第9章还有一个 BFPRT 算法（中位数的中位数），不用随机选择的方式也能严格做到时间复杂度 O(n)，额外空间复杂度 O(logn)。但很冷门，很少在笔试、面试、比赛场合出现，有兴趣可以自行研究。
## 五、总结
- 随机选择算法 = 随机快排的荷兰国旗划分 + 只递归（循环）目标所在的一侧。
- 求第 k 大即求升序排序后下标 n - k 位置的数；划分后按 i 与 [first, last] 的关系收缩一侧边界，命中 ==x 区域即返回。
- 时间复杂度期望 O(n)，额外空间 O(1)；partition 与随机快排完全复用。
- 证明略（算法导论 9.2），记住结论即可；BFPRT 可严格 O(n) 但冷门，了解即可。
