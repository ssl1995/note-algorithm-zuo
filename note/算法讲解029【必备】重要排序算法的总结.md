# 算法讲解029【必备】重要排序算法的总结
前置知识：之前讲过的所有排序（选择、冒泡、插入、归并、随机快排、堆排序、计数排序、基数排序），本节是总结课，无新增代码
## 一、什么是排序的稳定性
- 定义：同样大小的样本，在排序之后不会改变原始的相对次序，这样的排序算法称为稳定的。
- 举例：数组中有两个 5，排序前红 5 在黑 5 前面，排序后红 5 仍然在黑 5 前面，就是稳定的；如果可能颠倒，就是不稳定的。
- 对基础类型（int、double 等）毫无意义：两个 5 交换了你根本看不出来。
- 对非基础类型（自定义对象）有意义：比如先按年龄排序，再按收入稳定排序，收入相同的人仍保持年龄的相对次序，相当于保留了上一轮的排序信息。
- 面试中常被问：某某排序稳不稳定？为什么？答不上来说明对算法过程理解不透。
## 二、每个算法的稳定性说明
- 选择排序：不稳定。找到最小值后与 i 位置交换，交换动作可能把 i 位置的数"扔"到后面相等元素的后面。例：[5a, 5b, 3] -> 3 和 5a 交换 -> [3, 5b, 5a]，5a 跑到了 5b 后面。
- 冒泡排序：稳定。只有相邻两个数严格大于才交换，相等时不交换，相对次序永远不变。
- 插入排序：稳定。新数从右往左滑，遇到小于等于自己的数就停下插入，不会越过相等元素。
- 归并排序：稳定。merge 时左右相等先拷贝左组的数，只要写代码时注意这一点即可保证稳定。
- 快速排序：不稳定。partition 过程中元素被成块交换，无法保证相等元素的原始次序。
- 堆排序：不稳定。建堆和 heapify 的下沉过程是大跨度交换，相对次序必然被打乱。
- 计数排序：稳定（按词频统计的思路可以实现稳定版本）。
- 基数排序：稳定。每一趟按某一位入桶出桶都是先进先出，相等元素次序不变。
## 三、时间、空间、稳定性总结表（必须背下来）
| 排序算法 | 时间复杂度 | 额外空间复杂度 | 稳定性 |
| --- | --- | --- | --- |
| 选择排序 SelectionSort | O(N^2) | O(1) | 无 |
| 冒泡排序 BubbleSort | O(N^2) | O(1) | 有 |
| 插入排序 InsertionSort | O(N^2) | O(1) | 有 |
| 归并排序 MergeSort | O(N*logN) | O(N) | 有 |
| 随机快排 QuickSort | O(N*logN) | O(logN) | 无 |
| 堆排序 HeapSort | O(N*logN) | O(1) | 无 |
| 计数排序 CountSort | O(N) | O(M) | 有 |
| 基数排序 RadixSort | O(N) | O(M) | 有 |
- 注意 1：随机快速排序的复杂度一定要按照概率上的期望指标来估计，用最差复杂度估计无意义（随机选择让划分位置在概率上均匀，期望收敛到 O(N*logN)），随机快排讲解视频里已有详细说明。
- 注意 2：计数排序、基数排序的 O(N) 是有前提的，要求样本范围（桶的个数 M）有限，并非真正意义上的"突破比较排序下界"。
## 四、核心代码回顾（每种排序最精华的一段）
- 选择排序：每轮在未排序区找最小值与 i 位置交换。
```java
for (int minIndex, i = 0; i < arr.length - 1; i++) {
    minIndex = i;
    for (int j = i + 1; j < arr.length; j++) {
        if (arr[j] < arr[minIndex]) {
            minIndex = j;
        }
    }
    swap(arr, i, minIndex); // 这一下交换破坏了稳定性
}
```
- 冒泡排序：相邻比较，大的往后滚，相等不交换（稳定的根源）。
```java
for (int i = arr.length - 1; i > 0; i--) {
    for (int j = 0; j < i; j++) {
        if (arr[j] > arr[j + 1]) { // 严格大于才交换，所以稳定
            swap(arr, j, j + 1);
        }
    }
}
```
- 插入排序：新数往左滑，滑到不再比自己小的位置停下（稳定的根源）。
```java
for (int i = 1; i < arr.length; i++) {
    for (int j = i - 1; j >= 0 && arr[j] > arr[j + 1]; j--) {
        swap(arr, j, j + 1); // 相等就停，不越过相等元素
    }
}
```
- 归并排序：merge 时相等先拷贝左组（稳定的根源），时间 O(N*logN)，空间 O(N)。
```java
public static void merge(int[] arr, int l, int m, int r) {
    int[] help = new int[r - l + 1];
    int i = 0, p1 = l, p2 = m + 1;
    while (p1 <= m && p2 <= r) {
        help[i++] = arr[p1] <= arr[p2] ? arr[p1++] : arr[p2++]; // <= 先拷左组，保证稳定
    }
    while (p1 <= m) help[i++] = arr[p1++];
    while (p2 <= r) help[i++] = arr[p2++];
    for (i = 0; i < help.length; i++) arr[l + i] = help[i];
}
```
- 随机快排：随机选一个数做划分，期望 O(N*logN)，额外空间 O(logN)（递归栈深度）。
```java
public static void quickSort(int[] arr, int l, int r) {
    if (l >= r) return;
    // 只有这一下随机，才能在概率上把时间复杂度收敛到O(n * logn)
    int x = arr[l + (int) (Math.random() * (r - l + 1))];
    int mid = partition(arr, l, r, x);
    quickSort(arr, l, mid - 1);
    quickSort(arr, mid + 1, r);
}
```
- 堆排序：从底到顶建大根堆 O(N)，依次弹出堆顶 O(N*logN)，额外空间 O(1)。
```java
for (int i = n - 1; i >= 0; i--) {
    heapify(i, n); // 从底到顶建立大根堆，O(n)
}
int size = n;
while (size > 1) {
    swap(0, --size); // 堆顶最大值换到末尾
    heapify(0, size); // 重新调整堆
}
```
## 五、一个"不可能"与两个不常用的排序
- 基于比较的排序中，同时满足时间 O(N*logN)、额外空间低于 O(N)、还具有稳定性的算法，目前没有找到。
- TimSort 也不行：虽然实际应用中它通常不需要那么多额外空间，但空间复杂度指标就是 O(N)。Java 中对象排序（Arrays.sort 对引用类型）用的就是 TimSort，因为对象排序需要稳定性；基础类型排序用的是优化版快排，因为基础类型不在乎稳定性。
- 希尔排序（ShellSort）：就是加入步长调整的插入排序，面试、笔试、比赛中都很少用，有兴趣可以自行研究。
- 结论：不要试图寻找"又快、又省空间、又稳定"的完美比较排序，工程上是按需求做取舍。
## 六、工程上怎么选排序（一切看你在乎什么）
- 数据量非常小（一般认为 N < 60）要迅速排完：插入排序。数据量小且近乎有序时它的常数项极低，常作为其他排序的补丁（TimSort、JDK 的 DualPivotQuickSort 都在小区间上转插入排序）。
- 在乎性能、实现简单且利于改进（面对不同业务可选不同划分策略）、不在乎稳定性：随机快排。常数项小，实测最快，partition 思想还能迁移到大量题目。
- 在乎性能、不在乎额外空间占用、要求稳定性：归并排序。唯一 O(N*logN) 级别的稳定排序，且归并思想是小和问题、逆序对问题的核心。
- 在乎性能、额外空间必须 O(1)、不在乎稳定性：堆排序。理论上唯一同时做到 O(N*logN) 和 O(1) 空间的比较排序。
- 数据范围有限（如年龄 0~200、字节 0~255）：计数排序/基数排序，直接做到 O(N)。
## 七、面试速记口诀
- 时间 O(N^2) 三兄弟：选、冒、插，只有"选"不稳定。
- 时间 O(N*logN) 三剑客：归、快、堆，只有"归"是稳定的。
- 空间：归并 O(N) 最大，快排 O(logN) 是递归栈，其余都是 O(1)。
- 不基于比较的两个：计数、基数，O(N) 但要求数据范围有限，都稳定。
