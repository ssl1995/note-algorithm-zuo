## 一、本节内容概览
- 1）在有序数组中确定 num 存在还是不存在
- 2）在有序数组中找 >=num 的最左位置
- 3）在有序数组中找 <=num 的最右位置
- 4）二分搜索不一定发生在有序数组上（比如寻找峰值问题）
- 5）"二分答案法"这个非常重要的算法，很秀很厉害，将在【必备】课程里继续
- 如果数组长度为 n，那么二分搜索次数是 log n 次（以 2 为底），时间复杂度 O(log n)，下节课详细讲时间复杂度
## 二、问题1：有序数组中确定 num 是否存在（Code01）
- 前提：数组必须有序。每次看中间位置 m，根据 arr[m] 与 num 的大小关系排除掉一半区间。
- 口诀：找到就返回 true；arr[m] 比 num 大，说明答案只可能在左边，r 左移；反之 l 右移。
```java
// 二分搜索：保证arr有序，才能用这个方法
public static boolean exist(int[] arr, int num) {
    if (arr == null || arr.length == 0) {
        return false;
    }
    int l = 0, r = arr.length - 1, m = 0;
    while (l <= r) {
        m = (l + r) / 2;
        if (arr[m] == num) {
            return true;
        } else if (arr[m] > num) {
            r = m - 1;
        } else {
            l = m + 1;
        }
    }
    return false;
}
```
- 正确性验证：用对数器（海量随机样本 + 暴力遍历 right 方法比对），50 万次测试通过即可确认无误。
## 三、问题2：有序数组中找 >=num 的最左位置（Code02）
- 与问题1的区别：找到满足条件的 m 不能直接返回，因为它右边可能还有、左边也可能还有更靠左的满足条件的位置，要先记录 ans，再继续向左收缩。
- 写法要点（闭区间 [l, r] 写法）：
- 1、遇到 arr[m] >= num，先记录 ans = m，然后 r = m - 1 继续往左找更优解；
- 2、arr[m] < num 时 l = m + 1；ans 初始为 -1，表示"没找到"。
```java
// 有序数组中找>=num的最左位置，没找到返回-1
public static int findLeft(int[] arr, int num) {
    int l = 0, r = arr.length - 1, m = 0;
    int ans = -1;
    while (l <= r) {
        m = l + ((r - l) >> 1); // 防溢出的中点写法
        if (arr[m] >= num) {
            ans = m;   // 先记录候选答案
            r = m - 1; // 再往左找更靠左的
        } else {
            l = m + 1;
        }
    }
    return ans;
}
```
- 另一种常见写法是左闭右开区间 [left, right)，right 初始为 n、循环条件 left < right、收缩时 right = mid，循环结束后 left 就是"第一个 >= num 的位置"（插入位置语义，全都不满足时返回 n 而不是 -1）。两种写法等价，但初始化、循环条件、边界移动必须配套，混用是最常见的 bug 来源。
## 四、问题3：有序数组中找 <=num 的最右位置（Code03）
- 与问题2完全镜像：遇到 arr[m] <= num 先记录 ans = m，然后 l = m + 1 继续往右找更靠右的；arr[m] > num 时 r = m - 1。
```java
// 有序数组中找<=num的最右位置，没找到返回-1
public static int findRight(int[] arr, int num) {
    int l = 0, r = arr.length - 1, m = 0;
    int ans = -1;
    while (l <= r) {
        m = l + ((r - l) >> 1);
        if (arr[m] <= num) {
            ans = m;   // 先记录候选答案
            l = m + 1; // 再往右找更靠右的
        } else {
            r = m - 1;
        }
    }
    return ans;
}
```
- 易错点提醒（写二分时的常见坑）：
- 1、循环要写成 while 而不是 if，只判断一次区间根本没收缩到位；
- 2、中点要写成 left + ((right - left) >> 1)，注意 >> 优先级低于 +，不加括号会先算加法再移位，得到错误的中点。
## 五、问题4：二分搜索不一定发生在有序数组上——寻找峰值（Code04，LC162）
- 题意：峰值元素是指其值严格大于左右相邻值的元素。数组中任何两个相邻的值都不相等，找到峰值元素并返回其索引，有多个峰值返回任意一个即可。假设 nums[-1] = nums[n] = -∞，要求 O(log n)。
- 关键认知：二分的本质不是"数组有序"，而是"二段性"——每次看 mid 的情况，能断定答案必在哪一侧，把另一侧排除掉。有序数组只是单调性的一种特例。
- 本题的"二段性"来自坡向：
- 1、arr[m] < arr[m+1]（上坡）：沿坡向右走不可能永远上升（右端之外是 -∞），右半必有峰值，左半可扔；
- 2、arr[m-1] > arr[m]（下坡）：对称地，左半必有峰值，右半可扔；
- 3、都不是：m 本身就是峰值，直接返回。
```java
public static int findPeakElement(int[] arr) {
    int n = arr.length;
    if (arr.length == 1) {   // 只有1个数，左右都是-∞，自己就是峰值
        return 0;
    }
    if (arr[0] > arr[1]) {   // 左端点外侧是-∞，大于右邻就是峰值
        return 0;
    }
    if (arr[n - 1] > arr[n - 2]) { // 右端点同理
        return n - 1;
    }
    // 两端都不是峰值后，峰值必在 [1, n-2] 内部
    int l = 1, r = n - 2, m = 0, ans = -1;
    while (l <= r) {
        m = (l + r) / 2;
        if (arr[m - 1] > arr[m]) {
            r = m - 1; // 下坡：峰值必在左边
        } else if (arr[m] < arr[m + 1]) {
            l = m + 1; // 上坡：峰值必在右边
        } else {
            ans = m;   // arr[m-1] < arr[m] 且 arr[m] > arr[m+1]，m 就是峰值
            break;
        }
    }
    return ans;
}
```
- 示例：nums = [1,2,1,3,5,6,4]，返回索引 1（峰值 2）或索引 5（峰值 6）都算对。注意题目输出的是索引而不是值。
## 六、本节小结
- 二分搜索四步曲：判断存在 → 找 >=num 最左 → 找 <=num 最右 → 无序数组上找二段性（峰值问题）。
- 核心认知升级：二分不要求数组有序，要求的是判定条件具有单调性（二段性）——每次比较后能确定地排除一半搜索空间。
- 工程细节：对数器验证正确性；中点防溢出写法 l + ((r - l) >> 1)；闭区间与左闭右开两种写法的约定不能混用。
