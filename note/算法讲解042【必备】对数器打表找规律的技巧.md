# 算法讲解042【必备】对数器打表找规律的技巧
前置知识：会基本递归即可（推荐讲解038-常见经典递归过程解析）
代码位置：src/class042 ｜ 内容：买苹果最少袋子、轮流吃草博弈、连续正整数之和、好串计数，四道题演示"暴力打表 → 观察规律 → 一行最优解"的完整套路
## 零、本节课内容概览
- 核心思想：当题目的**输入参数是简单类型、返回值也是简单类型**时，可以使用"对数器打表找规律"的技巧。
- 打表找规律的三步过程：
  1. 用最暴力的实现（往往只需要最基本的递归能力）求出入参不大情况下的答案；
  2. 打印入参不大情况下的答案，观察规律；
  3. 把规律变成代码，就是最优解。
- 本节课用 4 道题目完整演示该套路：题目1 使用规格8和规格6的袋子买苹果问题；题目2 A和B轮流吃草最终谁会赢；题目3 判断一个数字是否是若干数量(数量>1)的连续正整数的和；题目4 要求只有一个长度>=2的回文子串，求所有长度为n的red字符串中好串的数量。
## 一、题目1：使用规格8和规格6的袋子买苹果问题
- 题意：有装下 8 个苹果的袋子、装下 6 个苹果的袋子，必须保证所有袋子都装满。给定 n 个苹果，返回至少要用多少个袋子；若不存在装满方案返回 -1。
- 在线测试链接：https://www.nowcoder.com/practice/73e0552b78474a9086781e47f4e01d73（牛客网，提交时类名改成 Main 可通过全部测试用例）。
- 第1步：写暴力递归。`f(rest)` 表示还剩 rest 个苹果时至少需要的袋子数，无效解用 `Integer.MAX_VALUE` 表示：
```java
// 当前还有rest个苹果，使用的每个袋子必须装满，返回至少几个袋子
public static int f(int rest) {
    if (rest < 0) {
        return Integer.MAX_VALUE;
    }
    if (rest == 0) {
        return 0;
    }
    int p1 = f(rest - 8); // 使用8规格的袋子
    int p2 = f(rest - 6); // 使用6规格的袋子
    p1 += p1 != Integer.MAX_VALUE ? 1 : 0;
    p2 += p2 != Integer.MAX_VALUE ? 1 : 0;
    return Math.min(p1, p2);
}
```
- 第2步：打表观察。打印 n = 0..99 的答案，部分结果如下：
```
0 : 0    6 : 1    8 : 1    12 : 2   14 : 2   16 : 2
18 : 3   20 : 3   22 : 3   24 : 3   26 : 4   28 : 4
30 : 4   32 : 4   34 : 5   36 : 5   38 : 5   ...
（所有奇数 n 的答案均为 -1）
```
- 观察到的规律：
  - n 是奇数 → 无解返回 -1（8 和 6 都是偶数，装满的袋子总数必然是偶数）；
  - n < 18 时是零散的边界情况，直接列举：0→0，6/8→1，12/14/16→2，其余→-1；
  - n >= 18 且为偶数时，答案是 `(n - 18) / 8 + 3`，每多 8 个苹果多 1 个袋子（18~24 都是 3 个袋子，26~32 都是 4 个袋子……）。
- 第3步：把规律写成最优解（已通过牛客全部测试用例）：
```java
public static int bags2(int apple) {
    if ((apple & 1) != 0) { // 奇数无解
        return -1;
    }
    if (apple < 18) {
        if (apple == 0) {
            return 0;
        }
        if (apple == 6 || apple == 8) {
            return 1;
        }
        if (apple == 12 || apple == 14 || apple == 16) {
            return 2;
        }
        return -1;
    }
    return (apple - 18) / 8 + 3;
}
```
- 规律的直观解释（扩充）：因为袋子规格 8 和 6 都是偶数，奇数必无解；设使用 a 个 8 袋、b 个 6 袋，要装满 n 个苹果且袋子数 a+b 最少，应尽可能多用大袋。打表发现 n >= 18 后每增加 8 恰好多 1 袋，本质是"剩余的小部分总能用 6 和 8 的组合凑齐"，于是以 18 为基准点得出通项公式。
## 二、题目2：A和B轮流吃草最终谁会赢
- 题意：草一共有 n 的重量，两只牛轮流吃草，A 先吃，B 后吃。每只牛在自己的回合，吃草的重量必须是 4 的幂（1、4、16、64……）。谁在自己的回合正好把草吃完谁赢，根据输入 n 返回谁赢。
- 第1步：写暴力递归。`f(rest, cur)` 表示还剩 rest 份草、当前选手是 cur 时最终谁赢：
```java
public static String f(int rest, String cur) {
    String enemy = cur.equals("A") ? "B" : "A";
    if (rest < 5) { // 只剩0~4份时直接枚举：吃1或4份能吃完则cur赢，否则enemy赢
        return (rest == 0 || rest == 2) ? enemy : cur;
    }
    // rest >= 5，枚举所有4的幂的吃法，只要有一种吃法能让自己赢就选它
    int pick = 1;
    while (pick <= rest) {
        if (f(rest - pick, enemy).equals(cur)) {
            return cur;
        }
        pick *= 4;
    }
    return enemy; // 所有吃法都让对方赢，则enemy赢
}
```
- 第2步：打表观察。打印 n = 0..50 的赢家：
```
0 : B   1 : A   2 : B   3 : A   4 : A
5 : B   6 : A   7 : B   8 : A   9 : A
10 : B  11 : A  12 : B  13 : A  14 : A  …（以5为周期循环）
```
- 观察到的规律：结果以 5 为周期循环，n % 5 == 0 或 n % 5 == 2 时后手 B 赢，其余情况先手 A 赢。
- 第3步：把规律写成最优解：
```java
public static String win2(int n) {
    if (n % 5 == 0 || n % 5 == 2) {
        return "B";
    } else {
        return "A";
    }
}
```
- 规律的直观解释（扩充）：这是典型的博弈论"必败态"问题。n = 0 或 2 时当前选手无法一次吃完且留给对手必胜局面（必败态）；而 n % 5 ∈ {1, 3, 4} 时，当前选手总能通过吃 1 或 4 份把局面推入对方的必败态。由于每次可以吃 1 或 4（模 5 意义下分别是 1 和 -1），必败态恰好按 5 的周期在 0、2 处循环出现。
## 三、题目3：判断一个数字是否是若干数量(数量>1)的连续正整数的和
- 题意：给定一个正整数 num，判断它能否表示成 2 个或以上连续正整数之和（例如 9 = 4+5 = 2+3+4）。
- 第1步：写暴力枚举。枚举起点 start，不断向后累加，看能否恰好等于 num：
```java
public static boolean is1(int num) {
    for (int start = 1, sum; start <= num; start++) {
        sum = start;
        for (int j = start + 1; j <= num; j++) {
            if (sum + j > num) {
                break;
            }
            if (sum + j == num) {
                return true;
            }
            sum += j;
        }
    }
    return false;
}
```
- 第2步：打表观察。打印 num = 1..199 的结果，所有为 F 的数是：
```
1 : F   2 : F   4 : F   8 : F   16 : F   32 : F   64 : F   128 : F
其余全部为 T
```
- 观察到的规律：**不能表示的数恰好是 2 的幂**（1、2、4、8、16、32……）。换言之：num 不是 2 的幂 ⟺ num 可以表示为若干(>1)连续正整数之和。
- 第3步：把规律写成最优解。2 的幂的二进制只有最高位是 1，`num & (num - 1) == 0` 即判定为 2 的幂（参考讲解003/030/031 位运算）：
```java
public static boolean is2(int num) {
    return (num & (num - 1)) != 0;
}
```
- 规律的数学证明（扩充）：
  - 设 num = a + (a+1) + … + (a+k-1)（k > 1 个连续正整数），则 num = k * (2a + k - 1) / 2，即 2 * num = k * (2a + k - 1)。
  - k 与 (2a + k - 1) 的奇偶性必然不同（两者之差 2a - 1 是奇数），所以 num 必须含有一个大于 1 的奇数因子；而 2 的幂没有任何奇数因子，因此 2 的幂一定不能表示。
  - 反过来，若 num 有一个奇数因子（即 num 不是 2 的幂），设 num = a * b（a 为奇数因子），总能构造出对应的连续序列（以 b - (a-1)/2 开头的 a 个数，或以 (a+1)/2 - b 开头的 2b 个数，两者至少有一个合法），所以一定能表示。
  - 结论：num 能表示 ⟺ num 有奇数因子 ⟺ num 不是 2 的幂。
## 四、题目4：好串计数（只有一个长度>=2的回文子串的red字符串数量）
- 题意：可以用 r、e、d 三种字符拼接字符串，如果拼出来的字符串中有且仅有 1 个长度 >= 2 的回文子串，那么这个字符串定义为"好串"。返回长度为 n 的所有可能字符串中好串的数量，结果对 10⁹+7 取模，1 <= n <= 10⁹。示例：n=1 输出 0，n=2 输出 3，n=3 输出 18。
- n 最大到 10⁹，任何 O(n) 及以上的算法都会超时，必须先打表找规律。
- 第1步：写暴力递归。枚举所有 3^n 种字符串，统计每个字符串中长度 >= 2 的回文子串个数，恰好为 1 的计入答案：
```java
public static int f(char[] path, int i) {
    if (i == path.length) {
        int cnt = 0;
        for (int l = 0; l < path.length; l++) {
            for (int r = l + 1; r < path.length; r++) {
                if (is(path, l, r)) { // is: 判断s[l..r]是否回文
                    cnt++;
                }
                if (cnt > 1) {
                    return 0;
                }
            }
        }
        return cnt == 1 ? 1 : 0;
    }
    int ans = 0;
    path[i] = 'r';
    ans += f(path, i + 1);
    path[i] = 'e';
    ans += f(path, i + 1);
    path[i] = 'd';
    ans += f(path, i + 1);
    return ans;
}
```
- 第2步：打表观察。打印 n = 1..10 的答案：
```
n=1 : 0    n=2 : 3    n=3 : 18   n=4 : 30   n=5 : 36
n=6 : 42   n=7 : 48   n=8 : 54   n=9 : 60   n=10 : 66
```
- 观察到的规律：n >= 3 时起，答案是 6 * (n + 1)（n=3 时 24 不符合，为特判；n>=4 严格符合，n=3 时 18 单独处理）。
- 第3步：把规律写成最优解：
```java
public static int num2(int n) {
    if (n == 1) {
        return 0;
    }
    if (n == 2) {
        return 3;
    }
    if (n == 3) {
        return 18;
    }
    return (int) (((long) 6 * (n + 1)) % 1000000007);
}
```
- 注意：规律只需要在小数据上验证正确后，直接套用到 10⁹ 的大数据上即可，这正是"打表找规律"技巧的威力——O(1) 解决看似需要复杂推导的问题。
## 五、总结
- 适用场景：**输入参数是简单类型，返回值也是简单类型**的题目，且往往大数据范围让常规算法无法通过。
- 固定套路：暴力递归（正确性容易保证）→ 小数据打表打印 → 观察规律（周期性、分段函数、与位运算/数论相关的性质）→ 规律写成 O(1) 或 O(log n) 代码。
- 暴力代码本身就是"对数器"的标准答案来源，规律代码写完后还可以继续用暴力代码在小范围内对数验证，保证正确性。
- 本节课四个规律结论：
  - 买苹果：奇数无解；n < 18 打表列举；n >= 18 偶数 → `(n - 18) / 8 + 3`。
  - 轮流吃草：n % 5 == 0 或 2 时 B 赢，否则 A 赢（周期为 5 的必败态）。
  - 连续正整数之和：num 不是 2 的幂即可表示，一行 `(num & (num - 1)) != 0`。
  - 好串计数：n=1→0，n=2→3，n=3→18，n>=4→`6 * (n + 1)`。
