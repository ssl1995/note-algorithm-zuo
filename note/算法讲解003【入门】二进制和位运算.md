## 一、二进制和位的概念
- 计算机中一切数据都以二进制（0/1）存储，每一个 0 或 1 称为一个"位"（bit）。
- Java 中 int 类型占 32 位，long 类型占 64 位。
## 二、正数怎么用二进制表达
- 最高位是符号位，0 表示非负数。
- 其余位就是该数字本身的二进制形式，例如 78 = 0b1001110。
## 三、负数怎么用二进制表达（补码）
- 最高位是符号位，1 表示负数。
- 负数 = 对应正数取反（~）后再 + 1（即补码）。
- 因此：一个数的相反数 = 取反 + 1 = 先 -1 再取反，两种写法等价。
```java
int a = 78;
int e  = ~a + 1;   // -78
int e1 = ~(a - 1); // -78，与上一行等价
```
- 特例：int、long 的最小值（Integer.MIN_VALUE / Long.MIN_VALUE），取相反数、取绝对值都还是自己，因为对应正数溢出了。
```java
int f = Integer.MIN_VALUE;
System.out.println(-f);      // 还是自己
System.out.println(~f + 1);  // 还是自己
```
## 四、打印二进制；直接定义二进制、十六进制变量
- 打印二进制思路：从第 31 位到第 0 位，逐位用 `num & (1 << i)` 判断该位是否为 1。
- 注意：判断时不能写成 `== 1`，因为第 i 位有 1 时结果是 2 的 i 次方，不一定是 1。
```java
// 十进制打印成二进制：写法1
public static void printBinary(int num) {
    for (int i = 31; i >= 0; i--) {
        System.out.print((num & (1 << i)) == 0 ? "0" : "1");
    }
    System.out.println();
}
// 十进制打印成二进制：写法2（更简洁）
public static void printBinary2(int num) {
    for (int i = 31; i >= 0; i--) {
        System.out.print((num >> i) & 1);
    }
    System.out.println();
}
```
- 直接定义二进制、十六进制变量：
```java
int c = 0b1001110; // 0b 开头：直接写二进制，值为 78
int d = 0x4e;      // 0x 开头：直接写十六进制，0100->4，1110->e，值也是 78
```
## 五、常见的位运算（|、&、^、~、<<、>>、>>>）
- `|` 按位或：对应位只要有一个 1 结果就是 1。
- `&` 按位与：对应位都是 1 结果才是 1。
- `^` 按位异或：对应位不同结果为 1，相同为 0（可理解为"无进位相加"）。
- `~` 按位取反：0 变 1，1 变 0。
```java
int g = 0b0001010;
int h = 0b0001100;
printBinary(g | h); // 00000000000000000000000000001110
printBinary(g & h); // 00000000000000000000000000001000
printBinary(g ^ h); // 00000000000000000000000000000110
```
- `<<` 左移：不区分正负数，低位补 0。
- `>>` 有符号右移：高位补符号位（正数补 0，负数补 1）。
- `>>>` 无符号右移：高位一律补 0。
- 非负数 `>>` 和 `>>>` 效果一样；负数两者效果不一样。
```java
int i = 0b0011010;
printBinary(i << 1);  // 左移1位
printBinary(i >> 2);  // 有符号右移2位
printBinary(i >>> 2); // 无符号右移2位，非负数与 >> 相同
int j = 0b11110000000000000000000000000000; // 负数
printBinary(j >> 2);  // 高位补1
printBinary(j >>> 2); // 高位补0
```
- 常用规律（只对非负数成立，负数不要用）：
  - 非负数 `<< i` 等同于乘以 2 的 i 次方；
  - 非负数 `>> i` 等同于除以 2 的 i 次方。
```java
int k = 10;
System.out.println(k << 1); // 20，等同于 10 * 2
System.out.println(k << 2); // 40，等同于 10 * 4
System.out.println(k >> 1); // 5， 等同于 10 / 2
System.out.println(k >> 2); // 2， 等同于 10 / 4
```
## 六、|、& 与 ||、&& 的区别
- `|`、`&` 是位运算或、位运算与，可以连接整数；`||`、`&&` 是逻辑或、逻辑与，只能连接 boolean 类型。
- 用 `|`、`&` 连接 boolean 时，两侧的表达式一定都会计算。
- `||`、`&&` 有"穿透性"（短路）特点：左侧已经能确定结果时，右侧不再计算。
```java
boolean test1 = returnTrue() | returnFalse();   // 两个函数都会进入
boolean test2 = returnTrue() || returnFalse();  // 只进入 returnTrue，右侧被短路
boolean test3 = returnFalse() & returnTrue();   // 两个函数都会进入
boolean test4 = returnFalse() && returnTrue();  // 只进入 returnFalse，右侧被短路
```
## 七、为什么这么设计二进制
- 补码的设计是为了让加法的逻辑统一成一套逻辑，没有条件转移（正数、负数用同一套加法电路即可）。
- 加法逻辑如此重要，因为减乘除以及各种复杂运算最终都要靠加法来实现。
## 八、关于溢出
- 计算机不会帮你检查溢出，一定是自己确保自己的调用所得结果不会溢出。
- 例如 long 类型有 64 位，`num & (1 << 48)` 这种写法不对，因为 1 是 int 类型只有 32 位，`1 << 48` 早就溢出了，应该写成 `num & (1L << 48)`。
