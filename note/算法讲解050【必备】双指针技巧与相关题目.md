## 零、本节课内容概览
- **双指针**：设置两个指针协同遍历的技巧，这种说法很宽泛，似乎没什么可总结的，关键要分清两类：
  1. 有的双指针**单纯是代码过程用双指针的形式表达出来**，没有单调性（贪心）方面的考虑（如题目1按奇偶排序、题目7缺失的第一个正数）；
  2. 有的双指针**包含单调性（贪心）方面的考虑**，牵扯到可能性的取舍，对分析能力要求变高——其实是**先有的思考和优化，然后代码才变成了双指针的形式**（如题目4救生艇、题目5盛水容器）。
- **核心结论**：双指针这个"皮"不重要，**分析题目单调性（贪心）方面的特征，这个能力才重要**。
- 常见双指针类型：① 同向双指针；② 快慢双指针（如题目2找重复数）；③ 从两头往中间的双指针（如题目3、4、5、6）；④ 其他。
## 一、题目1：按奇偶排序数组II（Code01_SortArrayByParityII）
- 题意：非负整数数组 nums，一半奇数一半偶数。对数组进行调整，使得 nums[i] 为奇数时 i 也是奇数，nums[i] 为偶数时 i 也是偶数。返回任意满足条件的数组。测试链接：https://leetcode.cn/problems/sort-array-by-parity-ii/
- 同一个题的不同说法：给定数组 arr，请调整成**奇数都在奇数位置 或者 偶数都在偶数位置**。
- 思路：盯住**最后一个位置** nums[n-1] 的奇偶性做分发——它是奇数就换到奇数下标区 odd（从 1 开始 +2 步进），是偶数就换到偶数下标区 even（从 0 开始 +2 步进）。换过来的数继续被检查、继续分发，直到 odd/even 越过边界。属于"没有单调性考虑，单纯用双指针表达过程"的类型。
- 图文说明（n=6，odd 管奇数位、even 管偶数位）：
```
盯 nums[5]：奇数 → 换到 nums[odd]，odd += 2
盯 nums[5]：偶数 → 换到 nums[even]，even += 2
下标:  0(even) 1(odd) 2(even) 3(odd) 4(even) 5(被盯的位置)
```
```java
// 时间复杂度O(n)，额外空间复杂度O(1)
public static int[] sortArrayByParityII(int[] nums) {
    int n = nums.length;
    for (int odd = 1, even = 0; odd < n && even < n;) {
        if ((nums[n - 1] & 1) == 1) {
            swap(nums, odd, n - 1);
            odd += 2;
        } else {
            swap(nums, even, n - 1);
            even += 2;
        }
    }
    return nums;
}
```
## 二、题目2：寻找重复数（Code02_FindTheDuplicateNumber）
- 题意：n+1 个整数的数组 nums，数字都在 [1, n] 范围内，只有一个重复的整数，返回它。要求**不修改数组**且只用 O(1) 额外空间。测试链接：https://leetcode.cn/problems/find-the-duplicate-number/
- 思路：**把数组看成链表**，`i -> nums[i]` 构成 next 指针。因为数字范围是 [1, n] 且有 n+1 个数，从 0 号位置出发的链必然成环，而**入环的第一个节点就是重复数**（重复数被多个下标指向）。于是变成经典的 **Floyd 快慢指针找环入口**：
  1. 第一阶段：slow 走一步、fast 走两步，直到相遇；
  2. 第二阶段：fast 回到起点，两指针都每次走一步，再次相遇处即环入口（重复数）。
- 图文说明（nums = [1,3,4,2,2]）：
```
下标链: 0 → 1 → 3 → 2 → 4 ↘
                    ↑______↓  （环：2 → 4 → 2，入口 2 就是重复数）
```
```java
// 时间复杂度O(n)，额外空间复杂度O(1)
public static int findDuplicate(int[] nums) {
    if (nums == null || nums.length < 2) {
        return -1;
    }
    int slow = nums[0];
    int fast = nums[nums[0]];
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[nums[fast]];
    }
    // 相遇了，快指针回开头
    fast = 0;
    while (slow != fast) {
        fast = nums[fast];
        slow = nums[slow];
    }
    return slow;
}
```
- 补充：第二阶段为何成立？设起点到环入口距离 a、入口到相遇点 b、相遇点绕回入口 c。第一次相遇时 slow 走 a+b，fast 走 a+b+k(b+c)，由 fast=2×slow 得 a+b=k(b+c)，即 a = (k-1)(b+c)+c——从起点走 a 步和从相遇点再走 a 步必然同时停在环入口。
## 三、题目3：接雨水（Code03_TrappingRainWater）
- 题意：n 个非负整数表示宽度为 1 的柱子高度图，计算下雨后能接多少雨水。测试链接：https://leetcode.cn/problems/trapping-rain-water/
- 注意：二维接雨水问题会在宽度优先遍历章节讲述（后续【必备】课程）。
- 核心观察：**每个位置 i 能接的水 = min(左侧最高, 右侧最高) - nums[i]**（与 0 取 max）。
- 解法一（辅助数组，非最优）：预处理 lmax[i] = 0~i 范围最大值、rmax[i] = i~n-1 范围最大值，然后逐位置结算。时间 O(n)，额外空间 O(n)。
- 解法二（双指针，最优解）：l 从左往右、r 从右往左，同时用变量 lmax、rmax 维护两侧见过的最大值。**谁小结算谁**：若 lmax <= rmax，则 l 位置的瓶颈一定在左侧（右边至少还有个 rmax 兜底，未来更新也只会更大），可以直接结算 l；否则结算 r。这体现了单调性取舍——较小的那侧最大值已"封顶"，可以立即确定答案。
```java
// 双指针的解法（最优解），时间O(n)，额外空间O(1)
public static int trap2(int[] nums) {
    int l = 1, r = nums.length - 2, lmax = nums[0], rmax = nums[nums.length - 1];
    int ans = 0;
    while (l <= r) {
        if (lmax <= rmax) {
            ans += Math.max(0, lmax - nums[l]);
            lmax = Math.max(lmax, nums[l++]);
        } else {
            ans += Math.max(0, rmax - nums[r]);
            rmax = Math.max(rmax, nums[r--]);
        }
    }
    return ans;
}
```
- 对比辅助数组解法（便于理解双指针版本）：
```java
// 时间复杂度O(n)，额外空间复杂度O(n)
public static int trap1(int[] nums) {
    int n = nums.length;
    int[] lmax = new int[n];
    int[] rmax = new int[n];
    lmax[0] = nums[0];
    for (int i = 1; i < n; i++) {           // 0~i范围上的最大值
        lmax[i] = Math.max(lmax[i - 1], nums[i]);
    }
    rmax[n - 1] = nums[n - 1];
    for (int i = n - 2; i >= 0; i--) {      // i~n-1范围上的最大值
        rmax[i] = Math.max(rmax[i + 1], nums[i]);
    }
    int ans = 0;
    for (int i = 1; i < n - 1; i++) {
        ans += Math.max(0, Math.min(lmax[i - 1], rmax[i + 1]) - nums[i]);
    }
    return ans;
}
```
- 复杂度：双指针法时间 O(n)，额外空间 O(1)。
## 四、题目4：救生艇（Code04_BoatsToSavePeople）
- 题意：people[i] 表示第 i 个人体重，船不限量，每艘船最大承重 limit、最多载两人，返回承载所有人所需的最小船数。测试链接：https://leetcode.cn/problems/boats-to-save-people/
- 思路（贪心 + 两头往中间双指针）：先排序。**最轻的人 l 和 最重的人 r 配对**：若两人体重和 <= limit，同船（l++、r--）；否则最重的人只能独自坐船（r--）。每轮 ans++。贪心理由：最重的人如果连最轻的人都带不动，那他跟谁都不能同船，只能独占一艘；若能带动，带最轻的绝对不亏（把更轻的留给更重的更不可能更优）。
```java
// 时间复杂度O(n*logn)，因为有排序，额外空间复杂度O(1)
public static int numRescueBoats(int[] people, int limit) {
    Arrays.sort(people);
    int ans = 0;
    int l = 0;
    int r = people.length - 1;
    int sum = 0;
    while (l <= r) {
        sum = l == r ? people[l] : people[l] + people[r];
        if (sum > limit) {
            r--;
        } else {
            l++;
            r--;
        }
        ans++;
    }
    return ans;
}
```
- 扩展（大厂真考过）：再增加一个要求——**如果两人一船那么体重之和必须是偶数**，又该怎么做？提示方向：奇偶体重分开处理/配对，偶数只能与偶数配、奇数只能与奇数配，再分别套用本题的配对贪心。
## 五、题目5：盛最多水的容器（Code05_ContainerWithMostWater）
- 题意：n 条垂线，第 i 条端点为 (i, 0) 和 (i, height[i])，找两条线与 x 轴构成的容器能盛最多水，返回最大水量（不能倾斜容器）。测试链接：https://leetcode.cn/problems/container-with-most-water/
- 思路（单调性取舍的经典题）：l、r 从两头出发，当前水量 = min(height[l], height[r]) × (r - l)。**每次移动较矮的那一边**：宽度必然缩小，若想水量变大只能靠高度补偿；移动较高的一边，高度上限被矮边锁死，水量只可能更小，这个可能性可以直接舍弃。这就是"先有分析，代码才长成双指针"的典型。
- 图文说明：
```
height:   |           |
          |     |     |        水量 = min(左, 右) × (r - l)
          |  |  |     |        矮边不动上限就被锁死
      l →              ← r     所以每次收缩较矮的一端
```
```java
// 时间复杂度O(n)，额外空间复杂度O(1)
public static int maxArea(int[] height) {
    int ans = 0;
    for (int l = 0, r = height.length - 1; l < r;) {
        ans = Math.max(ans, Math.min(height[l], height[r]) * (r - l));
        if (height[l] <= height[r]) {
            l++;
        } else {
            r--;
        }
    }
    return ans;
}
```
- 补充：对比暴力 O(n²) 枚举所有线对，双指针每次循环都**排除掉一整批不可能更优的配对**（矮边与任何中间线的组合），这就是单调性剪枝的威力。
## 六、题目6：供暖器（Code06_Heaters）
- 题意：水平线上的房屋 houses 和供暖器 heaters 位置，供暖器有固定加热半径，求能覆盖所有房屋的最小半径。测试链接：https://leetcode.cn/problems/heaters/
- 思路：两个数组都排序后，i 指向房屋、j 指向供暖器，同向（不回退）推进。对每个房屋 i，让 j 停在"对 i 最优"的供暖器上：若 heaters[j+1] 供暖 i 的半径 <= heaters[j] 的半径，j 就继续右跳；否则 j 就是 i 的最优供暖器，用 |heaters[j] - houses[i]| 更新答案。由于房屋和供暖器都有序，**房屋越靠右，其最优供暖器的下标不可能变小**，所以 j 不需要回退——单调性成立。
```java
// 时间复杂度O(n*logn)，因为有排序，额外空间复杂度O(1)
public static int findRadius(int[] houses, int[] heaters) {
    Arrays.sort(houses);
    Arrays.sort(heaters);
    int ans = 0;
    for (int i = 0, j = 0; i < houses.length; i++) {
        // i号房屋，j号供暖器
        while (!best(houses, heaters, i, j)) {
            j++;
        }
        ans = Math.max(ans, Math.abs(heaters[j] - houses[i]));
    }
    return ans;
}
// 当前的地点houses[i]由heaters[j]来供暖是最优的吗？
// 用heaters[j]供暖产生半径a，用heaters[j+1]供暖产生半径b
// a < b 说明最优，不该跳下一个；a >= b 说明应跳下一个位置
public static boolean best(int[] houses, int[] heaters, int i, int j) {
    return j == heaters.length - 1
            ||
           Math.abs(heaters[j] - houses[i]) < Math.abs(heaters[j + 1] - houses[i]);
}
```
- 补充：本题另一种常见解法是**二分查找**——对每个房屋在 heaters 里二分找最近的供暖器，时间 O(n log m)，本质同样是利用排序后的单调性。
## 七、题目7：缺失的第一个正数（Code07_FirstMissingPositive）
- 题意：未排序整数数组 nums，找出其中没有出现的最小正整数。要求时间 O(n)、常数级额外空间。测试链接：https://leetcode.cn/problems/first-missing-positive/
- 思路（玩概念！）：答案一定在 [1, n+1] 范围内。理想情况是"数字 i 放在下标 i-1"，即 1~n 各就各位。设两个边界：
  - **l 的左边**：已经做到"i 位置上放着 i+1"的好区域，永远盯着 l 位置看能不能扩充（l++）；
  - **[r, n-1] 垃圾区**：最好状况下认为 1~r 是可以收集全的，每出现垃圾（越界数、重复数），预期就变差（r--），把垃圾换进垃圾区。
- 对 arr[l] 的三种处理：① arr[l] == l+1，正好是它该在的位置，l++；② arr[l] <= l（已在好区域出现过的数）、arr[l] > r（超出当前预期）、或目标位置已有相同的数（重复垃圾）——扔进垃圾区（swap 到 --r）；③ 否则把 arr[l] 换到它该在的位置 arr[l]-1，换回来的数继续盯。循环结束返回 l+1。
```java
// 时间复杂度O(n)，额外空间复杂度O(1)
public static int firstMissingPositive(int[] arr) {
    // l的左边，都是做到i位置上放着i+1的区域
    int l = 0;
    // [r....]垃圾区，最好状况下认为1~r是可以收集全的
    int r = arr.length;
    while (l < r) {
        if (arr[l] == l + 1) {
            l++;
        } else if (arr[l] <= l || arr[l] > r || arr[arr[l] - 1] == arr[l]) {
            swap(arr, l, --r);
        } else {
            swap(arr, l, arr[l] - 1);
        }
    }
    return l + 1;
}
```
- 复杂度说明：虽然每次 swap 可能不换 l，但每个数最多被归位/扔垃圾一次，l 和 r 合计推进不超过 n 次，整体 O(n)。
## 八、总结
- 双指针只是"皮"，**分析题目的单调性（贪心）特征才是核心能力**——先想清楚哪个可能性可以舍弃，代码自然长成双指针的样子。
- 四类常见形式：同向双指针（供暖器）、快慢双指针（找重复数/链表成环）、两头往中间（接雨水、救生艇、盛水容器）、以及单纯用双指针表达分区过程（按奇偶排序、缺失的第一个正数）。
- 单调性取舍的典型论证：救生艇"最重的带不动最轻的就只能独坐"、盛水容器"移动高边不可能更优"、接雨水"较小一侧的最大值已封顶可先结算"——都是**排除一整批劣解**的剪枝思想。
- 排序是很多双指针题的前置步骤（救生艇、供暖器），排序产生单调性，单调性支撑指针不回退，从而把 O(n²) 暴力降到 O(n log n) 或 O(n)。
- 数组模拟链表 + Floyd 判圈（找重复数）是快慢指针的经典应用，两阶段（先相遇、再同速找入口）务必熟练默写。
- "好区域 / 垃圾区"的分区概念（缺失的第一个正数）与荷兰国旗问题一脉相承，是处理"O(n) 时间 + O(1) 空间原地重排"类要求的通用套路。
