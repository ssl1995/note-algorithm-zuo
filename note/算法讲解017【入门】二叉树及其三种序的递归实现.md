## 一、二叉树的节点
- 二叉树（Binary Tree）：每个节点最多有两个子节点的树结构，分别称为左孩子、右孩子。
- 二叉树是所有树结构问题的基础，后续的二叉搜索树、平衡树、堆等都建立在它之上。
- 节点定义非常简单：一个值 + 左右两个引用（指针）。
```java
public static class TreeNode {
    public int val;
    public TreeNode left;
    public TreeNode right;
    public TreeNode(int v) {
        val = v;
    }
}
```
## 二、二叉树的先序、中序、后序
- 先序遍历（前序）：对每棵子树，先处理头节点，再处理左子树，最后处理右子树（头 -> 左 -> 右）。
- 中序遍历：对每棵子树，先处理左子树，再处理头节点，最后处理右子树（左 -> 头 -> 右）。
- 后序遍历：对每棵子树，先处理左子树，再处理右子树，最后处理头节点（左 -> 右 -> 头）。
- "先、中、后"指的是头节点被处理的时机：最先、中间、最后。
- 以如下二叉树为例（代码中 main 方法建的树）：
```plain
        1
       / \
      2   3
     / \ / \
    4  5 6  7
先序遍历结果: 1 2 4 5 3 6 7   (头 -> 左 -> 右)
中序遍历结果: 4 2 5 1 6 3 7   (左 -> 头 -> 右)
后序遍历结果: 4 5 2 6 7 3 1   (左 -> 右 -> 头)
```
## 三、递归序：理解三种遍历的关键
- 递归遍历二叉树时，每个节点实际上会被"到达"三次，这就是递归序：
  - 第 1 次：刚进入该节点时（位置1）
  - 第 2 次：左子树递归返回后（位置2）
  - 第 3 次：右子树递归返回后（位置3）
- 递归的基本样子（三个位置标注）：
```java
// 递归基本样子，用来理解递归序
public static void f(TreeNode head) {
    if (head == null) {
        return;
    }
    // 1
    f(head.left);
    // 2
    f(head.right);
    // 3
}
```
- 以上面的树为例，递归序为：1, 2, 4, 4, 4, 2, 5, 5, 5, 2, 1, 3, 6, 6, 6, 3, 7, 7, 7, 3, 1（每个节点出现 3 次）。
- 三种遍历的本质：就是在递归序的基础上，选择每个节点第几次到达时才打印：
  - 先序：每个节点第 1 次到达时打印 -> 1 2 4 5 3 6 7
  - 中序：每个节点第 2 次到达时打印 -> 4 2 5 1 6 3 7
  - 后序：每个节点第 3 次到达时打印 -> 4 5 2 6 7 3 1
- 所以三种遍历是同一条递归路线加工出来的，只是"取数时机"不同。
## 四、代码实现：三序遍历的递归版
```java
// 先序打印所有节点，递归版
public static void preOrder(TreeNode head) {
    if (head == null) {
        return;
    }
    System.out.print(head.val + " "); // 第1次到达就打印
    preOrder(head.left);
    preOrder(head.right);
}
// 中序打印所有节点，递归版
public static void inOrder(TreeNode head) {
    if (head == null) {
        return;
    }
    inOrder(head.left);
    System.out.print(head.val + " "); // 第2次到达才打印
    inOrder(head.right);
}
// 后序打印所有节点，递归版
public static void posOrder(TreeNode head) {
    if (head == null) {
        return;
    }
    posOrder(head.left);
    posOrder(head.right);
    System.out.print(head.val + " "); // 第3次到达才打印
}
```
- 对比递归基本样子 f：先序在位置1打印，中序在位置2打印，后序在位置3打印，代码只是把打印语句挪了个位置。
## 五、复杂度分析
- 时间复杂度 O(n)：每个节点被到达 3 次，是 3n 次操作，常数可忽略，所以是 O(n)。
- 额外空间复杂度 O(h)：递归调用栈的深度等于二叉树的高度 h。
  - 最好情况：平衡二叉树，h = O(log n)。
  - 最坏情况：退化成链表的树（如只有左孩子），h = O(n)。
## 六、总结与后续
- 二叉树三序遍历 = 一条递归序 + 不同的打印时机，理解递归序就理解了三种遍历。
- 递归是二叉树问题最重要的思维方式，绝大多数二叉树题目都可以用"递归套路"解决。
