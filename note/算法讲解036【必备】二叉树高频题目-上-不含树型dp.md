## 二、题目1：二叉树的层序遍历（LeetCode 102）
- 测试链接：https://leetcode.cn/problems/binary-tree-level-order-traversal/
- 要求：按层返回二叉树节点值，每层一个列表。
- 方法1（不推荐）：普通 BFS + HashMap 记录每个节点在第几层，多此一举，常数大。
- 方法2（推荐）：每次处理一层的优化 BFS——用数组模拟队列，每轮循环先取出当前队列长度 size，这 size 个节点就是同一层，批量弹出收集、批量加入孩子。
```java
public static int MAXN = 2001;
public static TreeNode[] queue = new TreeNode[MAXN];
public static int l, r;
public static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> ans = new ArrayList<>();
    if (root != null) {
        l = r = 0;
        queue[r++] = root;
        while (l < r) { // 队列里还有东西
            int size = r - l; // 当前层的节点个数
            ArrayList<Integer> list = new ArrayList<Integer>();
            for (int i = 0; i < size; i++) {
                TreeNode cur = queue[l++];
                list.add(cur.val);
                if (cur.left != null) {
                    queue[r++] = cur.left;
                }
                if (cur.right != null) {
                    queue[r++] = cur.right;
                }
            }
            ans.add(list);
        }
    }
    return ans;
}
```
- 图示（每次处理一层）：
```text
队列: [A]            → size=1，弹出A收集，加入B C     → 第1层: [A]
队列: [B, C]         → size=2，弹出B C收集，加入D E F → 第2层: [B, C]
队列: [D, E, F]      → size=3，弹出D E F收集          → 第3层: [D, E, F]
```
- 复杂度：时间 O(n)，空间 O(n)。
- 关键点：用静态数组 + l/r 双指针模拟队列，比 LinkedList 快很多；"每轮先定 size 再循环"是分层 BFS 的万能模板。
## 三、题目2：二叉树的锯齿形层序遍历（LeetCode 103）
- 测试链接：https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/
- 要求：第1层从左到右，第2层从右到左，交替进行。
- 思路：用"每次处理一层"的优化 BFS 就非常容易实现——队列中的节点入队顺序永远不变（先左后右），只是收集答案时用一个 reverse 标志决定当前层从前往后读还是从后往前读，读完一层翻转标志。
```java
boolean reverse = false; // false=从左往右收集，true=从右往左收集
while (l < r) {
    int size = r - l;
    ArrayList<Integer> list = new ArrayList<Integer>();
    // reverse==false：左->右，l....r-1 收集size个；reverse==true：右->左，r-1....l 收集size个
    for (int i = reverse ? r - 1 : l, j = reverse ? -1 : 1, k = 0; k < size; i += j, k++) {
        list.add(queue[i].val);
    }
    for (int i = 0; i < size; i++) { // 正常弹出并把孩子按先左后右入队
        TreeNode cur = queue[l++];
        if (cur.left != null) {
            queue[r++] = cur.left;
        }
        if (cur.right != null) {
            queue[r++] = cur.right;
        }
    }
    ans.add(list);
    reverse = !reverse;
}
```
- 关键点：锯齿只影响"读取方向"，不影响"入队顺序"，所以不需要双端队列，一个遍历方向的 for 循环就搞定。
## 四、题目3：二叉树的最大特殊宽度（LeetCode 662）
- 测试链接：https://leetcode.cn/problems/maximum-width-of-binary-tree/
- 要求：每层宽度 = 该层最左非空节点与最右非空节点之间的"位置数"（中间的空位也算），求所有层中的最大宽度。
- 思路：给每个节点编号——根编号为 1，若父节点编号为 id，则左孩子编号为 id*2，右孩子编号为 id*2+1（满二叉树堆式编号）。每次处理一层时，该层宽度 = 最后一个节点编号 - 第一个节点编号 + 1，全局取最大值。
- 编号图示：
```text
            1
        2       3
      4   5   6   7
父编号id → 左孩子2*id，右孩子2*id+1
```
```java
public static TreeNode[] nq = new TreeNode[MAXN]; // 节点队列
public static long[] iq = new long[MAXN];         // 编号队列，与节点队列同步
public static int widthOfBinaryTree(TreeNode root) {
    int ans = 1;
    l = r = 0;
    nq[r] = root;
    iq[r++] = 1;
    while (l < r) {
        int size = r - l;
        ans = Math.max(ans, (int) (iq[r - 1] - iq[l] + 1)); // 当前层宽度
        for (int i = 0; i < size; i++) {
            TreeNode node = nq[l];
            long id = iq[l++];
            if (node.left != null) {
                nq[r] = node.left;
                iq[r++] = id * 2;
            }
            if (node.right != null) {
                nq[r] = node.right;
                iq[r++] = id * 2 + 1;
            }
        }
    }
    return ans;
}
```
- 复杂度：时间 O(n)，空间 O(n)。
- 关键点：编号可能很大，java 用 long 即可通过（极端深度时溢出不影响相对比较结果）；C++ 用 unsigned long long。
## 五、题目4：求二叉树的最大深度、最小深度（LeetCode 104 / 111）
- 最大深度测试链接：https://leetcode.cn/problems/maximum-depth-of-binary-tree/
- 最小深度测试链接：https://leetcode.cn/problems/minimum-depth-of-binary-tree/
- 最大深度：一行递归——空树返回 0，否则 = max(左树深度, 右树深度) + 1。
```java
public static int maxDepth(TreeNode root) {
    return root == null ? 0 : Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
}
```
- 最小深度：注意定义是"根到最近叶子节点的最短路径"，所以只有一个孩子的节点不能直接取空子树的 0，要只统计非空子树。
```java
public int minDepth(TreeNode root) {
    if (root == null) {
        return 0; // 当前的树是空树
    }
    if (root.left == null && root.right == null) {
        return 1; // 当前root是叶节点
    }
    int ldeep = Integer.MAX_VALUE;
    int rdeep = Integer.MAX_VALUE;
    if (root.left != null) {
        ldeep = minDepth(root.left);
    }
    if (root.right != null) {
        rdeep = minDepth(root.right);
    }
    return Math.min(ldeep, rdeep) + 1;
}
```
- 易错点：最小深度不能写成 `min(左, 右) + 1`，因为空子树深度为 0 会污染结果——比如根只有右子树时，答案应该是右子树深度+1，而不是 1。
- 复杂度：时间 O(n)，空间 O(树高)。
## 六、题目5：二叉树先序序列化和反序列化（LeetCode 297）
- 测试链接：https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/
- 重要结论：二叉树可以通过先序、后序或者按层遍历的方式序列化和反序列化，但是无法通过中序遍历的方式实现！因为不同的两棵树，可能得到同样的中序序列，即便补了空位置也可能一样：
```text
    __2              1__
   /        和           \
  1                       2
补足空位置的中序遍历结果都是 { null, 1, null, 2, null }
```
- 先序序列化思路：遍历时把空位置也记录为 "#"，每个值以 "," 结尾；反序列化时按同样的先序顺序消费字符串数组，遇到 "#" 返回 null，否则建节点后递归建立左、右子树。
```java
public String serialize(TreeNode root) {
    StringBuilder builder = new StringBuilder();
    f(root, builder);
    return builder.toString();
}
void f(TreeNode root, StringBuilder builder) {
    if (root == null) {
        builder.append("#,");
    } else {
        builder.append(root.val + ",");
        f(root.left, builder);
        f(root.right, builder);
    }
}
public TreeNode deserialize(String data) {
    String[] vals = data.split(",");
    cnt = 0; // 当前数组消费到哪了
    return g(vals);
}
TreeNode g(String[] vals) {
    String cur = vals[cnt++];
    if (cur.equals("#")) {
        return null;
    } else {
        TreeNode head = new TreeNode(Integer.valueOf(cur));
        head.left = g(vals);
        head.right = g(vals);
        return head;
    }
}
```
- 示例：树 1(2,3) 序列化为 "1,2,#,#,3,#,#,"，反序列化严格按先序"头、左、右"消费即可还原。
- 关键点：先序能反序列化的原因——"头"的位置唯一确定，空位标记让递归边界明确。
## 七、题目6：二叉树按层序列化和反序列化（LeetCode 297）
- 测试链接：https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/
- 思路：序列化用 BFS 按层遍历，左右孩子为空就追加 "#,"，非空则追加值并入队；反序列化也用队列——每次弹出一个节点，依次从数组中消费两个值作为它的左、右孩子，非空孩子入队继续处理。
```java
public String serialize(TreeNode root) {
    StringBuilder builder = new StringBuilder();
    if (root != null) {
        builder.append(root.val + ",");
        l = 0; r = 0;
        queue[r++] = root;
        while (l < r) {
            root = queue[l++];
            if (root.left != null) {
                builder.append(root.left.val + ",");
                queue[r++] = root.left;
            } else {
                builder.append("#,");
            }
            if (root.right != null) {
                builder.append(root.right.val + ",");
                queue[r++] = root.right;
            } else {
                builder.append("#,");
            }
        }
    }
    return builder.toString();
}
public TreeNode deserialize(String data) {
    if (data.equals("")) {
        return null;
    }
    String[] nodes = data.split(",");
    int index = 0;
    TreeNode root = generate(nodes[index++]);
    l = 0; r = 0;
    queue[r++] = root;
    while (l < r) {
        TreeNode cur = queue[l++];
        cur.left = generate(nodes[index++]);  // 依次消费左孩子
        cur.right = generate(nodes[index++]); // 依次消费右孩子
        if (cur.left != null) {
            queue[r++] = cur.left;
        }
        if (cur.right != null) {
            queue[r++] = cur.right;
        }
    }
    return root;
}
private TreeNode generate(String val) {
    return val.equals("#") ? null : new TreeNode(Integer.valueOf(val));
}
```
- 关键点：序列化和反序列化的"消费顺序"必须严格一致（都是按层、先左后右），一一对应就能还原。LeetCode 官方测试数据就是这种格式。
## 八、题目7：利用先序与中序遍历序列构造二叉树（LeetCode 105）
- 测试链接：https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/
- 思路：先序数组的第一个值就是当前子树的头；用哈希表记录中序数组中每个值的位置，O(1) 找到头在中序里的位置 k；k 左边是左子树的中序，右边是右子树的中序；左子树节点个数 = k - l2，从而能切出先序中左、右子树的区间，递归构造。
```text
pre : l1(左子树......)[右子树......r1]
in  : (左子树l2...)k[右子树......r2]
左子树节点数 = k - l2
```
```java
public static TreeNode f(int[] pre, int l1, int r1, int[] in, int l2, int r2, HashMap<Integer, Integer> map) {
    if (l1 > r1) {
        return null;
    }
    TreeNode head = new TreeNode(pre[l1]);
    if (l1 == r1) {
        return head;
    }
    int k = map.get(pre[l1]);
    head.left = f(pre, l1 + 1, l1 + k - l2, in, l2, k - 1, map);
    head.right = f(pre, l1 + k - l2 + 1, r1, in, k + 1, r2, map);
    return head;
}
```
- 复杂度：时间 O(n)（哈希表优化了查头位置），空间 O(n)。
- 关键点：不用哈希表每次在中序数组里线性找头也可以过，但复杂度退化为 O(n^2)；同理"中序+后序"也能建树（后序最后一个值是头），而"先序+后序"在树不唯一时无法建树。
## 九、题目8：验证完全二叉树（LeetCode 958）
- 测试链接：https://leetcode.cn/problems/check-completeness-of-a-binary-tree/
- 思路：按层遍历（BFS），维护一个标志 leaf 表示"是否遇到过左右孩子不双全的节点"，两条规则任一违反即返回 false：
  - 1）任何节点有右孩子但没有左孩子 → 一定不是完全二叉树；
  - 2）一旦遇到过孩子不双全的节点，后续所有节点都必须是叶子（不能再有孩子）。
```java
public static boolean isCompleteTree(TreeNode h) {
    if (h == null) {
        return true;
    }
    l = r = 0;
    queue[r++] = h;
    boolean leaf = false; // 是否遇到过左右两个孩子不双全的节点
    while (l < r) {
        h = queue[l++];
        if ((h.left == null && h.right != null) || (leaf && (h.left != null || h.right != null))) {
            return false;
        }
        if (h.left != null) {
            queue[r++] = h.left;
        }
        if (h.right != null) {
            queue[r++] = h.right;
        }
        if (h.left == null || h.right == null) {
            leaf = true;
        }
    }
    return true;
}
```
- 图示（违反规则2的情况）：
```text
      1
    /   \
   2     3     ← 3 有孩子，但之前 2 已经"孩子不双全" → false
  /     /
 4     5
```
- 复杂度：时间 O(n)，空间 O(n)。
## 十、题目9：求完全二叉树的节点个数（LeetCode 222，要求低于 O(n)）
- 测试链接：https://leetcode.cn/problems/count-complete-tree-nodes/
- 思路（核心难点）：利用完全二叉树的性质——对任意节点 cur，看 cur 右子树的最左节点能扎到第几层：
  - 1）如果 cur 右树的最左节点扎到了整棵树的最深层（== h），说明 cur 的左子树是满二叉树，左子树节点数 = 2^(h-level) - 1，加上 cur 自己共 2^(h-level)，然后递归统计右子树；
  - 2）如果没扎到最深层，说明 cur 的右子树是满二叉树（高度少一层），右子树节点数 = 2^(h-level-1) - 1，加上 cur 自己共 2^(h-level-1)，然后递归统计左子树。
```text
            cur(level)
           /   \
     左子树     右子树
                 \
                  最左节点扎到h层？ 是 → 左树是满树，递归右树
                                   否 → 右树是满树(矮一层)，递归左树
```
```java
// cur : 当前来到的节点；level : 当前节点在第几层；h : 整棵树的高度
// 求 : cur这棵子树上有多少节点
public static int f(TreeNode cur, int level, int h) {
    if (level == h) {
        return 1;
    }
    if (mostLeft(cur.right, level + 1) == h) {
        // cur右树上的最左节点，扎到了最深层 → 左树是满二叉树
        return (1 << (h - level)) + f(cur.right, level + 1, h);
    } else {
        // cur右树上的最左节点，没扎到最深层 → 右树是满二叉树（高度少1）
        return (1 << (h - level - 1)) + f(cur.left, level + 1, h);
    }
}
// 当前节点是cur，并且它在level层，返回从cur开始不停往左能扎到几层
public static int mostLeft(TreeNode cur, int level) {
    while (cur != null) {
        level++;
        cur = cur.left;
    }
    return level - 1;
}
```
- 复杂度分析：整棵树高度 h = O(log n)，每层递归只走一条路径，每次调用 mostLeft 代价 O(log n)，总时间 O(log^2 n)，远低于 O(n)。
- 关键点：满二叉树节点数 = 2^高度 - 1，可以直接算；完全二叉树的"最后一层不满"只会影响一条路径，其余子树都是满的，所以能逐层剪枝。
## 十一、总结
- 层序遍历类题目的万能模板：数组模拟队列 + "每次处理一层"（先取 size = r - l 再循环），层序遍历、锯齿遍历、最大宽度、验证完全二叉树全部套这一个框架。
- 树的深度类题目直接用递归：最大深度无脑取 max，最小深度要小心"只有一个孩子"的边界。
- 序列化结论：先序、后序、按层都可以完成序列化/反序列化（空位补 #），中序不行（不同树可能得到相同序列）。
- 建树结论：先序+中序、中序+后序都能唯一建树（中序负责切分左右子树），哈希表存中序位置可把复杂度优化到 O(n)。
- 完全二叉树两大考点：验证用"BFS + 孩子不双全标志"；数节点用"右树最左节点是否扎到底"判断哪边是满树，做到 O(log^2 n)。
