## 一、快速排序的整体思路
- 在当前范围 arr[l...r] 上选择一个数字 x，通过 partition 过程把数组划分成：<=x 的放左边、>x 的放右边（经典版）；或者 <x 放左边、==x 放中间、>x 放右边（荷兰国旗优化版）。
- 然后对左边范围、右边范围分别重复这个过程，直到范围里只剩一个数（l >= r 时返回），整个数组就有序了。
- 这是一个分治递归：每次 partition 把 x 放到它最终应该在的位置上，之后再也不动它，子问题规模越来越小。
- 核心问题：怎么选择数字 x？
  - 选择的数字是当前范围上的固定位置，比如范围上的最右数字，那么就是普通快速排序。
  - 选择的数字是当前范围上的随机位置，那么就是随机快速排序。
## 二、经典版 partition（不推荐）
- 思想：用指针 a 维护 arr[l...a-1] 是 <=x 的区域，从左到右扫描，遇到 <=x 的数就换到 <=x 区域的下一个位置（a 位置），a 右移。
- 扫描结束后，把记录好的某个等于 x 的位置 xi 与 <=x 区域的最后一个位置 a-1 交换，确保划分完成后 <=x 区域的最后一个数字是 x，返回这个位置 mid。
- 之后递归处理 [l, mid-1] 和 [mid+1, r]。
```java
// 随机快速排序经典版(不推荐)
// 甚至在洛谷上测试因为递归开太多层会爆栈导致出错
public static void quickSort1(int l, int r) {
    // l == r，只有一个数；l > r，范围不存在
    if (l >= r) {
        return;
    }
    // 随机选一个位置的值x做划分，只有这一下随机，才能在概率上把时间复杂度收敛到O(n * logn)
    int x = arr[l + (int) (Math.random() * (r - l + 1))];
    int mid = partition1(l, r, x);
    quickSort1(l, mid - 1);
    quickSort1(mid + 1, r);
}
// 已知arr[l....r]范围上一定有x这个值
// 划分数组 <=x放左边，>x放右边，并且确保划分完成后<=x区域的最后一个数字是x
public static int partition1(int l, int r, int x) {
    // a : arr[l....a-1]范围是<=x的区域
    // xi : 记录在<=x的区域上任何一个x的位置，哪一个都可以
    int a = l, xi = 0;
    for (int i = l; i <= r; i++) {
        if (arr[i] <= x) {
            swap(a, i);
            if (arr[a] == x) {
                xi = a;
            }
            a++;
        }
    }
    swap(xi, a - 1);
    return a - 1;
}
```
## 三、荷兰国旗问题优化版（推荐）
- 经典版每次只搞定一个 x 的位置；荷兰国旗优化版每次划分会搞定所有值是 x 的数字：<x 放左边、==x 放中间、>x 放右边，等于 x 的这一片全部就位，不再参与后续递归。
- 三个指针的含义：
  - first：arr[l...first-1] 是 <x 的区域。
  - last：arr[last+1...r] 是 >x 的区域。
  - i：当前考察的位置，arr[first...i-1] 是 ==x 的区域。
- 过程：i <= last 时循环：arr[i] == x 则 i++；arr[i] < x 则与 first 位置交换后 first++、i++；arr[i] > x 则与 last 位置交换后 last--（此时 i 不动，因为换来的数还没看过）。
- 结束后 [first, last] 就是 ==x 的区域，只需递归处理 [l, first-1] 和 [last+1, r]。
```java
// 随机快速排序改进版(推荐)，可以通过所有测试用例
public static void quickSort2(int l, int r) {
    if (l >= r) {
        return;
    }
    int x = arr[l + (int) (Math.random() * (r - l + 1))];
    partition2(l, r, x);
    // 为了防止底层的递归过程覆盖全局变量，这里用临时变量记录first、last
    int left = first;
    int right = last;
    quickSort2(l, left - 1);
    quickSort2(right + 1, r);
}
// 荷兰国旗问题
public static int first, last;
// 划分数组 <x放左边，==x放中间，>x放右边
// 把全局变量first, last，更新成==x区域的左右边界
public static void partition2(int l, int r, int x) {
    first = l;
    last = r;
    int i = l;
    while (i <= last) {
        if (arr[i] == x) {
            i++;
        } else if (arr[i] < x) {
            swap(first++, i++);
        } else {
            swap(i, last--);
        }
    }
}
```
- 以 arr = {3, 5, 3, 8, 3, 1, 3}、x = 3 为例，划分过程：
```plain
初始: first=0, i=0, last=6    [3, 5, 3, 8, 3, 1, 3]
i=0: arr[0]==3 -> i=1
i=1: arr[1]==5>3 -> 换到last, last=5, i不动   [3, 3, 3, 8, 3, 1, 5]
i=1: arr[1]==3 -> i=2
i=2: arr[2]==3 -> i=3
i=3: arr[3]==8>3 -> 换到last, last=4, i不动   [3, 3, 3, 1, 3, 8, 5]
i=3: arr[3]==1<3 -> 换到first, first=1, i=4   [1, 3, 3, 3, 3, 8, 5]
i=4: arr[4]==3 -> i=5, i>last 结束
结果: [1 | 3, 3, 3, 3 | 8, 5]
       <x    ==x区域     >x
     只需递归 [0,0] 和 [5,6]，所有等于3的数一次性全部就位
```
- 注意细节：partition2 用全局变量 first、last 返回 ==x 区域的边界，递归前必须先用临时变量 left、right 记录下来，否则底层递归会覆盖全局变量。
## 四、时间和空间复杂度分析
- 核心点：划分值 x 选得好不好，决定了递归树的平衡程度。
  - 普通快速排序（固定位置选值，比如最右）：数据状况可以人为构造（如已经有序的数组），每次都划分出最偏的一侧，时间复杂度 O(n^2)，递归深度 O(n)，额外空间复杂度 O(n)。
  - 随机快速排序（随机位置选值）：x 落在范围上的任何位置等概率，任何人构造的数据都无法针对随机行为，划分在长期期望上足够平衡，时间复杂度收敛到 O(n * logn)，递归深度期望 O(logn)，额外空间复杂度 O(logn)。
- 随机这一下常数时间比较大，但只有这一下随机，才能在概率上把快速排序的时间复杂度收敛到 O(n * logn)，这正是"随机行为的时间复杂度按长期期望来估计"（讲解007的内容）。
- 关于复杂度的分析只做定性说明，定量证明略（证明较为复杂），《算法导论》7.4.2 节有详细证明。
- 快速排序是不稳定排序：partition 中的交换会打乱相等元素的相对顺序。
## 五、笔试中的两种写法
- acm 练习风格（Code01）：自己处理输入输出，用 BufferedReader + StreamTokenizer + PrintWriter 保证读写效率；静态数组避免频繁申请内存；提交洛谷 P1177 时类名改成 Main，直接调用 quickSort2(0, n - 1) 即可通过（经典版 quickSort1 在洛谷上会因递归层数太多爆栈出错，所以用改进版）。
- 填函数练习风格（Code02）：只需实现 sortArray(int[] nums)，内部调用 quickSort2(nums, 0, nums.length - 1)，所有逻辑传入数组参数操作即可。
## 六、总结
- 快速排序 = 选一个划分值 x + partition 划分 + 左右递归；经典版划分出 <=x | >x，荷兰国旗优化版划分出 <x | ==x | >x，一次搞定所有等于 x 的数。
- 固定位置选值是普通快排，最坏 O(n^2)；随机位置选值是随机快排，期望时间复杂度 O(n * logn)、额外空间 O(logn)。
- 随机快速排序是不稳定排序；实战中用荷兰国旗优化版（quickSort2），注意递归前用临时变量保存 first、last。
