## 一、哈希表：HashSet 与 HashMap
- 把哈希表认为是"集合"：根据值来做 key，或者根据内存地址来做 key。
- HashSet 和 HashMap 原理一样，区别只在于有无伴随数据：HashSet 只存 key，HashMap 存 key-value 键值对。
- 增、删、改、查时间复杂度为 O(1)，但是大常数（比数组访问慢）。
- 所以当 key 的范围是固定的、可控的情况下，可以用数组结构替代哈希表结构。
- 注意：Java 中通过自定义 hashCode、equals 等方法，任何类都可以实现"根据值做 key"或者"根据内存地址做 key"的需求。但在算法学习范畴内这些细节不重要，笔试、面试、比赛也很少用到，知道结论即可。
### 1. 值类型 key 与引用类型 key 的区别
- Integer、Long、Double、Float、Byte、Short、Character、Boolean、String 等包装类和字符串，都是按值做 key：内容相同就是同一个 key。
- 自己定义的类（没有重写 hashCode/equals），默认按内存地址做 key：即使两个对象内容完全一样，也是不同的 key。
```java
String str1 = new String("Hello");
String str2 = new String("Hello");
// false，因为不同的内存地址
System.out.println(str1 == str2);
// true，因为它们的值是相同的
System.out.println(str1.equals(str2));

HashSet<String> set = new HashSet<>();
set.add(str1);
System.out.println(set.contains("Hello")); // true，按值查找
System.out.println(set.contains(str2));    // true
set.add(str2);
System.out.println(set.size());            // 1，str1和str2值相同，不会去重失败
```
### 2. HashMap 常用操作
```java
HashMap<String, String> map1 = new HashMap<>();
map1.put(str1, "World");
System.out.println(map1.containsKey("Hello")); // true
System.out.println(map1.get(str2));            // "World"，按值做key，str2也能查到
System.out.println(map1.get("你好") == null);   // true，查不到返回null
map1.remove("Hello");
System.out.println(map1.size());               // 0
```
### 3. 自定义类默认按内存地址做 key
```java
public static class Student {
    public int age;
    public String name;
    public Student(int a, String b) { age = a; name = b; }
}

Student s1 = new Student(17, "张三");
Student s2 = new Student(17, "张三");
HashMap<Student, String> map3 = new HashMap<>();
map3.put(s1, "这是张三");
System.out.println(map3.containsKey(s1)); // true
System.out.println(map3.containsKey(s2)); // false！内容相同但内存地址不同
map3.put(s2, "这是另一个张三");
System.out.println(map3.size());          // 2，被当成两个不同的key
```
### 4. 笔试中常用数组替代哈希表
- 一般在笔试中，未必需要申请哈希表：key 范围固定可控时，数组的增删改查也是 O(1)，且常数更小、代码更短。
```java
HashMap<Integer, Integer> map2 = new HashMap<>();
map2.put(56, 7285);
map2.put(34, 3671263);
// 上面的map2行为，可以被如下数组的行为替代
int[] arr = new int[100];
arr[56] = 7285;
arr[34] = 3671263;
// 哈希表的增、删、改、查都可以被数组替代，前提是key的范围是固定的、可控的
```
## 二、有序表：TreeSet 与 TreeMap
- 有序表也是"集合"，但内部按 key 有序组织。Java 中 TreeSet / TreeMap 底层是红黑树。
- TreeSet 和 TreeMap 原理一样，区别也是有无伴随数据。
- 增、删、改、查 + 很多和有序相关的操作（floor、ceiling、first、last 等），时间都是 O(log n)。
- 有序表比较相同的东西会去重；如果不想去重，就加入更多的比较策略（比较器定制）。堆（PriorityQueue）不会去重。
- 补充：AVL树、SB树、替罪羊树、Treap、Splay、跳表等很多结构都可实现同样功能，后续课程会涉及，这里只讲用法。
### 1. TreeMap 常用操作
```java
TreeMap<Integer, String> treeMap = new TreeMap<>();
treeMap.put(5, "这是5");
treeMap.put(7, "这是7");
treeMap.put(1, "这是1");
treeMap.put(2, "这是2");
treeMap.put(3, "这是3");
treeMap.put(4, "这是4");

System.out.println(treeMap.containsKey(1));  // true
System.out.println(treeMap.get(4));          // "这是4"
treeMap.put(4, "张三是4");                    // key已存在，覆盖value

System.out.println(treeMap.firstKey());      // 1，最小的key
System.out.println(treeMap.lastKey());       // 7，最大的key
// 所有的key中，<= 4 且最近的key
System.out.println(treeMap.floorKey(4));     // 4
// 所有的key中，>= 4 且最近的key
System.out.println(treeMap.ceilingKey(4));   // 4
```
### 2. TreeSet 与堆的区别：去重
```java
TreeSet<Integer> set = new TreeSet<>();
set.add(3);
set.add(3);
set.add(4);
set.add(4);
System.out.println("有序表大小 : " + set.size()); // 2，重复元素被去重
while (!set.isEmpty()) {
    System.out.println(set.pollFirst()); // 3、4，按从小到大弹出
    // set.pollLast() 则从大到小弹出
}
```
- TreeSet 会去重，而 PriorityQueue（堆）不会去重，这是两者的重要区别。
### 3. 堆：默认小根堆，比较器定制大根堆
```java
// 堆，默认小根堆，不会去重
PriorityQueue<Integer> heap1 = new PriorityQueue<>();
heap1.add(3); heap1.add(3); heap1.add(4); heap1.add(4);
System.out.println("堆大小 : " + heap1.size()); // 4，不去重
while (!heap1.isEmpty()) {
    System.out.println(heap1.poll()); // 3、3、4、4，小的先弹出
}

// 定制的大根堆，用比较器！
PriorityQueue<Integer> heap2 = new PriorityQueue<>((a, b) -> b - a);
heap2.add(3); heap2.add(3); heap2.add(4); heap2.add(4);
while (!heap2.isEmpty()) {
    System.out.println(heap2.poll()); // 4、4、3、3，大的先弹出
}
```
## 三、比较器：定制比较策略
- 比较器用来定制"序"的规则，排序（Arrays.sort）、堆（PriorityQueue）、有序表（TreeSet/TreeMap）等很多需要序的结构中都可以使用。
- 写法：定义一个实现 Comparator 接口的类，或者直接写 Lambda 表达式。
### 1. 比较器的核心约定（任何语言都一样）
- compare(o1, o2) 返回负数：认为 o1 的优先级更高，排前面。
- compare(o1, o2) 返回正数：认为 o2 的优先级更高，排前面。
- 返回 0：认为两者优先级一样。
- 有了比较器之后，就不再有"大小"的概念，只有"优先级"的概念：返回负数放前面，利用这个设定可以定制任何优先级。
```java
public static class Employee {
    public int company;
    public int age;
    public Employee(int c, int a) { company = c; age = a; }
}

public static class EmployeeComparator implements Comparator<Employee> {
    @Override
    public int compare(Employee o1, Employee o2) {
        // 返回负数认为o1优先级更高；返回正数认为o2优先级更高
        // 这里按年龄从小到大排
        return o1.age - o2.age;
    }
}

Employee[] arr = { s1, s2, s3, s4, s5, s6 };
Arrays.sort(arr, new EmployeeComparator()); // 按年龄升序
```
### 2. Lambda 表达式与多级比较
```java
// Lambda：按年龄从大到小
Arrays.sort(arr, (a, b) -> b.age - a.age);

// 多级比较：先按公司编号小在前；公司编号一样，年龄小在前
Arrays.sort(arr, (a, b) -> a.company != b.company
        ? (a.company - b.company)
        : (a.age - b.age));
```
### 3. 比较器放进有序表：控制去重
- TreeSet 认为比较器返回 0 的两个元素是"同一个"，会去重。
```java
// 只按年龄比较：年龄相同就被视为同一个元素，会去重
TreeSet<Employee> treeSet1 = new TreeSet<>(new EmployeeComparator());
for (Employee e : arr) {
    treeSet1.add(e);
}
treeSet1.add(new Employee(2, 27)); // 和s1年龄相同，加不进去
System.out.println(treeSet1.size()); // 6，去重了

// 如果不想去重，就需要增加更多的比较策略
// 比如对象的内存地址（toString含地址）、或对象的独特信息（如数组下标）
TreeSet<Employee> treeSet2 = new TreeSet<>((a, b) ->
        a.company != b.company ? (a.company - b.company)
        : a.age != b.age ? (a.age - b.age)
        : a.toString().compareTo(b.toString()));
for (Employee e : arr) {
    treeSet2.add(e);
}
treeSet2.add(new Employee(2, 27)); // 内存地址不同，可以加进去
System.out.println(treeSet2.size()); // 7，不去重
```
- 注意：PriorityQueue（堆）不会去重，不管比较器怎么写。
### 4. 字典序
- 字符串之间的比较是字典序：从左到右逐字符比较，遇到第一对不同的字符，谁的字符小谁就排前；如果一方是另一方的前缀，则短的排前。
- Java 中用 String 的 compareTo 方法，返回值同样遵循比较器约定（负数：自己在前）。
```java
String str1 = "abcde";
String str2 = "ks";
System.out.println(str1.compareTo(str2)); // 负数，'a' < 'k'，"abcde"排前
System.out.println(str2.compareTo(str1)); // 正数
```
## 四、总结
- 哈希表（HashSet/HashMap）：增删改查 O(1) 但常数大；包装类和 String 按值做 key，自定义类默认按内存地址做 key；key 范围固定可控时可用数组替代。
- 有序表（TreeSet/TreeMap）：底层红黑树，增删改查及 floor/ceiling/first/last 等有序操作都是 O(log n)；会去重，不想去重就在比较器里加更多比较策略。
- 比较器：统一约定"返回负数 o1 优先、返回正数 o2 优先、返回 0 相等"，从此只有优先级没有大小；可用于排序、堆、有序表；字符串比较遵循字典序。
- 堆（PriorityQueue）：默认小根堆，比较器可定制大根堆；不会去重。
