## 零、单调栈：原理与最经典用法
- **单调栈**：栈中存放数组下标，保证栈中下标对应的值从栈底到栈顶满足单调性（递增或递减）。新元素进栈前，把破坏单调性的栈顶元素依次弹出，**元素被弹出的时刻就是收集答案的时刻**。
- **最经典的用法**是解决"每个位置左右两侧最近大/小值"问题：
  1. 每个位置求：左侧比当前位置的数字**小**、且距离最近的位置在哪；右侧比当前位置的数字**小**、且距离最近的位置在哪；
  2. 或者把"小"换成"大"，求左右两侧最近更大值。
- **复杂度**：每个下标最多入栈一次、出栈一次，所以求解过程中单调栈所有调整的总代价为 **O(n)**，单次操作的**均摊代价为 O(1)**。注意不是每次操作 O(1)（一次可能连续弹很多个），而是均摊 O(1)。
- 注意：这只是单调栈最经典的用法，下节课（讲解053）继续介绍其他用法；单调栈还能和动态规划等技巧交叉使用（扩展课讲）。
- **求"左右最近更小值"的图解**（栈底→栈顶值递增）：
```
假设数组无重复值，遍历到 i 位置：
1) 当 arr[栈顶] > arr[i] 时，栈顶 cur 弹出：
   → cur 的"右侧最近且更小"的位置 = i（就是 i 把它弹出来的）
   → cur 的"左侧最近且更小"的位置 = 弹出后新的栈顶（栈空则为 -1，表示没有）
2) 然后 i 进栈，继续遍历下一个位置。
3) 遍历结束后栈中剩余元素依次弹出（清算阶段）：
   → 右侧答案 = -1（右边没有更小的了）
   → 左侧答案 = 弹出时它下面的栈顶（栈空则为 -1）
```
- **有重复值时的关键处理**（本节课重点！不同题目对"相等"的处理不同）：
  - 弹栈条件用 `>=`（相等也弹）还是 `>`（相等不弹），取决于题目需要"严格小于"还是"小于等于"，**用错会在重复值上算错**。
  - 模版题（求严格小于）：用 `>=` 弹出，弹出时收集的答案中**左侧答案一定正确，右侧答案可能偏大**（相等值会让它提前记录），最后需要从右往左**修正**一遍右侧答案。
  - 核心记忆点：**相等的时候怎么处理，决定了每个位置的"管辖范围"如何划分**，后面每道题都会体现。
## 一、题目1：单调栈最经典用法的模版（Code01_LeftRightLess）
- 题意：给定一个**可能含有重复值**的数组 arr，找到每一个 i 位置左边和右边离 i 位置最近且值**严格比 arr[i] 小**的位置，不存在输出 -1。测试链接：https://www.nowcoder.com/practice/2a2c00e7a88a498693568cef63a4b7bb
- 思路（三阶段）：
  1. **遍历阶段**：栈底→栈顶值递增。遇到 arr[i]，把所有 >= arr[i] 的栈顶弹出（注意是 `>=`，相等也弹），弹出位置 cur 的左答案 = 新栈顶（栈空为 -1），右答案 = i；然后 i 进栈。
  2. **清算阶段**：遍历结束后栈内剩余元素依次弹出，左答案 = 新栈顶（栈空为 -1），右答案 = -1。
  3. **修正阶段**：因为有重复值且用 `>=` 弹出，**左答案一定正确，右答案可能不准**。从右往左扫描：若 ans[i][1] != -1 且 arr[ans[i][1]] == arr[i]，说明右侧那个位置值相等、不是严格更小，真正的右答案应该继承那个位置的右答案：ans[i][1] = ans[ans[i][1]][1]。
- 图文说明（arr = [3, 1, 2, 1]，求左右最近严格更小）：
```
i=0: 栈空，0 进栈                栈:[0](值3)
i=1: arr[0]=3 >= 1，弹出0: 左=-1 右=1；1进栈    栈:[1](值1)
i=2: arr[1]=1 < 2，不弹；2进栈   栈:[1,2](值1,2)
i=3: arr[2]=2 >= 1，弹出2: 左=1 右=3
     arr[1]=1 >= 1，弹出1: 左=-1 右=3；3进栈   栈:[3](值1)
清算: 弹出3: 左=-1 右=-1
修正(从右往左): arr[3]==arr[1]==1，位置1的右答案3处值相等 → ans[1][1]继承ans[3][1]=-1
最终: 0:[-1,1]  1:[-1,-1]  2:[1,3]  3:[-1,-1]
```
```java
// arr[0...n-1]，求每个位置左右最近且严格更小的位置
public static void compute() {
    r = 0; // 栈顶指针，stack[0...r-1]为栈内容
    int cur;
    // 遍历阶段
    for (int i = 0; i < n; i++) {
        while (r > 0 && arr[stack[r - 1]] >= arr[i]) {
            cur = stack[--r];
            // cur当前弹出的位置：左边最近且小
            ans[cur][0] = r > 0 ? stack[r - 1] : -1;
            // 右边最近且小（暂定，可能需要修正）
            ans[cur][1] = i;
        }
        stack[r++] = i;
    }
    // 清算阶段
    while (r > 0) {
        cur = stack[--r];
        ans[cur][0] = r > 0 ? stack[r - 1] : -1;
        ans[cur][1] = -1;
    }
    // 修正阶段：只有右侧答案需要修正，从右往左
    for (int i = n - 2; i >= 0; i--) {
        if (ans[i][1] != -1 && arr[ans[i][1]] == arr[i]) {
            ans[i][1] = ans[ans[i][1]][1];
        }
    }
}
```
## 二、题目2：每日温度（Code02_DailyTemperatures）
- 题意：给定每天温度数组 temperatures，answer[i] 表示第 i 天之后**下一个更高温度**出现在几天后；如果之后都不会升高则为 0。测试链接：https://leetcode.cn/problems/daily-temperatures/
- 思路：求"右侧最近更大值"，栈底→栈顶值**递减**（存下标）。遇到比栈顶温度高的 i，栈顶 cur 弹出，答案就是 i - cur。
- **相等值处理**：本题用 `<` 弹出（相等不弹），即**相等的温度也留在栈里一起进栈**。因为要求的是"更高温度"，相等不算答案，所以相等时绝不能弹出，否则会把相等值误当成更高值。
- 图文说明（temperatures = [73,74,75,71,69,72,76,73]）：
```
i=0: 栈空，0进栈                     → 栈:[0](值73)
i=1: 74>73，弹0(ans[0]=1)，1进栈     → 栈:[1](值74)
i=2: 75>74，弹1(ans[1]=1)，2进栈     → 栈:[2](值75)
i=3,4: 71、69 递减直接进栈           → 栈:[2,3,4](值75,71,69)
i=5: 72>69弹4(ans[4]=1)，72>71弹3(ans[3]=2) → 栈:[2,5](值75,72)
i=6: 76>72弹5(ans[5]=1)，76>75弹2(ans[2]=4) → 栈:[6](值76)
i=7: 73<76 直接进栈                  → 栈:[6,7]，清算后 ans[6]=ans[7]=0
结果: [1,1,4,2,1,1,0,0]
```
```java
public static int[] dailyTemperatures(int[] nums) {
    int n = nums.length;
    int[] ans = new int[n];
    r = 0;
    for (int i = 0, cur; i < n; i++) {
        // 相等时候的处理：相等也加入单调栈（不弹出）
        while (r > 0 && nums[stack[r - 1]] < nums[i]) {
            cur = stack[--r];
            ans[cur] = i - cur;
        }
        stack[r++] = i;
    }
    return ans; // 清算阶段不用写：ans默认0，栈中剩余位置右边没有更高温度
}
```
## 三、题目3：子数组的最小值之和（Code03_SumOfSubarrayMinimums）
- 题意：求 arr 的每个连续子数组的最小值之和，答案对 10^9+7 取模。测试链接：https://leetcode.cn/problems/sum-of-subarray-minimums/
- 思路（**以每个位置做最小值的子数组有多少个**的转化）：位置 cur 作为最小值能覆盖的范围，左边界 = 左侧最近更小的位置 left，右边界 = 右侧最近更小（或相等，见下）的位置 i。则以 arr[cur] 为最小值的子数组个数 = (cur - left) × (i - cur)，贡献 = 个数 × arr[cur]，累加所有位置即可。
- **相等值处理（关键！）**：用 `>=` 弹出，即 cur 的右边界是"右侧最近**小于等于**"的位置。这样重复值区域会被**左边那个相等值独占**，右边的相等值不会重复统计，**每个子数组的最小值恰好只被算一次**（课上重点讲的相等情况修正）。若两边都用"严格小于"，重复值区域会被左右两个相等值重复计算。
- 注意取模：答案很大，中间累乘要转 long 再取模；不熟悉取模可看讲解041-同余原理。
- 图文说明（arr = [3,1,2,4]）：
```
位置0(值3): left=-1 right=1 → 贡献 (0-(-1))×(1-0)×3 = 3    （子数组[3]）
位置1(值1): left=-1 right=4(清算) → 贡献 2×3×1 = 6            （[1],[3,1],[1,2],[3,1,2],[1,2,4],[3,1,2,4]）
位置2(值2): left=1 right=4 → 贡献 1×2×2 = 4                   （[2],[2,4]）
位置3(值4): left=2 right=4 → 贡献 1×1×4 = 4                   （[4]）
总和 = 3+6+4+4 = 17
```
```java
public static int sumSubarrayMins(int[] arr) {
    long ans = 0;
    r = 0;
    // 注意课上讲的相等情况的修正：>= 弹出，重复值只被左侧那个统计
    for (int i = 0; i < arr.length; i++) {
        while (r > 0 && arr[stack[r - 1]] >= arr[i]) {
            int cur = stack[--r];
            int left = r == 0 ? -1 : stack[r - 1];
            ans = (ans + (long) (cur - left) * (i - cur) * arr[cur]) % MOD;
        }
        stack[r++] = i;
    }
    // 清算阶段：右侧没有更小/相等的了，右边界 = arr.length
    while (r > 0) {
        int cur = stack[--r];
        int left = r == 0 ? -1 : stack[r - 1];
        ans = (ans + (long) (cur - left) * (arr.length - cur) * arr[cur]) % MOD;
    }
    return (int) ans;
}
```
## 四、题目4：柱状图中最大的矩形（Code04_LargestRectangleInHistogram）
- 题意：n 个宽度为 1、高度为 height[i] 的柱子彼此相邻，求能勾勒出的最大矩形面积。测试链接：https://leetcode.cn/problems/largest-rectangle-in-histogram
- 思路：**以每根柱子的高度作为矩形的高**，它能向左右扩展到多远？左右都扩展到"最近更矮的柱子"为止（不含）。位置 cur 左扩到 left、右扩到 i，宽度 = i - left - 1，面积 = height[cur] × (i - left - 1)，所有位置取最大值。
- **相等值处理**：本题用 `>=` 弹出。相等的柱子中，左边那个提前结算时会把宽度**算小**，但因为右边那根等高柱子结算时会把这片区域算全，**最大值不会丢**（只求最大值，重复/偏小不影响正确性），所以无需像题目1那样修正。
- 图文说明（height = [2,1,5,6,2,3]）：
```
位置3(高6): 右扩展到位置4(高2)，左扩展到位置2(高5) → 宽=4-2-1=1，面积=6×1=6
位置2(高5): 右扩展到位置4，左扩展到位置1(高1) → 宽=4-1-1=2，面积=5×2=10  ← 最大
位置1(高1): 左右都能扩到边界 → 宽=6，面积=1×6=6
最终答案 = 10
```
```java
public static int largestRectangleArea(int[] height) {
    int n = height.length;
    r = 0;
    int ans = 0, cur, left;
    for (int i = 0; i < n; i++) {
        while (r > 0 && height[stack[r - 1]] >= height[i]) {
            cur = stack[--r];
            left = r == 0 ? -1 : stack[r - 1];
            // 以height[cur]为高，左扩到left、右扩到i，宽 = i - left - 1
            ans = Math.max(ans, height[cur] * (i - left - 1));
        }
        stack[r++] = i;
    }
    // 清算阶段：右侧可以扩到数组末尾 n
    while (r > 0) {
        cur = stack[--r];
        left = r == 0 ? -1 : stack[r - 1];
        ans = Math.max(ans, height[cur] * (n - left - 1));
    }
    return ans;
}
```
## 五、题目5：最大矩形（Code05_MaximalRectangle）
- 题意：给定 rows × cols 的 0/1 二维矩阵，找出只包含 1 的最大矩形面积。测试链接：https://leetcode.cn/problems/maximal-rectangle/
- 思路（**压缩数组 + 复用题目4**）：枚举每一行 i 作为矩形的**底边**，把矩阵压缩成一维高度数组：height[j] = 第 j 列从第 i 行往上连续 1 的个数（遇到 0 清零）。此时"以第 i 行为底的最大矩形"就等价于**在 height 柱状图中求最大矩形**，直接调用题目4的函数。每行处理一次，取最大值。
- 复杂度：压缩 O(rows × cols)，每行单调栈 O(cols)，总时间 O(rows × cols)。
- 图文说明：
```
矩阵(行0~3):     逐行压缩出的height数组:
1 0 1 0 0        行0: [1,0,1,0,0] → 最大矩形1
1 0 1 1 1        行1: [2,0,2,1,1] → 最大矩形3
1 1 1 1 1        行2: [3,1,3,2,2] → 最大矩形6（第2~4列高3,2,2，取高2×宽3）
1 0 0 1 0        行3: [2,0,0,3,0] → 最大矩形3
每行跑一次largestRectangleArea，全局取max → 答案6
```
```java
public static int maximalRectangle(char[][] grid) {
    int n = grid.length;
    int m = grid[0].length;
    Arrays.fill(height, 0, m, 0);
    int ans = 0;
    for (int i = 0; i < n; i++) {
        // 来到i行，长方形一定要以i行做底！加工高度数组(压缩数组)
        for (int j = 0; j < m; j++) {
            height[j] = grid[i][j] == '0' ? 0 : height[j] + 1;
        }
        ans = Math.max(largestRectangleArea(m), ans); // 复用题目4的单调栈
    }
    return ans;
}
```
## 六、补充：洛谷P5788 单调栈（Code06_MonotonicStackLuogu）
- 课上没讲的代码，原理一样：给定数组，打印每个位置**右侧大于该位置数字的最近位置**（不存在输出0）。测试链接：https://www.luogu.com.cn/problem/P5788
- 这道题对 Java 特别不友好（卡空间卡常），代码里有两个极限优化：**复用 arr 作为答案数组**（位置 x 被 i 弹出时令 arr[x] = i，不再保存原值）、**手写快速读入**。现在的笔试和比赛不会这么极限，看看就好，掌握思想即可。
```java
// 单调栈中保证 : 左 >= 右（栈底到栈顶值不增）
for (int i = 1; i <= n; i++) {
    while (r > 0 && arr[stack[r - 1]] < arr[i]) {
        arr[stack[--r]] = i; // 复用arr：被i弹出 → x右侧最近更大位置就是i
    }
    stack[r++] = i;
}
while (r > 0) {
    arr[stack[--r]] = 0; // 清算：右侧没有更大的
}
```
## 七、总结
- **单调栈模版**：栈存下标、维护单调性，"谁让我弹出，谁就是我那一侧的答案；弹出后我的新栈顶，就是我另一侧的答案"；遍历阶段 + 清算阶段两步走。
- **复杂度**：每个位置只进栈一次、出栈一次，总代价 O(n)，均摊 O(1)。
- **相等值处理是灵魂**：求严格小于 → `>=` 弹出且可能要修正右答案（题目1）；求严格更大 → `<` 弹出、相等直接进栈（题目2）；子数组最小值去重 → 一侧用 `>=` 让重复值只统计一次（题目3）；只求最大值 → 相等怎么弹都不影响正确性（题目4、5）。
- **应用套路**：凡是需要"每个位置向左右扩展到第一个更小/更大值"的问题（最大矩形、子数组最值贡献、下一个更大元素等），都往单调栈上想；二维问题可先压缩成一维柱状图再套模版（题目5）。
