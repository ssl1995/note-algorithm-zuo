# 算法讲解012【入门】链表入门题目-划分链表
前置知识：理解链表及其基本调整 ｜ 建议：做过这个题的同学跳过
代码位置：src/class012/PartitionList.java ｜ 测试链接：https://leetcode.cn/problems/partition-list/
## 一、题目描述
- 给你一个链表的头节点 head 和一个特定值 x，请你对链表进行分隔，使得所有小于 x 的节点都出现在大于或等于 x 的节点之前。
- 你应当保留两个分区中每个节点的初始相对位置（即分区是"稳定"的，不是排序）。
- 示例：1 -> 4 -> 3 -> 2 -> 5 -> 2，x = 3，划分结果为 1 -> 2 -> 2 -> 4 -> 3 -> 5。
## 二、解题思路
- 经典做法：拆成两条链表再拼起来。准备 < x 区域和 >= x 区域各自的头尾指针（leftHead/leftTail、rightHead/rightTail）。
- 遍历原链表，每个节点按值挂到对应区域的尾部；因为是按原顺序依次挂接，相对位置天然保留。
- 关键细节1：每取出一个节点，先记 next = cur.next，再 cur.next = null 断链，防止节点还带着旧指向造成环或脏连接。
- 关键细节2：每个区域的第一个节点要特判（头指针为空时直接当头），之后统一 tail.next = cur 挂尾。
- 最后拼接：leftTail.next = rightHead，返回 leftHead；若没有 < x 的区域（leftHead 为 null），直接返回 rightHead。
## 三、代码实现
```java
public static class ListNode {
    public int val;
    public ListNode next;
    public ListNode(int val) { this.val = val; }
    public ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
public static ListNode partition(ListNode head, int x) {
    ListNode leftHead = null, leftTail = null;   // < x的区域
    ListNode rightHead = null, rightTail = null; // >= x的区域
    ListNode cur = head;
    ListNode next;
    while (cur != null) {
        next = cur.next;
        cur.next = null; // 先断链，防止脏连接
        if (cur.val < x) {
            if (leftHead == null) {
                leftHead = cur;
            } else {
                leftTail.next = cur;
            }
            leftTail = cur;
        } else {
            if (rightHead == null) {
                rightHead = cur;
            } else {
                rightTail.next = cur;
            }
            rightTail = cur;
        }
        cur = next;
    }
    if (leftHead == null) { // 没有<x的区域
        return rightHead;
    }
    leftTail.next = rightHead; // 有<x的区域，先连接大的区域，再返回
    return leftHead;
}
```
## 四、过程图解（以 1->4->3->2->5->2，x=3 为例）
```plain
原链表: 1 -> 4 -> 3 -> 2 -> 5 -> 2
逐个拆分到两个区域:
  <x区域:  1 -> 2 -> 2   （依次接到leftTail后）
  >=x区域: 4 -> 3 -> 5   （依次接到rightTail后）
拼接: leftTail.next = rightHead
结果: 1 -> 2 -> 2 -> 4 -> 3 -> 5
```
## 五、复杂度与易错点
- 时间复杂度 O(N)，只遍历一遍；空间复杂度 O(1)，复用原节点、只用几个引用变量。
- 易错点1：拆节点时忘记 cur.next = null 断链，可能把旧链表的指向带进结果，产生环。
- 易错点2：忘记"没有 < x 区域"的边界，leftHead 为 null 时对 leftTail 操作会空指针。
- 本题思路与荷兰国旗问题（数组划分）一脉相承，都是"分区域、保持稳定"的思想。
