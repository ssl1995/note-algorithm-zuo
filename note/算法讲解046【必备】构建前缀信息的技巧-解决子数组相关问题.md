## 零、本节课内容概览
- 核心思想：很多**子数组（连续）相关问题**，都可以用"构建某种前缀信息 + 哈希表记录该信息**最早出现位置 / 最晚出现位置 / 出现次数**"的技巧，在 **O(n)** 时间内解决。
- 通用模型：设 `sum(i)` 表示 `arr[0..i]` 的某种前缀信息（累加和、余数、奇偶状态等），则以 i 结尾的子数组 `arr[j+1..i]` 的信息 = `sum(i) - sum(j)`（或对应的逆运算）。枚举 i，用哈希表查"需要的那个 sum(j) 出现过没有、在哪/几次"，就把"枚举所有子数组"的 O(n²) 变成了 O(n)。
- 本节课 7 道题覆盖三种经典用法：
  1. **前缀和数组**：快速解决子数组范围求和（题目1）；
  2. **前缀和最早出现的位置**：求满足条件的**最长**子数组（题目2、4、5、7）；
  3. **前缀和出现次数**：求满足条件的子数组**个数**（题目3）；
  4. **前缀和余数最晚出现的位置**：求满足条件的**最短**子数组（题目6）。
- 记忆口诀：**求最长记最早，求最短记最晚，求个数记次数**。
## 一、题目1：前缀和数组（Code01_PrefixSumArray）
- 题意：实现 `NumArray` 类，支持多次查询 `sumRange(left, right)` 返回 `nums[left..right]` 的累加和。测试链接：https://leetcode.cn/problems/range-sum-query-immutable/
- 思路：预处理前缀和数组 `sum`，其中 `sum[i]` 表示 `nums[0..i-1]` 的累加和（即 sum 比原数组多一格，`sum[0]=0`）。查询时 `sumRange(l, r) = sum[r+1] - sum[l]`，每次查询 O(1)。
- 示意图：`nums = [3, 1, 4, 2]` → `sum = [0, 3, 4, 8, 10]`，求 `nums[1..2]` 的和 = `sum[3] - sum[1] = 8 - 3 = 5`。
```java
class NumArray {
    public int[] sum;
    public NumArray(int[] nums) {
        sum = new int[nums.length + 1];
        for (int i = 1; i <= nums.length; i++) {
            sum[i] = sum[i - 1] + nums[i - 1];
        }
    }
    public int sumRange(int left, int right) {
        return sum[right + 1] - sum[left];
    }
}
```
- 复杂度：预处理 O(n)，每次查询 O(1)。这是所有前缀和技巧的基础。
## 二、题目2：累加和为给定值的最长子数组（Code02_LongestSubarraySumEqualsAim）
- 题意：无序数组 arr，元素可正、可负、可 0，给定 aim，求所有子数组中**累加和为 aim 的最长子数组长度**。测试链接：https://www.nowcoder.com/practice/36fb0fd3c656480c92b569258a1223d5
- 关键推导：以 i 结尾的子数组 `arr[j+1..i]` 累加和 = `sum(i) - sum(j)`，要让它等于 aim，即找 `sum(j) = sum(i) - aim`。因为元素可正可负，前缀和不再单调，**不能二分**，必须上哈希表。
- 为什么记"最早出现位置"：要求**最长**子数组，对每个前缀和值只需记住它**第一次**出现的下标，之后再次出现不更新——越早出现，减出来的长度越大。
- **易错点**：必须先查答案、再登记当前前缀和；且初始化 `map.put(0, -1)`——前缀和 0 在"一个数也没有"时就存在了，否则从 0 开始的合法子数组会漏掉。
```java
// key : 某个前缀和；value : 这个前缀和最早出现的位置
public static HashMap<Integer, Integer> map = new HashMap<>();
public static int compute() {
    map.clear();
    // 重要 : 0这个前缀和，一个数字也没有的时候，就存在了
    map.put(0, -1);
    int ans = 0;
    for (int i = 0, sum = 0; i < n; i++) {
        sum += arr[i];
        if (map.containsKey(sum - aim)) {
            ans = Math.max(ans, i - map.get(sum - aim));
        }
        if (!map.containsKey(sum)) {
            map.put(sum, i); // 只在第一次出现时登记，保证是"最早"位置
        }
    }
    return ans;
}
```
- 复杂度：时间 O(n)，空间 O(n)。代码中还给出了牛客网高效输入输出模板（`StreamTokenizer` + `PrintWriter`），笔试时直接套用。
## 三、题目3：累加和为给定值的子数组个数（Code03_NumberOfSubarraySumEqualsAim）
- 题意：求数组中累加和等于 aim 的子数组**个数**。测试链接：https://leetcode.cn/problems/subarray-sum-equals-k/
- 思路变化：从"求最长"变成"求个数"，哈希表的 value 从"最早位置"变成"**该前缀和出现的次数**"。以 i 结尾时，历史上有多少个 `sum - aim`，就有多少个以 i 结尾的合法子数组，直接累加进答案。
- 初始化 `map.put(0, 1)`：前缀和 0 在没任何数字时已出现 1 次。
```java
public static int subarraySum(int[] nums, int aim) {
    HashMap<Integer, Integer> map = new HashMap<>();
    // 0这个前缀和，在没有任何数字的时候，已经有1次了
    map.put(0, 1);
    int ans = 0;
    for (int i = 0, sum = 0; i < nums.length; i++) {
        sum += nums[i]; // sum : 0...i前缀和
        ans += map.getOrDefault(sum - aim, 0);
        map.put(sum, map.getOrDefault(sum, 0) + 1);
    }
    return ans;
}
```
- 复杂度：时间 O(n)，空间 O(n)。这题是前缀和 + 哈希表计数的最经典模板题。
## 四、题目4：正数和负数个数相等的最长子数组（Code04_PositivesEqualsNegtivesLongestSubarray）
- 题意：无序数组（可正、可负、可 0），求**正数个数与负数个数相等**的最长子数组长度。测试链接：https://www.nowcoder.com/practice/545544c060804eceaed0bb84fcd992fb
- **转化技巧（本课精华之一）**：正数当 +1、负数当 -1、0 当 0，则"正负个数相等" ⇔ "子数组累加和为 0"，瞬间退化成题目2（aim = 0 的特例）：
```java
arr[i] = num != 0 ? (num > 0 ? 1 : -1) : 0;
```
- 之后就是标准的"前缀和最早出现位置"模板——找相同的 sum 出现过的最早位置（因为 `sum(i) - sum(j) = 0` 即 `sum(j) = sum(i)`）：
```java
public static int compute() {
    map.clear();
    map.put(0, -1);
    int ans = 0;
    for (int i = 0, sum = 0; i < n; i++) {
        sum += arr[i];
        if (map.containsKey(sum)) {
            ans = Math.max(ans, i - map.get(sum));
        } else {
            map.put(sum, i);
        }
    }
    return ans;
}
```
- 启示：很多"计数相等/差值固定"类条件，都可以通过 **数值映射（+1/-1/0）** 转化为前缀和问题。同类题：0 和 1 个数相等的最长子数组（LeetCode 525）。
## 五、题目5：表现良好的最长时间段（Code05_LongestWellPerformingInterval）
- 题意：工作时间表 hours，工作 > 8 小时算"劳累"，求**劳累天数严格大于非劳累天数**的最长时间段长度。测试链接：https://leetcode.cn/problems/longest-well-performing-interval/
- 转化：> 8 小时当 +1，否则当 -1，问题变成"累加和 **> 0** 的最长子数组"——注意这次不是"等于"，而是"大于"，处理方式有讲究。
- 分类讨论当前前缀和 sum（0..i 的和）：
  1. `sum > 0`：整个 `0..i` 都满足，答案直接是 `i + 1`；
  2. `sum <= 0`：需要子数组 `j+1..i` 的和 > 0，即 `sum(i) - sum(j) >= 1`，只需找 `sum(j) <= sum(i) - 1` 的最早位置。由于前缀和每次只变化 ±1（步长为 1），**比 sum-1 更小的值出现的位置一定不比 sum-1 更早**，所以只查 `sum - 1` 即可（这是本题最妙的优化）。
```java
public static int longestWPI(int[] hours) {
    // 某个前缀和，最早出现的位置
    HashMap<Integer, Integer> map = new HashMap<>();
    map.put(0, -1);
    int ans = 0;
    for (int i = 0, sum = 0; i < hours.length; i++) {
        sum += hours[i] > 8 ? 1 : -1;
        if (sum > 0) {
            ans = i + 1;
        } else if (map.containsKey(sum - 1)) {
            ans = Math.max(ans, i - map.get(sum - 1));
        }
        if (!map.containsKey(sum)) {
            map.put(sum, i);
        }
    }
    return ans;
}
```
- 复杂度：时间 O(n)，空间 O(n)。关键前提"前缀和变化步长为 1"才允许只查 `sum-1`，步长不唯一时此优化不成立。
## 六、题目6：使数组和能被 P 整除（Code06_MakeSumDivisibleByP）
- 题意：正整数数组 nums，移除**最短**子数组（可为空，不能全移除），使剩余元素和能被 p 整除，返回最短长度，做不到返回 -1。测试链接：https://leetcode.cn/problems/make-sum-divisible-by-p/
- 推导（**同余原理**，讲解041 也讲过）：设整体和的余数为 `mod = total % p`。若 `mod == 0` 直接返回 0。否则要移除的子数组余数必须恰好等于 mod：设 `cur = sum(i) % p`，要找 `sum(j) % p = (cur - mod + p) % p`。
- 求**最短**子数组 → 哈希表记每个余数**最晚**出现的位置（每次都更新覆盖），这样减出来的长度最小。
```java
public static int minSubarray(int[] nums, int p) {
    int mod = 0;
    for (int num : nums) {
        mod = (mod + num) % p; // 整体余数
    }
    if (mod == 0) {
        return 0;
    }
    // key : 前缀和%p的余数；value : 最晚出现的位置
    HashMap<Integer, Integer> map = new HashMap<>();
    map.put(0, -1);
    int ans = Integer.MAX_VALUE;
    for (int i = 0, cur = 0, find; i < nums.length; i++) {
        cur = (cur + nums[i]) % p; // 0...i这部分的余数
        find = cur >= mod ? (cur - mod) : (cur + p - mod); // 等价于 (cur + p - mod) % p
        if (map.containsKey(find)) {
            ans = Math.min(ans, i - map.get(find));
        }
        map.put(cur, i); // 每次覆盖，保证是"最晚"位置
    }
    return ans == nums.length ? -1 : ans; // 不允许全移除
}
```
- 对比记忆：题目2/4/5 求最长记**最早**（只在没出现过时 put）；本题求最短记**最晚**（每次都 put 覆盖）。
## 七、题目7：每个元音包含偶数次的最长子串（Code07_EvenCountsLongestSubarray）
- 题意：字符串 s，求每个元音字母 a/e/i/o/u 都恰好出现**偶数次**的最长子串长度。测试链接：https://leetcode.cn/problems/find-the-longest-substring-containing-vowels-in-even-counts/
- 前缀信息的推广：前缀信息不一定是"和"，可以是**状态**！5 个元音各只有奇/偶两种 → 用一个 5 位二进制数 `status` 表示 `0..i` 上各元音出现次数的奇偶性，共 2^5 = 32 种状态，可用数组代替哈希表。
- 关键性质：`j+1..i` 上每个元音都出现偶数次 ⇔ `status(i)` 与 `status(j)` **完全相同**（异或为 0）。所以记录每个状态**最早**出现的位置即可。遇到元音字符就 `status ^= 1 << m` 翻转对应位。
- 用 `map[status] == -2` 表示"该状态还没出现过"，`map[0] = -1` 表示全偶状态在空串时就存在：
```java
public static int findTheLongestSubstring(String s) {
    int n = s.length();
    int[] map = new int[32]; // 只有5个元音字符，状态就5位
    Arrays.fill(map, -2);    // -2 : 这个状态之前没出现过
    map[0] = -1;
    int ans = 0;
    for (int i = 0, status = 0, m; i < n; i++) {
        m = move(s.charAt(i)); // 'a'~'u' -> 0~4，非元音 -> -1
        if (m != -1) {
            status ^= 1 << m;
        }
        // status : 0..i 字符串上 aeiou 的奇偶性
        if (map[status] != -2) {
            ans = Math.max(ans, i - map[status]);
        } else {
            map[status] = i; // 只记最早出现位置
        }
    }
    return ans;
}
public static int move(char cha) {
    switch (cha) {
        case 'a': return 0;
        case 'e': return 1;
        case 'i': return 2;
        case 'o': return 3;
        case 'u': return 4;
        default: return -1;
    }
}
```
- 复杂度：时间 O(n)，空间 O(1)（固定 32 大小的数组）。这题展示了"前缀信息 + 状态压缩"的组合，遇到异或/奇偶类条件时非常好用。
## 八、总结
- 一句话：**子数组问题想前缀和，前缀信息配哈希表**。
- 三种 value 记法对应三种问题：求**最长**记最早出现位置（只在首次 put）；求**最短**记最晚出现位置（每次 put 覆盖）；求**个数**记出现次数（getOrDefault + 1）。
- 两个固定动作：① 初始化 `0` 这个前缀信息在位置 `-1`（或次数 1）已经存在；② 每轮**先查答案、再登记当前信息**，保证不会用到自己。
- 前缀信息可以很灵活：累加和、模 p 余数、奇偶状态（位压缩）、甚至更多自定义信息——构建某种前缀信息（最早出现、最晚出现、出现次数等）解决子数组相关问题，是非常常见且必须掌握的技巧。
