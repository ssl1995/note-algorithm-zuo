## 零、递归的本质认知
- 任何递归都是 dfs（深度优先遍历），且非常灵活。"回溯"这个术语并不重要，本质就是递归调用 + 恢复现场。
- 带路径的递归 vs 不带路径的递归：大部分 dp、状态压缩 dp 可以认为是把路径简化成了结构，dp 专题后续讲述。
- 写递归的关键：定义好子问题（递归函数的含义），主问题调用子问题即可，不要去"人肉模拟"整个调用过程。
## 一、返回字符串全部子序列（去重）｜ 时间复杂度 O(2^n * n)
- 测试链接：https://www.nowcoder.com/practice/92e6247998294f2c933906fdedbc6e6a
- 思路：对每个字符做"要 / 不要"两个决定，递归到结尾时路径就是一个子序列，用 HashSet 去重。
- 决策树示意（以 "ab" 为例）：每个位置分两支，左支"要当前字符"，右支"不要"，走到叶子收集结果：
```
            ""
         /      \
       要a       不要a
      /  \       /  \
    ab    a     b    ""
```
- 写法1：用 StringBuilder 作为路径，"加进去 → 递归 → 删掉 → 再递归"，这就是标准的回溯（恢复现场）：
```java
public static void f1(char[] s, int i, StringBuilder path, HashSet<String> set) {
  if (i == s.length) {
    set.add(path.toString());
  } else {
    path.append(s[i]); // 加到路径中去
    f1(s, i + 1, path, set);
    path.deleteCharAt(path.length() - 1); // 从路径中移除（恢复现场）
    f1(s, i + 1, path, set);
  }
}
```
- 写法2：用 char[] 做路径，额外维护一个 size 表示路径长度，天然"写覆盖"，无需删除：
```java
public static void f2(char[] s, int i, char[] path, int size, HashSet<String> set) {
  if (i == s.length) {
    set.add(String.valueOf(path, 0, size));
  } else {
    path[size] = s[i];
    f2(s, i + 1, path, size + 1, set);
    f2(s, i + 1, path, size, set);
  }
}
```
## 二、返回数组的所有组合（含重复元素，结果去重）｜ 时间复杂度 O(2^n * n)
- 测试链接：https://leetcode.cn/problems/subsets-ii/（LeetCode 90. 子集 II）
- 示例：nums = [1,2,2] → [[],[1],[1,2],[1,2,2],[2],[2,2]]
- 思路：先排序让相同数字相邻；递归时不逐个"要/不要"，而是把连续的一段相同数字 x 看成一组，枚举"要 0 个、要 1 个、要 2 个……"，这样天然不会产生重复组合。
```java
public static List<List<Integer>> subsetsWithDup(int[] nums) {
  List<List<Integer>> ans = new ArrayList<>();
  Arrays.sort(nums);
  f(nums, 0, new int[nums.length], 0, ans);
  return ans;
}

public static void f(int[] nums, int i, int[] path, int size, List<List<Integer>> ans) {
  if (i == nums.length) {
    ArrayList<Integer> cur = new ArrayList<>();
    for (int j = 0; j < size; j++) {
      cur.add(path[j]);
    }
    ans.add(cur);
  } else {
    // 下一组的第一个数的位置（跳过与 nums[i] 相同的一段）
    int j = i + 1;
    while (j < nums.length && nums[i] == nums[j]) {
      j++;
    }
    // 当前数 x，要 0 个
    f(nums, j, path, size, ans);
    // 当前数 x，要 1 个、要 2 个、要 3 个...都尝试
    for (; i < j; i++) {
      path[size++] = nums[i];
      f(nums, j, path, size, ans);
    }
  }
}
```
- 关键点：去重不是靠 HashSet 收集，而是在"做决策"时就保证不产生重复分支。
## 三、没有重复值数组的全部排列｜ 时间复杂度 O(n! * n)
- 测试链接：https://leetcode.cn/problems/permutations/（LeetCode 46. 全排列）
- 思路（交换法）：递归到第 i 层时，i 之前的部分已经固定；枚举 nums[i...n-1] 中每个数来到 i 位置，交换后递归 i+1，递归回来再交换回去（恢复现场）。
- 图解（[1,2,3] 第 0 层）：1 固定在首位 → 递归 [2,3]；2 与 1 交换（[2,1,3]）→ 递归 [1,3]；3 与 1 交换（[3,2,1]）→ 递归 [2,1]。每条支路递归完都要把数组换回原样，兄弟分支才能基于同样的状态继续。
```java
public static void f(int[] nums, int i, List<List<Integer>> ans) {
  if (i == nums.length) {
    List<Integer> cur = new ArrayList<>();
    for (int num : nums) {
      cur.add(num);
    }
    ans.add(cur);
  } else {
    for (int j = i; j < nums.length; j++) {
      swap(nums, i, j);
      f(nums, i + 1, ans);
      swap(nums, i, j); // 特别重要：恢复现场
    }
  }
}
```
- 复杂度：排列共 n! 种，每种收集时拷贝 n 个数，故 O(n! * n)。
## 四、有重复值数组的去重全排列｜ 时间复杂度 O(n! * n)
- 测试链接：https://leetcode.cn/problems/permutations-ii/（LeetCode 47. 全排列 II）
- 思路：在题目三的交换法基础上，每一层用一个 HashSet 记录"哪些值已经来到过 i 位置"，重复的值不再交换到 i 位置，从源头剪掉重复分支，无需最后去重。
```java
public static void f(int[] nums, int i, List<List<Integer>> ans) {
  if (i == nums.length) {
    List<Integer> cur = new ArrayList<>();
    for (int num : nums) {
      cur.add(num);
    }
    ans.add(cur);
  } else {
    HashSet<Integer> set = new HashSet<>();
    for (int j = i; j < nums.length; j++) {
      // nums[j] 没有来到过 i 位置，才会去尝试
      if (!set.contains(nums[j])) {
        set.add(nums[j]);
        swap(nums, i, j);
        f(nums, i + 1, ans);
        swap(nums, i, j);
      }
    }
  }
}
```
- 注意：这个剪枝不需要数组有序（与 LeetCode 90 不同），每层的 set 只对本层负责。
## 五、用递归逆序一个栈｜ 时间复杂度 O(n^2)
- 题目：不借助任何其他容器，只用递归把栈逆序。
- 核心子过程 bottomOut：把栈底元素弹出返回，上面的元素原样盖下来（递归到底部后逐层把元素压回）。
- reverse：弹出栈底元素 num → 递归逆序剩余栈 → 把 num 压回栈顶，原来栈底的元素就沉到了最底。
```
栈: 1 2 3 4 5(栈顶)
bottomOut -> 弹出栈底 1，栈变为 2 3 4 5
reverse 递归逆序剩余 -> 栈变为 5 4 3 2
把 1 压回栈顶 -> 5 4 3 2 1，完成逆序
```
```java
public static void reverse(Stack<Integer> stack) {
  if (stack.isEmpty()) {
    return;
  }
  int num = bottomOut(stack);
  reverse(stack);
  stack.push(num);
}

// 栈底元素移除掉，上面的元素盖下来，返回移除掉的栈底元素
public static int bottomOut(Stack<Integer> stack) {
  int ans = stack.pop();
  if (stack.isEmpty()) {
    return ans;
  } else {
    int last = bottomOut(stack);
    stack.push(ans);
    return last;
  }
}
```
- 复杂度：reverse 递归 n 层，每层 bottomOut 是 O(n)，总 O(n^2)。
## 六、用递归排序一个栈｜ 时间复杂度 O(n^2)
- 题目：只能用栈的 push、pop、isEmpty 三个方法和递归函数（返回值最多单个整数），不能用任何容器（数组也不行），把栈排成"从栈顶到栈底从小到大"。
- 思路（类似选择排序）：每轮从当前无序的 deep 层里找到最大值 max 及其出现次数 k，把这 k 个 max 沉到 deep 层的底部，然后 deep -= k 继续下一轮。
- 四个递归子函数，全部做到"用完恢复栈原状"：
  - deep(stack)：返回栈的深度（弹出再压回，恢复原状）。
  - max(stack, deep)：从栈顶往下数 deep 层，返回最大值（恢复原状）。
  - times(stack, deep, max)：统计 deep 层中 max 出现的次数（恢复原状）。
  - down(stack, deep, max, k)：把 deep 层中的 k 个 max 沉底，其余元素相对顺序不变。
```java
public static void sort(Stack<Integer> stack) {
  int deep = deep(stack);
  while (deep > 0) {
    int max = max(stack, deep);
    int k = times(stack, deep, max);
    down(stack, deep, max, k);
    deep -= k;
  }
}

// 把 deep 层里的 k 个最大值沉底，剩下的数据状况不变
public static void down(Stack<Integer> stack, int deep, int max, int k) {
  if (deep == 0) {
    for (int i = 0; i < k; i++) {
      stack.push(max);
    }
  } else {
    int num = stack.pop();
    down(stack, deep - 1, max, k);
    if (num != max) {
      stack.push(num);
    }
  }
}
```
- 代码中附带对数器（randomStack + isSorted 随机验证 20000 次），是值得学习的验证手段。
## 七、打印 n 层汉诺塔问题的最优移动轨迹｜ 时间复杂度 O(2^n)
- 题目：3 根柱子（左、中、右），n 个圆盘从小到大叠在左边，每次移动一个盘且大盘不能压小盘，打印把全部圆盘从"左"挪到"右"的最优轨迹。
- 递归定义：f(i, from, to, other) 表示"把上面 i 层圆盘从 from 挪到 to，借助 other"的最优移动过程：
  1. 先把 i-1 层从 from 挪到 other（借助 to）；
  2. 把第 i 层（最大的盘）从 from 挪到 to；
  3. 再把 i-1 层从 other 挪到 to（借助 from）。
```java
public static void hanoi(int n) {
  if (n > 0) {
    f(n, "左", "右", "中");
  }
}

public static void f(int i, String from, String to, String other) {
  if (i == 1) {
    System.out.println("移动圆盘 1 从 " + from + " 到 " + to);
  } else {
    f(i - 1, from, other, to);
    System.out.println("移动圆盘 " + i + " 从 " + from + " 到 " + to);
    f(i - 1, other, to, from);
  }
}
```
- n = 3 时的输出：
```
移动圆盘 1 从 左 到 右
移动圆盘 2 从 左 到 中
移动圆盘 1 从 右 到 中
移动圆盘 3 从 左 到 右
移动圆盘 1 从 中 到 左
移动圆盘 2 从 中 到 右
移动圆盘 1 从 左 到 右
```
- 复杂度：移动步数 T(n) = 2*T(n-1) + 1 = 2^n - 1，故 O(2^n)。这也是汉诺塔问题的最优解（数学上可证明最少步数就是 2^n - 1）。
## 八、本节小结
- 子序列/组合/排列三大枚举模型：每个位置"要不要"（2^n）、按组枚举相同元素个数（组合去重）、交换法全排列（n!）。
- 回溯三板斧：做选择 → 递归 → 恢复现场（StringBuilder 删字符、swap 换回来）。
- 去重的两种境界：收集结果时用 HashSet 去重（笨但通用）vs 决策时剪枝不产生重复分支（更优）。
- 栈的递归技巧：所有子函数都遵守"弹出 → 递归 → 压回"的协议，就能在不破坏栈的前提下读取/修改任意深度。
- 汉诺塔是"递归定义子问题"的典范：信任子问题已被解决，只描述主问题如何用子问题拼装。
